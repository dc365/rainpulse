# Unified clutter fusion v1

Base 9f8489075a90874903f881a5d49c79bf3d61254e. Opt-in `volume_review.clutter_fusion`.
No changed defaults, no radial changes. One feature/decision/action stage after RDR.
Optional `background` reuses the attached short-episode builder and matcher as AUDIT EVIDENCE ONLY;
it must not perform an independent EBG disposition. No asset means no background evidence, not no algorithm.

Raw DBZH/availability stay immutable. Unknown high-level observations NEVER become absence.
Ground-like and biological-like are uncalibrated feature-pattern names, not cause confirmation.
Polarization transforms constitute ONE family. Missing features never renormalize weights.
Background alone, reflectivity texture alone and near-zero Doppler alone never authorize action.
Modes audit / cr_withhold / quarantine. Single-polar-family biological pattern is at most CR-only;
quarantine requires >=2 active evidence families. Explicit positive and unattributed legacy weather
remain barriers. Local-only conflicts may be CR-withheld as MIXED via opt-in, never quarantined.
Unknown no-rain codes are not reinterpreted. No whole-column deletion, interpolation or dBZ subtraction.

CF_BEFORE_* preserve changed fields; validation invokes unchanged parent first then replays exact delta.
CF_* diagnostics and config+asset receipts are persisted through QC snapshots and composite risk arrays.
All input radars must have the same fusion config identity (including registry), though bound model
content is allowed to differ by station. No earlier trust/CR/QPE exclusion is revived.

Cross-cut Doppler and vertical context require actual per-ray time and footprint matching. Their
point-centre matches are diagnostics; action-grade vertical additionally requires declared beam width
and non-overlapping main-beam height intervals. Paired Doppler action additionally requires an explicit
verified waveform/dealiasing/Nyquist contract. Original coincident VR/SW may be used without pairing.
No echo-top/upper-missing hard masks. No satellite, model data, online training or permanent masks.

Resource limit -> complete zero-action diagnostics for whole enhancement volume; corrupted assets or
invalid configuration -> explicit error, never baseline disguised as an enhanced success.
