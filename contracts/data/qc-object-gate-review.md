# Object/gate review contract

Join Py-ART object IDs, scikit-image boundary evidence and the BWS gate hypothesis.
Emit independent reason bits (not an exclusive category): geometry unconfirmed,
source unavailable, power mismatch, polar mismatch, weather/conflict, numeric
plateau, no valid observation, hypothesis eligible. Geometric membership alone
cannot erase a source conflict or manufacture absent reference evidence.

Proposal requires paired geometry AND existing valid BWS candidate AND finite
source residual within 2.5 dB AND absence of explicit weather/conflict/plateau.
This is a conservative intersection, not a claim of new detection or improvement.
Use it first to locate the remaining blockers. No input mutation or publication.
