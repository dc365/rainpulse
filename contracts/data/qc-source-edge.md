# 源模型边缘关联候选 v1

仅研究候选，不发布产品、不决定删除。输入原生极坐标、冻结的源候选 seed、目标距离功率参考有效性及残差，必须显式传入 weather/conflicts（包括数值平台）。
同距离相邻实测径向、角差 >0 且 <=1.5°、无几何断裂才可关联。不递归传播，不跨缺测，不使用新候选反向扩张。
目标需自身参考有效且有限残差绝对值<=2.5 dB、原始回波>35 dBZ连续50 km（既有 scikit-image opening），并通过保护。
返回候选与重叠原因位：1关联、2自身源匹配、4长条、8保护、16最终候选。此为源关联假设，不等于气象真值或独立污染证据；上线仍需完整天气证据与原生流水线验收。

## 7.3.4 流水线接入

新增 source_edge 开关，默认false且不进入旧参数哈希；仅7.3.4身份允许。自身参考还必须通过留出SNR包络；边缘候选来源为冻结的宽源候选，只隔离不新增确认干扰。BWS_REASON bit128为新增边缘关联支持；功率残差在此开关下对全部合格单径向参考记录。最终仍由generalization统一执行天气/增强保护、QI、QPE和预算复核。审计模式不改变动作。
