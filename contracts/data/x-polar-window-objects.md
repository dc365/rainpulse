# X original polar window objects

This candidate measures joint DBZH/SNR/RHOHV/ZDR anomaly distributions on
complete physical range windows. It does not relabel missing data, change RAW,
or use PHIDP/Doppler/vendor extension codes. Point connectivity is not object
identity: intermittent normally measured points remain in the window history.

Nomination uses the existing low-RHOHV, sufficient-SNR and abnormal-ZDR
conjunction. Geometry retains every nominated original window, including wide,
changing, unknown and conflicting histories. No width admission filter or
restart on a narrow tail is allowed. Declared angle/time/elevation gaps and
supplied weather/counterexample masks are barriers.

Both exterior sides require independently observed, sufficiently populated
polar windows with ordinary RHOHV/ZDR and sufficient SNR. Window medians are
distribution measurements, never a claim that every shoulder gate is weather.
Unknown or unsupported shoulders cannot count as quiet. Stable complete native
boundaries, physical span/support and the fan range ratio are required.

Returned membership is restricted to originally observed gates satisfying the
joint anomaly conjunction. Normally measured holes, unavailable moments and
weather protections are never painted into membership. The existing strong
reflectivity gate limit restricts membership without erasing original geometry
history. Per-gate diagnostic
membership does not infer source authority for other gates or objects.

The candidate is diagnostic only until paired real-data, weather counterexample,
normal finalizer, publication and UI verification pass. No production profile,
action fraction or writer defaults change. Resource failures are atomic and
explicit; all measured history and qualification reasons remain inspectable.

Every measured object reports all failed qualification checks, rather than a
single boolean refusal. Fork/merge ancestry and supplied protection have
distinct conflict codes. Exterior reference observations that are unavailable
or protected are counted separately from known polar distributions that fail
the reference test. These diagnostic causes do not authorize an action or
change qualification, thresholds, membership, or missing-data semantics.
