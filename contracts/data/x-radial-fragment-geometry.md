# X 原生间歇径向家族候选

`multiband/xqc_v2/fragment_geometry.py` 是独立候选提名入口，尚未接入生产动作。

- 只读原生 RAW；返回已有观测门上的候选矩阵及 `UNQUALIFIED_GEOMETRY` 家族，不能当污染标签、天气负票、源模型票、隔离或清除许可。
- 接收噪声底必须显式给定。两侧角边界均来自真实可用 SNR；未知接收信号、坏射线、采集间断不得跨越。宽度采用原有 X 上限。
- 同射线片段仅在间隔不超过原有物理距离上限且全间隔接收信号有测量时关联。接收器实测低值可为间歇源身份关联，不能对间隔填入反射率或自动触发动作。
- 家族必须达到原有物理跨度、门数和径向长宽比要求。角宽采用所有候选门实测宽度的最大值，不能把宽扇区逐射线拆窄冒充径向。
- 缺测不能变为零；高 rho、低 SNR、天气冲突不由几何提名覆盖。后续动作仍须独立源/偏振判据、上下层天气保护及原有动作预算。
- 提名记录保留原始射线、片段数、原范围、真实门密度、角宽和长宽比；无递归关联、无新增值、无产品发布。

验证：`PYTHONPATH=algorithms .build/xqc-zf702-investigation/venv/bin/python -m pytest -q algorithms/tests/xqc_v2_20260928/test_fragment_geometry.py`

## 原始家族范围内的源资格

`fragment_source.detect` 仍为独立诊断入口，未接入 `core` 或生产动作。几何提名后逐家族、逐模式调用 `source_blocks.detect(domain=...)`：

- domain 是布尔原生矩阵，由 RAW 家族原范围冻结；同射线两段独立家族不能合并训练，目标与保护邻块仍不得作参考。
- domain 同时限定参考与目标；角向接收器边界仍读取完整实际观测，不得把范围外或其他射线裁成虚假静默侧翼。
- 沿用原跨度、范围杠杆、参考比例、源功率/反射率距离响应、稳定度和每门预测界限；不增大阈值或动作预算。
- 90/50 模式分别拟合，最后仅返回原几何提名中的观测门且排除保护门；不从合格门递归派生新源或填入缺测。
- 共用一次 RAW 统计与全层资源预算，预算超限抛出 ResourceLimit，不返回部分模型结果。
- 输出保存每个原家族范围、分位模式、目标/参考块、拟合参数和合资格门数。合资格源模型不等于独立降水误删验收。
- `domain=None` 保持既有生产行为；全 true domain 的 mask 和完整模型记录与旧路径逐字段相等。新增入口未改变配置摘要或线上图件。

验证增加 `test_source_domain.py` 与 `test_fragment_source.py`：覆盖跨零方位、高仰角、间歇弱源、目标留出、短家族不能借远段参考、保护与异常增强、范围变化天气、接收信号缺测、资源弃权。
