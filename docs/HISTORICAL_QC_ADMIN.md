# 历史案例质控重算入口

后台 `/admin` 顶部“历史案例 · 雷达质控重算”按北京时间日期选择案例。目录使用完整分页读取；按源运行去重，提交该日期全部可重算起报时次。复用已有 forecast_all 流程，包含各输入帧的雷达质控、QPE、LK及关联产品，不是仅计算QC。

已受理任务由后台持续执行。提交请求目前由页面依次发送，因此必须等待全部受理后再关闭页面；未受理项目不会在关页后继续自动提交。本浏览器localStorage保存本批回执，刷新自动恢复查询，非跨浏览器共享队列。

进度以已发布时次/本批总时次计数，逐时次显示状态、当前任务、错误和运行ID；受理不算完成。查询并发上限4，每轮5秒。网络提交结果不明确时停止后续提交，先核对运行记录，不能自动重试可能已受理的POST。后台已有重复运行保护。

缺少run_id的目录时次明确计数提示，不能直接发起forecast_all，不能称这些时次已经重算或保证全部原始体扫覆盖。这些分析时次可能被相邻起报的输入帧覆盖；独立无起报历史分析重算仍需新增服务端入口。

测试覆盖日期时区、源运行去重、未就绪时次提示、整批提交、发布计数、刷新恢复不重复提交、网络异常停止。保留既有多选/单时次重算入口。
