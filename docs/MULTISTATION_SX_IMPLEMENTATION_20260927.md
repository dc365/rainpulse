# 多站 S/X 地图实施记录

## 本批实现

- 多站叠加共用现有 OpenLayers 地图、反射率色谱、六分钟时间轴与双图/卷帘/单图布局。
- 站点多选、波段筛选、快捷全选、每站仰角/可见性/透明度/层序；选择在当前浏览器会话保存。
- X 按真实体扫开始时间落入六分钟资料窗口，分页读取目录，并发最多四个站点目录请求；换时次立即清除旧结果。
- 各站独立几何范围，候选 X 地图可叠加；距离圈仅数字，默认关注站，支持全部/关闭。
- 站点目录扩展 S/X/all；组合目录仅返回成功、未退役的冻结任务版本。
- S 组合使用已发布数值产品和真实 bounds。S / S+X 对照只使用同一计算的同网格结果。
- 多波段 Worker 新增 S、X、S+X EPSG:4326 地图预览，最近邻重投影；原数组、质量门控和计算方法不变。
- 缺少 X 数值组合时明确标注 X 未参与，S 单图保留可查看；不以站点 PNG 叠图生成数值组合。
- 生成入口携带已选站点和六分钟时次，继续使用现有计划、预检查、提交链路。

## 环境限制和后续项

后续实现已补齐批量图层解析、源数值点查、贡献分析图层及图片缓存预算；见下方续批记录。真实 4 S + 11 X 联网验收仍依赖完整站点登记。

## 续批：点查、贡献与有界加载

- 新增 POST `radar-layer-resolutions`（最多 16 站、4 路并发、单站失败隔离）与 `radar-layer-probes`（最多 16 图层）。S 周期必须与请求时次一致；X 按六分钟窗口选择真实体扫，分页异常明确失败。
- 源值索引采用 64×64 数值小块，与图片和扫描身份绑定 SHA-256；float64 容器无损保存 float32 源值及 uint32 标记。Go 只解压点击处小块，返回标量，缺测返回 null。界面显示原生射线/距离门和质量状态，旧结果没有索引时明确要求重新生成。
- 点查坐标是所显示北向图片的像素比例，返回该像素实际采样的原生数值；不是连续空间插值，也不反解颜色。候选 X 的地理位置仍待核验。
- 同次计算增加 S+X−S（仅共同有效回波格点）、X 新增有效覆盖（包括有效无回波）、获胜波段/站点、年龄与质量得分。来源与排除信息保留，未获得资格的 X 不参与数值融合。
- 图片共享下载并发 4，已解码缓存估算预算 128 MiB，使用中帧固定、闲置帧按最近使用顺序淘汰；切换时次取消旧请求并释放对象 URL。此预算是缓存驻留估算，不是浏览器整个进程 RSS 上限。
- 合成负载测试覆盖 4 S + 11 X 双图共 30 图片、连续 7 帧的缓存淘汰；并检查同 URL 共享、预算拒绝、旧点查结果隔离。真实全网压力验证尚无 11 个已登记 X 站可用。
- 本地验证：146 前端测试；62 多波段测试；30 diagnostics/receipts 测试；131 C/D 回归通过、3 项跳过；相关 Go 包通过；契约生成一致；前端构建通过，lint 无错误（6 条原有警告）。
