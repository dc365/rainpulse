# 多站 S/X 地图实施记录

## 本批实现

- 多站叠加共用现有 OpenLayers 地图、反射率色谱、六分钟时间轴与双图/卷帘/单图布局。
- 站点多选、波段筛选、快捷全选、每站仰角/可见性/透明度/层序；选择在当前浏览器会话保存。
- X 按真实体扫开始时间落入六分钟资料窗口，分页读取目录，并发最多四个站点目录请求；换时次立即清除旧结果。
- 各站独立几何范围，候选 X 地图可叠加；距离圈仅数字，默认关注站，支持全部/关闭。
- 站点目录扩展 S/X/all；组合目录仅返回成功、未退役的冻结任务版本。
- S 组合使用已发布数值产品和真实 bounds。S / S+X 对照只使用同一计算的同网格结果。
- 多波段 Worker 新增 S、X、S+X EPSG:4326 地图预览，最近邻重投影；原数组、质量门控和计算方法不变。
- 缺少 X 数值组合时明确标注 X 未参与，S 单图保留可查看；不以站点 PNG 叠图生成数值组合。
- 生成入口携带已选站点和六分钟时次，继续使用现有计划、预检查、提交链路。

## 环境限制和后续项

105 当前网络配置仅有 zf101/zf505，均 enabled=false、geometry_verified=false、calibration_verified=false，products 为空。此批不修改这些资格；真实 S+X 数值融合暂不能运行。

批准设计中的批量源数值点查、贡献分析图层、按像素内存预算缓存和 4 S + 11 X 压力验收仍待后续落实。现阶段复用现有目录 API 完成多站解析，未增加单独的 batch-resolution API；不把反射率颜色反推值作为源数值读数。

本批实机资料包含 4 个 S 站目录和 2 个 X 站目录；08:06 资料窗口有 2 S + 2 X 可显示，另 2 S 明确缺测。

## 验证

- 前端单站回归、多站混合选择、跨波段筛选保持选择、换时次清除旧 X 图件。
- 组合时次 ISO 表示兼容、过期结果清除。
- Python 地图北向/南向、缺测透明、网格外边界；原组合计算回归。
- Go 组合地图 CRS/边界/路径验证；站点和组合目录 SQL 集成测试使用专用临时数据库。
- 桌面 1440×1000 和移动端 375×812 实际浏览器检查。
