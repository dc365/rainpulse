# NowcastNet 输出重叠试验

## 冻结边界

v1 输入瓦片重叠，但可信输出窗口相邻不重叠，加权归一化退化为直接
拼接。v2 保持 128×128 输入和原有逐成员 raised-edge 加权函数，调整
可信输出窗口使其真正重叠；内部边缘预留 16 格上下文，东西向常规
可信重叠 32 格，南北向重叠 23 格，最东端重叠 43 格。

此配置是受控离线候选，不替换默认 worker 的 v1 atlas，不改变公开
权重、分辨率、原生时间步长或缺测发布掩膜，不自动发布到工作台。
同一输入、种子、批大小做 v1/v2 对照；原生帧和派生帧分开评价。
仅改善接缝不能证明预报技巧提升。原有缺测上下文填零策略不在本次
试验中改变，输出仍保留实况有效域，需另行进行科学验证。

后续应比较更大上下文窗口和更窄/分尺度融合带，检查偏移造成的强
降雨稀释；需要同域 CSI/FSS、多起报证据后才能决定是否推广。

## 重现

在现有 NowcastNet 环境中，使用仓库外的 MinIO 读取配置，执行：

```sh
PYTHONPATH=algorithms:.build/worker-site-packages \
runtime/nowcastnet/venv/bin/python scripts/compare_nowcastnet_overlap.py \
  --issue-time 2026-08-28T08:30:00Z \
  --output runtime/experiments/nowcastnet-overlap-1630-new
```

输出目录必须不存在，防止覆盖证据。脚本只读业务数据，写本地实验
目录，包含 report.json、两份数值 NPZ 和 comparison.png，不调用
发布接口。GPU 上还运行其他任务时，不将冷/热启动的 4.68/2.69 秒
差异解释为性能提升。

回归：旧 atlas 几何产生 1.5 mm/h 人工跳变，测试失败；v2 的横纵
相邻格跳变均小于 0.1，且一致预测中的 80 mm/h 单格峰值保持不变。
tile atlas、shadow worker、temporal adapter 合计九项测试通过。
同类检查：旧动态 tiling 路径已经在实际重叠域做 cosine 融合，
本次不改；正式固定 atlas 路径仍用 v1，等待候选验收再升级版本。
# 三步实验收口（2026-09-08）

三项建议的工程实验和检查已完成；**不等于预报效果已验收或已上线**。

| 步骤 | 已执行 | 决策 |
| --- | --- | --- |
| 1 输出真实重叠 | v2 逐成员加权，东西重叠 32–43 格；南北受 201 格域高限制为 23 格；比较中心加权 | 保留离线候选，未证明全面精度收益 |
| 2 大输入与随机性 | v3 六个 192×256 输入，16 格内边缘裁剪，三个起报完整推理；检查种子和噪声投影 | 能运行但不推荐上线；未实现地理一致随机扰动 |
| 3 大窗口上复验插帧 | v3 与 v3-rain-midpoint 同一原生输出对照 | 保持线上原插帧，不采用雨强平均候选 |

v3 配置：fujian-nowcastnet-tile-atlas-v3.yaml。x 起点 0/128/245，y 起点 0/9；
输入比 v2 大，同时覆盖/重叠结构改变，因此不能把效果差异全部归因于上下文。
公开源与权重未改，冻结校验通过，矩形输入的运行兼容性通过，不代表训练分布兼容。
105 单批单成员零场探针：输出 1×1×20×192×256 全部有限；本进程 PyTorch
峰值 allocated 421 MiB、reserved 466 MiB（不含其他进程和完整业务链路开销）。
三个真实起报均完成，没有停止其他 GPU 服务。

随机一致性检查：official_backend.infer_batch 每成员重设种子；batch=1 时，
相同尺寸瓦片重用局地 noise，而不是全球坐标上的同一 noise。128 格瓦片的
4×4 低分辨率噪声，在横向错开 64 格后对应的重叠切片并不相同。
公开 Net.forward 还使用固定 4×4×8×8 的投影重排。故“种子相同”不等于
“跨瓦片地理一致”，batch=4 也不能直接套用本轮 batch=1 结论。
本轮检查已完成，但未修改冻结模型噪声路径；地理一致扰动需独立模型兼容性
设计与版本，不作已修复声明。

# 第三轮：单独隔离时间插值的减弱贡献

105 离线完成北京时间 16:00、16:30、17:00 的对照。新增显式实验选项
midpoint_space=rain；默认仍为 log，线上 worker 未启用候选。
两种方案保持同一 v2 切片预测、同一光流、同一 log 空间平移，仅把平移后的
两个锚点从对数平均改为雨强算术平均。40 与 0 mm/h 的零位移回归样本，
原算法中点为 sqrt(41)-1≈5.403，候选为 20；这是可验证的衰减机制，
不是已证明需要删除的算法错误。原生分块仍由空间拼接路径解释。

| +115 指标 | 16:00 原/候选 | 16:30 原/候选 | 17:00 原/候选 |
| --- | --- | --- | --- |
| ≥10 mm/h 格点 | 283 / 408 | 298 / 408 | 411 / 506 |
| MAE mm/h | 2.006 / 2.054 | 2.136 / 2.198 | 无实况 |
| CSI10 | 0.0252 / 0.0287 | 0.00557 / 0.00910 | 无实况 |

指标仍用所有方案共同有效区；16:00、16:30 再与实况有效区相交。
三个起报实际数值数组检查：候选与 v2 的全部原生帧逐格完全一致，全部时效的
缺测掩码完全一致。CSI10 提升但 MAE 增加，不能据单日两个验证时次宣称更优；
因此不推广候选、不覆盖已有产品。此轮尚未验证更大切片上下文，也没有改变
空间重采样方式；更大切片是下一项独立实验。

输出在 runtime/experiments/nowcastnet-temporal-20260908-{0800,0830,0900}，
沿用 compare_nowcastnet_overlap.py 命令和环境。报告记录 temporal_derivation，
候选使用独立 experimental-v1 标识，原默认标识不变。
12 项相关测试通过（包括两种模式下的缺测测试）；新增候选测试先在缺少
midpoint_space 实现时失败，再通过。代码未提交/push，服务未重启。
同类检查：中点计算仅在 temporal_adapter.py；shadow worker 仍校验原
derivation 配置并使用默认 log，不会自动启用实验选项。

# 第二轮：固定切片预测，只改变融合权重

本轮在 105 离线验证北京时间 16:00、16:30、17:00 三个起报，未发布产品，
未重启服务。v2-sharp 将空间权重平方后归一化，优先采用更靠近切片中心的
预测；不按雨量择大，不增幅，不改变默认 worker 的融合策略。
v2 与 v2-sharp 复用同一份切片预测，报告中的 tile_prediction_sha256 相同。
比较脚本新增 paired_metrics，所有方案按同一有效区域比较；有实况时再取
实况有效区域交集。17:00 起报的 +110/+115/+120 没有实况，不计算精度。

这些是同一天相邻起报、并非独立天气过程；不能作模型总体能力验收。
全网格梯度也已记录，避免只看旧接缝；仍需补充新切片边缘的专门诊断。

后续优先检查更大输入上下文、相邻切片预测位置差异，以及 +115 时间插值的
独立衰减贡献；不继续盲调权重或人工增雨。更大上下文需要先验证公开模型的
输入尺寸兼容性和显存，再进行单变量对照。
