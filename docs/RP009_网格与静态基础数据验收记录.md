## 2. 统一业务网格

配置：`configs/grids/fuzhou-0p01deg-v1.yaml`

```text
grid_id: fuzhou_118_123_25_27_0p01deg_v1
CRS: EPSG:4326
registration: point
lon: 118.00 ... 123.00 / 0.01° / 501
lat:  25.00 ...  27.00 / 0.01° / 201
dimension_order: lat × lon
coordinate_dtype: float32
coordinate_sha256: 111a8653e5f227153216d100b81e4214bd2dbf3d134ee07641969be884a3d658
pixel_edge_bounds: [117.995, 24.995, 123.005, 27.005]
```

坐标起止点计入格点数，与 `test_datas/26082508.003.nc` 的二维 `lat × lon`
坐标习惯相同。样例文件仅作为维度、坐标方向和逐时次二维文件的兼容参考；其
缺少变量级 `_FillValue` 和完整 CF 元数据，因此没有原样复制其元数据缺陷。

测试服务器实测的 WGS84 geodesic 网格尺度：

```text
grid_metric_version: wgs84-geod-grid-metric-v1
x spacing at 26°N: 1001.391021 m
y spacing at 26°N: 1107.879925 m
```

## 3. 静态源数据

配置：`configs/ancillary/fujian-taiwan-v1.yaml`

```text
domain_id: fujian-taiwan-114-127-21-29-v1
bounds: [114, 21, 127, 29]
DEM: Copernicus DEM GLO-30 DGED
DEM horizontal CRS: EPSG:4326
DEM vertical CRS: EPSG:3855 / EGM2008
coastline: GSHHG 2.3.7 full + high, shoreline level 1
```

运行位置：

```text
<remote-project-dir>/runtime/ancillary/assets
```

验收结果：

| 项目 | 结果 |
|---|---:|
| 理论 1° DEM 槽位 | 104 |
| Copernicus 实际发布 GeoTIFF | 62 |
| 源端未发布槽位 | 42 |
| DEM 规格 | `3600 × 3600`, `float32`, EPSG:4326 |
| GSHHG full L1 要素数 | 179,837 |
| GSHHG high L1 要素数 | 144,749 |
| 清单源文件总字节 | 1,952,087,264 |
| 运行目录占用 | 约 2.1 GB |

Copernicus 不发布纯海洋瓦片。42 个源端空槽位均使用 GSHHG high L1 复核；其中
`N25/E120` 存在约 `0.057791 km²` 的极小陆地碎片，低于冻结的每槽位
`0.1 km²` 上限，其余空槽位不含 GSHHG 陆地。任何未来超过该上限的源端缺瓦片
必须验收失败。

## 4. 可复现命令

```bash
make ancillary-plan
make ancillary-download ANCILLARY_ROOT=runtime/ancillary/assets ANCILLARY_WORKERS=6
make ancillary-verify ANCILLARY_ROOT=runtime/ancillary/assets
make test-radar-config
make test-contracts
make test-grid
make test-ancillary
```

下载支持 `.part` 断点续传、进程独占锁、源端 Content-Length、逐文件 SHA-256、
GeoTIFF CRS/范围/形状验证和 GSHHG 陆地覆盖复核。测试服务器的代理
`http://127.0.0.1:7897` 可通过下载命令的 `--proxy` 参数使用。

## 5. 未解除的业务门槛

- Z9598 天线高度的垂直基准仍未确认。DEM 使用 EGM2008；基准一致前，波束高度
  和遮挡率只能用于工程验证，不能作为业务验收。
- 静态杂波图仍需长期晴空雷达基数据按雷达和仰角统计。
- 原始 GSHHG 仅是海岸线源数据；RP-008 需要的海杂波/AP 概率资产仍需后续派生
  和案例标定。
- 应用降雨 NetCDF 的业务 `ElementCode` 命名仍需在产品阶段与下游确认。
