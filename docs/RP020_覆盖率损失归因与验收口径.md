# RP-020 覆盖率损失归因与验收口径

## 目标

RP-018 在固定实况域上保留了 `forecast_to_truth_coverage >= 0.95` 的严格门槛，
但该指标没有区分两类性质不同的损失：

1. 降水场随估计运动平流后，反向轨迹落到有限网格之外；
2. 反向轨迹仍在网格内，但源数据缺测或算法未产生有限值。

RP-020 只补充覆盖率归因证据，不修改 RP-018 的冻结配置、原始覆盖率、FSS、
基线或通过状态。

## 分解定义

对每个模型、起报、预报时效，先用与该模型相同的运动场和外推器平流一个全 1
网格，得到不受源数据缺测影响的几何有效域 `D`。在固定实况有效域 `T` 内：

- `C = T ∩ forecast_valid`：模型实际有效区域；
- `B = T ∩ ¬D`：平流轨迹越出有限网格的边界损失；
- `I = T ∩ D ∩ ¬forecast_valid`：域内缺测或算法无效损失。

记录以下字段：

- `forecast_to_truth_coverage = |C| / |T|`；
- `advection_domain_to_truth_coverage = |T ∩ D| / |T|`；
- `advection_boundary_loss_ratio = |B| / |T|`；
- `interior_missing_loss_ratio = |I| / |T|`；
- `boundary_adjusted_forecast_to_truth_coverage = |C| / |T ∩ D|`；
- `coverage_decomposition_closure_error = |(|C| + |B| + |I|) / |T| - 1|`。

实现强制要求 `forecast_valid ⊆ D`，并要求闭合误差为 0。若没有显式几何域，
归因字段保持不可用，不能臆测损失来源。

## 模型处理

- pySTEPS-LK：用 LK 稠密运动场平流全 1 网格；
- 基于 LK 的整场平移：用 LK 导出的全场平移量平流全 1 网格；
- 独立相位相关平移：用独立位移和相同 `ndimage.shift` 参数平流全 1 网格；
- 持续性：几何域为完整网格，源缺测全部归入域内损失；
- 原生 10 分钟 LK：使用自身运动场独立计算几何域。

累积降水使用所含全部时效几何域的交集，保持与累积有效掩膜相同的时间语义。

## 验收约束

1. 原 RP-018 `skill_not_demonstrated` 结论保持不变；
2. 不降低 95% 原始覆盖率门槛，不删除独立相位相关基线；
3. 所有模型必须有覆盖率归因，所有切片闭合误差必须为 0；
4. 先对既有 53 个起报全量归因，再决定未来门槛是否同时包含“原始覆盖率”和
   “排除边界后的域内覆盖率”；
5. 后续留出月份不得用于反向选择运动参数或验收阈值。

## 代表性真实数据冒烟

105 服务器使用 `midwest_convection_20210810` 首个起报完成冒烟：

- LK 12 个时效全部有归因；
- 原始最低覆盖率 `0.965412`，平均覆盖率 `0.978958`；
- 平均边界损失 `0.021042`，最大边界损失 `0.034588`；
- 域内缺测切片数 `0`，最大域内缺测率 `0`；
- 排除边界后的最低覆盖率 `1.0`；
- 最大闭合误差 `0`。

这只证明归因方法在一个真实 MRMS 起报上闭合且可解释，不代替 53 起报全量结论。

## 全量验收

105 服务器完成 `rp020-coverage-full-v1` 全量归因，报告与旧
`rp018-full-v1` 隔离保存：

- 53/53 个起报完成，0 失败；
- 每个模型归因 636 个唯一时效切片；
- LK 原始平均覆盖率 `0.965082`，最低 `0.683052`，121 个切片低于原 95% 门槛；
- LK 平均边界损失 `0.034918`，最大边界损失 `0.316948`；
- LK 域内缺测切片数 `0`，最大域内缺测率 `0`；
- LK 排除边界后的最低覆盖率 `1.0`；
- 持续性、LK 整场平移、独立相位相关和原生 10 分钟 LK 的域内缺测也全部为 0；
- 所有模型最大闭合误差均为 `0`；
- 全量运行 P50/P95/最大耗时为 `12002/12617/12835 ms`，峰值 RSS
  P50/P95/最大为 `896999424/1029050368/1067155456 bytes`。

## 结论与后续冻结口径

本轮数据中的低覆盖全部来自有限网格上的平流边界，没有发现源数据域内缺测或
算法数值无效。固定实况域 FSS 已经把边界无预报当作漏报计分；若再用原始覆盖率
作为数据完整性硬门槛，会对同一边界效应重复处罚。

因此后续留出集采用以下冻结口径：

1. FSS、CSI、MAE 等技巧评分继续使用固定实况域，边界无预报继续按无预报处理；
2. 数据完整性门槛使用
   `boundary_adjusted_forecast_to_truth_coverage >= 0.95`；
3. 原始覆盖率和边界损失继续逐时效报告，但不单独决定数据完整性是否通过；
4. 任一域内缺测、归因缺失、有效区越出几何域或闭合误差非零均视为实现问题；
5. RP-018 的冻结 `skill_not_demonstrated` 不追溯改写；即使覆盖归因门槛通过，
   后续仍须独立通过持续性、LK 整场平移和相位相关基线的技巧门槛。

业务部署还应通过扩大计算域或保留输出裁剪缓冲区减少边界损失；这属于产品域设计，
不能通过把缺测填零来掩盖。
