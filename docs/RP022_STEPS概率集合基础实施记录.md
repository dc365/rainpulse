# RP-022：pySTEPS-STEPS 概率集合基础实施记录

## 1. 结论

RP-022 已建立不影响一期 pySTEPS-LK 默认发布路径的离线概率集合基础：

- 冻结 pySTEPS 1.21.5、12 个集合成员、6 层尺度分解和固定随机种子；
- 启用非参数降水噪声、BPS 速度扰动、增量降水掩膜和 CDF 概率匹配；
- 新增 `ForecastOutput contract_version=1.2` 多成员 Zarr 实现；
- 输出逐成员雨强、逐成员有效域、0–1h/0–2h 累积、超阈值概率及
  P10/P50/P90；
- 新增 Brier Score、CRPS、可靠性分箱、集合均值 RMSE 和集合离散度检验；
- 现有 `ForecastOutput 1.1`、LK Worker、产品发布和前端默认路径不变。

该结果是工程基础，不是福建业务概率预报验收。概率产品保持
`operational_enabled=false`。

发布。

## 3. 缺测与边界规则

RP-022 没有猜测随机成员的缺测状态：

1. 输入仍有任意缺测时，STEPS fail-closed，不把缺测填为有效无雨；
2. 每个随机成员通过 `member_valid_mask` 保存自己的有限网格支持；
3. 每个成员的雨强和累计量只在自身支持域有效；
4. 公共 `output_valid_mask` 是所有成员有效域的交集；
5. 超阈值概率和分位数只在公共有效域生成；
6. 随机速度扰动造成的成员边界差异不会静默变成零降水。

这使概率评分可以显式报告覆盖率，不会通过丢失难预报区域获得虚假的技巧增益。

## 4. 本轮实现

### 4.1 配置与契约

- 新增 STEPS profile 和 JSON Schema；
- 新增概率产品 profile 和 JSON Schema；
- ForecastOutput 1.2 增加多成员、逐成员有效域、概率和分位数字段；
- 1.1 确定性契约和校验器保持不变。

### 4.2 算法适配器

- 复用已经验证的 LK 运动场，不建立第二套运动估计语义；
- 使用 WGS84 逐纬度网格距离的几何平均值作为 STEPS 标称 km/pixel；
- 支持真实 `pysteps.nowcasts.steps.forecast` 后端和可注入测试后端；
- 无可追踪降水时显式生成零降水集合，并记录
  `no_trackable_precipitation`，不调用随机后端；
- pySTEPS 内部异常转换为结构化 STEPS 失败，由后续编排保持 LK 独立发布，禁止
  伪造随机集合；
- 固定种子、单 Worker 和 NumPy FFT，保证当前工程环境可重复。

### 4.3 概率检验

概率检验固定使用实况与公共预报支持域，计算：

- Brier Score；
- ensemble CRPS；
- 可靠性分箱；
- 集合均值 RMSE；
- 平均集合离散度；
- 有效格点数和覆盖率。

## 5. 本地验收证据

以下测试通过：

```bash
make test-pysteps-steps
uv run --project algorithms pytest \
  algorithms/tests/test_pysteps_steps.py \
  algorithms/tests/test_probabilistic_verification.py \
  contracts/tests/test_contracts.py
```

覆盖内容包括 profile/Schema、固定种子重现、概率与分位数派生、ForecastOutput
1.2 原子 Zarr、缺测拒绝、无雨回退、真实 pySTEPS 1.21.5 后端，以及概率检验的
手算个例。

12 成员、24 时效、64×64 工程小网格真后端冒烟结果：

- 算法耗时约 1.35 秒；
- 最大 RSS 约 264 MiB；
- 输出形状 `12 × 24 × 64 × 64`；
- 无算法回退；
- 快速平移的小网格在远时效公共支持域收缩到零，但逐成员支持仍被保存。

该小网格结果只验证真实库接口、随机路径、掩膜和资源量级；不能外推为福州
501×201 网格的时延、覆盖率或预报技巧结论。

部署服务器使用带空间纹理、平移和强度演变的合成降水场完成福州 501×201
全网格剖析：

- 12 成员、24 时效 STEPS 计算约 13.55 秒；
- ForecastOutput 1.2 校验和压缩构建约 1.78 秒；
- 进程峰值 RSS 约 1.29 GiB；
- Zarr 共 3,814 个对象、约 40.4 MiB；
- +5 分钟公共覆盖率约 97.72%，成员平均覆盖率约 99.15%；
- +120 分钟公共覆盖率约 33.53%，成员平均覆盖率约 76.48%；
- 无模型回退，输出最大雨强约 11.47 mm/h。

该结果解除 12 成员福州网格的基础资源可运行门槛，但仍是合成场，不能作为技巧、
可靠性或业务时延结论。公共域和成员平均域在远时效的差异证明
`member_valid_mask` 不可省略；后续检验必须同时报告概率技巧和覆盖率。
