# RP-023：STEPS 离线产品与资源验收记录

## 1. 结论

RP-023 完成了概率集合从内部 ForecastOutput 到离线应用产品和 GIS 的闭环，且没有
改变现有 LK 确定性业务发布路径：

- 构建 5 个瞬时雨强超阈概率图层和 P10/P50/P90 雨强分位数图层；
- 每个图层提供 T+5 至 T+120 的 24 个透明 PNG 和 24 个 NetCDF；
- 新增文件型只读目录与 Go API，读取前校验相对路径、大小、SHA-256 和文件签名；
- React/OpenLayers 在同一 GIS 和同一五分钟时间轴切换 LK、概率阈值和分位数；
- 所有集合图层明确显示“离线、原始未校准、不进入业务发布”；
- 完成 12/24 成员福州全网格同场资源对比。

首轮离线概率回算继续采用 12 个成员。24 个成员只作为资源对照，不改变 RP-022
冻结配置，也不产生业务发布产品。

## 2. 应用产品契约

独立契约为
`contracts/data/ensemble-application-product-bundle.md`，配置为
`configs/products/rp023-ensemble-application-products-v1.yaml`。

一个 bundle 固定包含 8 个 layer、384 个资产和一个 manifest：

| 图层 | 选择器 | 时效 | 每时效资产 |
|---|---|---:|---|
| probability_exceedance | 严格大于 1/5/10/20/50 mm/h | 24 | PNG + NetCDF |
| quantile | P10/P50/P90 | 24 | PNG + NetCDF |

概率值单位为 `1`，分位数单位为 `mm h-1`。PNG 仅用于 GIS 显示，NetCDF 和源
ForecastOutput 才是科学处理与交换边界。缺测沿用 ForecastOutput 的公共成员交集，
不会转成有效零值。

## 3. 隔离边界

RP-023 没有扩展生产 `product-published` 流程：

1. bundle 写入独立的只读目录；
2. Go API 只读取最新离线 bundle 和其 manifest 已登记资产；
3. 不写产品数据库，不产生产品事件，不改变 forecast run 状态；
4. Web 的 STEPS 模式在无 bundle 时禁用；
5. 有 bundle 时仍固定展示原始未校准和非业务发布状态。

因此部署离线样例不等于发布概率产品。

## 4. 服务器资源对比

使用 `scripts/profile_steps_full_grid.py` 在部署服务器对同一个带空间纹理和平移的
合成场进行剖析。网格为 201×501，时效数为 24，固定单 Worker、6 层尺度分解和
同一随机种子。

| 指标 | 12 成员 | 24 成员 |
|---|---:|---:|
| STEPS 算法耗时 | 12.778 s | 25.217 s |
| ForecastOutput 构建 | 1.657 s | 3.018 s |
| 峰值 RSS | 1.32 GiB | 2.28 GiB |
| ForecastOutput 大小 | 61.3 MiB | 105.1 MiB |
| Zarr 对象数 | 3,814 | 6,214 |
| T+5 公共覆盖 | 98.27% | 98.16% |
| T+120 公共覆盖 | 37.72% | 29.09% |
| T+5 成员平均覆盖 | 98.83% | 98.87% |
| T+120 成员平均覆盖 | 72.82% | 73.99% |
| 模型回退 | 否 | 否 |

12 成员应用产品另耗时 1.431 秒，生成 385 个对象、约 75.3 MiB。

24 成员计算时间接近 12 成员的两倍，峰值内存增加约 73%。长时效成员平均覆盖接近，
但“所有成员都有效”的公共交集随成员增加而收缩。这不是概率技巧变差的证据，而是
当前公共支持策略更保守的直接结果。离线检验必须同时报告公共覆盖与成员平均覆盖。

在福建独立可靠性结果证明 24 成员有明确收益前，首轮回算固定 12 成员，以控制资源
和支持域收缩。后续可以研究按格点有效成员数计算的概率，但必须形成新契约，不能
静默改变当前公共域语义。

## 5. Web 与 API

新增接口：

- `GET /api/v1/ensemble-products/latest`
- `GET /api/v1/ensemble-products/{bundle_id}/assets/{asset_id}`

Web 的模型条显示 LK 确定性和 STEPS 集合；集合模式下可选择五个超阈事件及三个
分位数。地图继续使用现有 EPSG:4326 OpenLayers 栅格、海岸线、底图、经纬网、比例尺
和 5 分钟时间轴。集合模式关闭确定性单点/区域抽屉入口，避免把“技术质量”或 LK 点值
误读成概率。

## 6. 尚未解除的门槛

1. 当前仍是合成全网格资源验收，不代表福建概率技巧；
2. 概率尚未用福建实况做可靠性校准；
3. 新的 MRMS 开发集与未见留出集仍需在运行任何集合回算前冻结；
4. 福建连续五分钟 QC/QPE 输入、雷达配置和多雷达覆盖仍未具备；
5. 70–120 分钟整场平移基线继续保留；
6. 生产产品数据库、事件与自动发布保持不支持。

## 7. 下一步

下一阶段冻结新的 MRMS 概率开发集和独立留出集，确保不复用 RP-021 的
2024-06/2025-01，然后以 12 成员执行离线回算，按 10–60 和 70–120 分钟分别报告
Brier、CRPS、可靠性、覆盖率、集合离散度和三个确定性基线。只有独立结果通过后，
才讨论福建并行灰度和概率校准。
