# RP-025 概率校准与影子运行基础实施记录

日期：2026-08-29
状态：数据无关基础完成；拟合、影子应用和业务发布均未启用

## 1. 目标和边界

福建尚无可用的连续真实雷达/QPE 资料，本阶段不能拟合福建校准器，也不能声明概率业务可用。RP-025 只提前完成不依赖真实样本的校准契约、算法安全边界和影子评估接口，使后续数据到位后不必临时设计数据划分或修改概率语义。

本阶段没有读取、重跑或重新解释 RP-024 的 2022 开发集和 2023 独立留出集；历史已消耗月份仍禁止用于新的独立验收声明。

## 2. 已实现能力

### 2.1 版本化配置与工件

- `configs/calibration/rp025-probability-calibration-v1.yaml` 冻结 ForecastOutput 1.2、严格大于事件、1/5/10/20/50 mm/h 阈值和 5 分钟业务时效；
- 近时效为 5～60 分钟，远时效为 65～120 分钟；
- `ProbabilityCalibrationArtifact 1.0` 记录模型、网格、训练源清单 SHA-256、训练/验证命名空间、个例、时次、曲线和拟合诊断；
- 配置和工件均有 Draft 2020-12 JSON Schema，未知字段或非法业务开关会被拒绝。

### 2.2 校准算法

- 使用 pool-adjacent-violators（PAV）等距回归拟合单调概率映射；
- 在拟合结点之间线性插值，输入超出拟合范围时只裁剪到端点；
- 明确保留缺测，拒绝有效域内的 NaN、无穷值及 `[0,1]` 外概率；
- 拟合前检查有效样本、事件、非事件、概率取值、个例和起报时次数量；
- 每条曲线保存校准前后训练 Brier Score，但训练改进本身不能作为晋级依据。

### 2.3 跨阈值一致性

1/5/10/20/50 mm/h 的原始超越概率必须随阈值升高而不增加；不一致的原始产品直接拒绝。各阈值独立校准后，以递增阈值方向的累计最小值保持：

```text
P(R > 1) ≥ P(R > 5) ≥ P(R > 10) ≥ P(R > 20) ≥ P(R > 50)
```

该投影只作用于校准概率旁路，不修改集合成员、P10/P50/P90、原始概率或确定性 LK 产品。

### 2.4 防泄漏与影子评估

- 拟合数据角色固定为 `calibration_training`，预留数据为 `calibration_validation`；
- 训练和验证命名空间、个例 ID 必须完全不相交；
- 拟合工件声明预留验证集在拟合时未被使用；
- 影子评估再次检查评估数据与训练数据不重叠；
- 影子结果只报告原始/校准 Brier Score 和相对技巧，固定返回 `operational_eligible=false` 与 `blocked_pending_fujian_acceptance`。

## 3. 默认关闭状态

当前配置强制：

| 开关 | 值 |
|---|---|
| 校准工件拟合 | `false` |
| 影子应用 | `false` |
| 校准概率产品发布 | `false` |
| 必须通过的门槛 | `independent_fujian_calibration_acceptance_required` |

即使使用合成数据生成了格式正确的工件，也不能改变这些开关。确定性 LK 和未经校准、明确标注为离线的原始集合概率继续保留。

## 4. 验证

新增测试覆盖：

1. 配置和工件 Schema；
2. 合成可靠性样本上的单调 PAV 拟合与 Brier 改进；
3. 样本不足和非法概率拒绝；
4. 有效/缺测语义保持；
5. 跨阈值超越概率一致性；
6. 训练/验证泄漏拒绝；
7. 影子评分不自动晋级。

复现命令：

```bash
make test-probability-calibration
```

## 6. 真实数据到位后的执行顺序

1. 先验收福建极坐标质控、Hybrid Scan、多雷达 QI 拼图和 QPE；
2. 冻结连续五分钟校准训练集和完全独立的验证集，记录源清单哈希；
3. 根据真实发生率重新审查本配置的样本数量下限，并冻结可靠性、分辨率、ROC/经济价值和极端降水门槛；
4. 拟合每个时效段/阈值曲线，在预留验证集上仅执行一次正式验收；
5. 先开启不发布产品的影子旁路，验证延迟、资源、缺测、回退和原始概率可追溯性；
6. 经评审后才允许生成独立版本的校准概率产品，且增强链路失败不能阻塞 LK。
