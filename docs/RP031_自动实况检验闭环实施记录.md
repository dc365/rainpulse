# RP-031 自动实况检验闭环实施记录

状态：代码与契约已完成；等待福建连续五分钟 RadarAnalysis 进行业务数据验收

## 1. 目标与边界

RP-031 对齐 v1.1 中“产品发布后自动实况检验”的主链。每个确定性
`ForecastOutput 1.1` 发布后，控制面等待同网格、同时间轴的未来 24 个五分钟
`RadarAnalysis 1.2` 到齐，再触发一次不可变检验任务。

本阶段只检验当前业务确定性链 `pySTEPS-LK` 及其两个随产品共同提交的基线：

- LK；
- 持续性；
- 整场平移。

STEPS 概率集合和 NowcastNet 继续保留在既有离线验证路径，不借 RP-031 自动进入业务
发布。完成一次检验只表示结果已生成，不表示技巧通过或模型获准晋级。

## 2. 自动调度

预测运行状态链增加实际执行语义：

`PUBLISHED → VERIFYING → VERIFIED`

调度器只接受以下输入：

- 已成功生成应用产品的 PUBLISHED 运行；
- 已提交且带 SHA-256 的 ForecastOutput；
- 起报后 +5 至 +120 分钟共 24 个严格连续真值帧；
- 真值与预报使用同一 `grid_id`；
- 真值对象已由 QPE 完成事件登记 URI、SHA-256 和大小。

真值不足时不创建部分评分，也不把缺帧当无雨；API 返回 `waiting_truth`、已到帧数和
缺失时效。默认自动规划回看六小时，为未来两小时真值及处理延迟留出余量。

## 3. 检验计算

冻结配置为 `rp031-operational-deterministic-v1`：

- 雨强阈值：0.1、1、5、10、20、50 mm/h；
- FSS 领域：1、5、10、20、40 km；
- 累计窗口：0–60、0–120 分钟；
- 累计阈值：1、5、10、25、50 mm；
- 有效域：实况与全部比较模型的公共有效域；
- 晋级资格：关闭。

FSS 的 km 领域会依据实际经纬网格和 WGS84 测地距离换算为计算窗口，不再把像素数
当业务尺度。缺测保持缺测，无雨保持有效的 0，低质量真值通过 RadarAnalysis 的有效
掩膜进入公共域判断。

每次成功任务生成一个内容寻址、不可变的结果包：

- `summary.json`；
- `metrics.json`，共 2160 行逐时效确定性指标；
- `accumulation-metrics.json`，共 150 行累计量指标。

Web 首页只展示 5–60 分钟、5 mm/h、10 km 的 LK FSS 摘要，并明确该值不是业务
放行结论。完整逐切片数据留在对象存储，不写入 PostgreSQL 大表；数据库只保存有界
摘要和结果对象身份。

## 4. 控制面与 Web

`GET /api/v1/verification/summary?run_id=...` 现在返回：

- `pending_forecast`：产品尚未发布；
- `waiting_truth`：等待未来真值；
- `running`：评分正在执行；
- `succeeded`：不可变结果已登记；
- `failed`：评分任务失败。

短临 GIS 页的运行状态浮层同步显示实况检验阶段。完成后展示 LK 头部 FSS；等待时
展示真值帧进度。离线“算法验证”工作区仍用于 MRMS/概率集合/NowcastNet 的独立工程
证据，两者不混用。

## 5. 兼容与迁移

## 6. 当前验证

本地通过：

- 事件 JSON Schema、OpenAPI 生成一致性和冻结配置 Schema；
- Python 对象 SHA 校验、24 帧身份/时间/网格校验、缺测保持和已知 FSS 算例；
- Go 调度输入约束、事务落库、查询接口与状态映射；
- React 状态展示、FSS 摘要、完整 Web 测试与生产构建；
- Go vet、Ruff 和生成文件漂移检查。

MRMS 仍用于检验算法的工程实现证据；当前没有福建真实连续 RadarAnalysis，因此不能
声称 RP-031 已完成福建业务技巧验收，也不能据此打开概率产品或 NowcastNet 业务发布。

## 7. 福建数据到位后的验收

1. 先完成真实极坐标质控、Hybrid Scan、多雷达 QI 拼图和 QPE；
2. 选普通降雨、强对流、台风及弱回波/缺测过程，连续运行完整发布与自动检验链；
