# RP-033 超阈值概率空间地图实施记录

## 目标

在 RP-032 集合均值雨强空间证据之外，增加真正的阈值超越概率 GIS：
同一案例、起报、时效和雨强阈值下，并排比较 MRMS 超阈实况、NowcastNet
原始集合概率和 STEPS 原始集合概率。

## 已实施

- 固定阈值：1、5、10、20、50 mm/h；
- 概率定义：有效集合成员中超过阈值的原始相对频率，未做校准；
- 有效域：预报层要求该集合全部冻结成员有效，缺测保持透明；
- 产品语义：实况层仅取 0% / 100%，集合层取 0–100%；
- 地图：EPSG:4326，经纬度格点，三图共享视野、时效和阈值；
- 契约/API：使用独立 `probability-maps` 目录、独立清单、独立资源端点；
- Web：可在“超阈概率”和“集合均值雨强”之间切换；
- 边界：`operational_eligible=false`、`product_publication_enabled=false`，不改变
  RP-026 冻结评分，不替代 RP-032 雨强地图。

## 验收口径

本轮只能证明 MRMS 离线集合结果具备可审阅的空间概率表达。原始概率尚未校准，
不能直接发布；MRMS 结果也不能替代福建雷达基数据质控、Hybrid Scan、QI 拼图、
QPE 标定和本地业务检验。

## 105 服务器验收

- 代码版本：`d29cbee`，API `system/status` 返回 `ready`；
- 完整回算：冻结 RP-026 独立留出集 50/50 个起报成功，0 个失败；
- 概率产品：50 个 bundle、9,000 个 PNG 图层；原 RP-032 雨强产品仍为
  50 个 bundle、3,600 个 PNG 图层，合计 12,600 个资源、约 132 MiB；
- 完整性：发布前逐资源核验文件大小和 SHA-256，随后原子切换到控制面目录；
- 回归边界：配置、样本选择、评分行数、覆盖率、可靠性和分时效汇总均与冻结的
  `holdout-map-v1` 一致，说明新增空间表达未改变既有评分；
- 运行性能：概率地图生成耗时 P50 1.323 s、P95 2.666 s、最大 3.253 s；
  完整单起报流程 P50 41.228 s、P95 46.935 s、最大 49.554 s；
- API 抽查：5 mm/h、+10 分钟湿案例的 MRMS、NowcastNet、STEPS 三个资源均返回
  `image/png`，且响应内容 SHA-256 与清单一致；原雨强地图端点仍返回 6 个图层；
- Web 验收：桌面端三幅 GIS 同屏，移动端以图层页签切换；概率/雨强模式、
  1/5/10/20/50 mm/h 阈值和时效联动正常。Playwright 检查控制台 0 错误、
  0 警告，关键请求均为 200。

因此 RP-033 的工程实现和 MRMS 服务器验收已完成；其业务结论仍保持“原始、
未校准、离线验证、禁止发布”，待福建真实雷达数据到位后再做本地校准和业务验收。
