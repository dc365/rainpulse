# RP-038 统一分析周期与产品工作台实施记录

更新日期：2026-08-31

## 结论

RP-038 继续使用现有“短临预报”页面，不增加菜单、页面或独立入口。页面的核心对象从
“分析条目或预报条目”调整为“分析周期”：任一历史周期都等价于回到该时刻的实时工作台，
周期内固定保留雷达实况、LK 确定性和 STEPS 集合三个产品位。

产品是否缺失只改变按钮的可用状态和原因，不改变按钮位置、时间选择方式或时间轴语义。
这避免了历史分析时模型栏消失、历史预报与雷达分析需要两套交互的问题。

## 冻结交互语义

1. 顶部时间框只选择分析周期；实时跟随是最新正式周期的动态指针，历史选择会固定周期。
2. 相同 `grid_id + UTC 分析时间` 的雷达分析、正式预报和 STEPS 集合包合并为一个周期。
3. 周期内始终显示三个产品位：
   - 雷达实况：质控、拼图和 QPE 后的 T0 分析；
   - LK 确定性：同周期起报的 0–120 分钟确定性产品；
   - STEPS 集合：同周期起报的概率和分位数产品。
4. 缺少产品时入口保持可见并禁用，提示“该周期未生成”，不得借用其他周期的结果。
5. 时间轴只表达当前周期和当前产品的有效时间：雷达实况为单帧 T0，LK/STEPS 为
   T+5 到 T+120；切换历史周期只能通过顶部周期框，不再把历史分析目录混入有效时间轴。

## API 与数据目录

- `GET /api/v1/ensemble-products/cycles` 返回轻量级 STEPS 历史周期目录；
- `GET /api/v1/ensemble-products/by-cycle?issue_time=...&grid_id=...` 精确读取一个周期的
  集合产品包；
- 集合产品文件存储按 `issue_time + grid_id` 匹配，存在多个匹配包时选取最新创建版本；
- `GET /api/v1/ensemble-products/latest` 保留兼容，但 Web 不再用它代替历史周期查询。

## 真实数据边界

- 2026-08-28 福建雷达回放周期当前只有雷达 QPE，因此雷达实况可用，LK/STEPS 明确禁用；
- 2026-08-25 正式周期当前有 LK 产品，雷达实况和 STEPS 未生成；
- 上述差异是数据链与门控的真实结果，不由界面补造产品；
- 后续任一周期实际生成 LK 或 STEPS 后，会自动在相同产品位和时间轴中恢复。
