# RP-040 福建径向干扰质控收敛与历史周期重建记录

## 结论

RP-040 修复了 2026-08-28 福建历史雷达中 Z9591 长距离径向干扰逃逸到拼图和 QPE 的问题。生产检测器已对 110 个 Z9591 归档体扫完成只读重放，选出 44 个受影响扫描并重建了它们的质控、单站网格、四站拼图和 QPE。受影响的 28 个历史起报周期现均有修正后的 LK 和 STEPS 产品，通过现有统一时间与产品界面提供，没有新增页面或导航入口。

本阶段是工程质控收敛和代表周期回放，不是正式业务准入。雷达配置仍为 draft，当前规则尚未用晴空、强对流、台风、海杂波和山地遮挡等独立样本完成业务阈值验收。

## 根因

原径向干扰概率主要比较相邻方位。当多条相邻射线同时被连续干扰污染时，扇区内部射线彼此相似，邻域差异反而不显著，因此宽扇形内部可能逃逸。

第一轮长距离饱和特征已识别 72 条异常射线并消除大部分宽扇形，但实际渲染仍残留一条窄射线。对 Z9591 最低仰角逐射线复核后，定位到方位角 63.52° 的第 267 条射线：有效库数 1,835，45 dBZ 以上比例为 0.667，距离增长 32.5 dB，峰值 66.5 dBZ。它具备明显的长距离增强特征，但比第一版 0.70 的高值比例门槛低约 3.3 个百分点。

## 修复与版本链

最终规则在保留邻域检测的基础上，增加保守的长距离连续饱和判据：

```text
连续高反射率库数 >= 400
且 45 dBZ 以上库点比例 >= 0.60
且近远距离反射率增长 >= 12 dB
```

三个条件必须同时成立，降低把普通强对流核心误判为径向干扰的风险。对应不可变版本为：

- 极坐标质控：`rp040-fujian-radial-v3`，流水线 `rp040-fujian-radial-1.2.0`；
- 单站网格：`rp040-hybrid-qc-v3`，算法 `hybrid-scan-1.2.2-rp040-qc`；
- 四站拼图：`rp040-fujian-four-radar-qc-v2`，算法 `qi-mosaic-1.3.1-rp040-qc`；
- 历史输入：`rp040-historical-replay-v3`，构建器 `nowcast-input-builder-1.1.1`。

旧版本工件不覆盖、不删除。为了让已经完成单站网格的历史扫描能够进入新的质控版本，控制面和持久层均新增 `RADAR_GRID_READY -> QC_RUNNING` 的版本化重处理路径；新作业继续用版本和工作流身份隔离，失败不会污染旧的可用产品。

## 全日影响审计与选择性重建

旧质控摘要只记录当时版本的判定，无法反映 RP-040 新增的长距离饱和特征。因此新增了只读、可断点续跑的扫描审计器，它直接读取已验证的 NormalizedRadarVolume，调用与生产质控相同的检测函数，不依赖旧摘要做判断。

- 审计范围：Z9591 共 110 个扫描，完成 110/110，错误 0；
- 受影响扫描：44 个，审计特征命中 1,856 条射线；
- 完整质控结果：44 个扫描全部进入 `rp040-fujian-radial-v3`，结合相邻射线规则共标记 1,880 条干扰射线；
- 单站网格：44/44 进入 `RADAR_GRID_READY`，有效覆盖率为 0.3727–0.5034；
- 依赖分析：新建 34 个，加上已修正的 06:30 共 35 个，全部使用 Z9591、Z9593、Z9598、Z9599 四站；
- 分析质量：覆盖率 0.4103–0.5107，平均 QI 0.4153–0.5399，QPE 和诊断均成功 35/35。

对 35 个有旧版本对照的分析周期，平均雨强的周期均值从 8.754 降到 2.271 mm/h，P95 的周期均值从 47.570 降到 7.908 mm/h。02:40、02:45 和 02:50 UTC 是审计射线数最多的连续三帧，实际 `grid-rate-qpe` PNG 已检查：原问题中东侧红紫扇区未进入新 QPE。

## 测试与回归保护

新增的真实边界回归测试固定“两-thirds 高值、长距离增长”的残余射线，修改前失败、修改后通过。审计器回归进一步保证只读选片与实际 QC 共用同一检测函数；修改前因审计入口不存在而失败，修改后质控与配置测试共 35 项通过。控制面的编排、持久化和命令测试通过，并覆盖“已完成网格可以创建新版本 QC、原始接收状态不能越级”的双向状态约束。

105 服务器没有 Go 工具链，因此控制面二进制在本地交叉编译为 Linux amd64 后复制到构建目录，再重建并替换编排容器。Python 质控镜像以及 QC、Grid、Mosaic、NowcastInput 等相关服务均在 105 重新构建或重建。

## 边界与下一步

本次已完成基于 RP-040 生产检测器的全量扫描审计和选择性链路重建，不是将当天所有历史产品无差别重跑。对于审计未命中且不依赖命中扫描的周期，旧版本仍保留为权威工程回放结果；不应把“28 个受影响周期已修正”误读为当天所有原始回波都已完成业务质控验收。

正式业务启用前仍需准备静态杂波图、海杂波/异常传播概率、经确认的雷达标定与站点元数据，以及独立晴空、普通降水、强对流、台风和山地遮挡案例。阈值应在这些冻结样本上评估误报和漏报，不能继续针对 06:30 UTC 个例调参。
