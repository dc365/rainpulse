# RP-040 福建径向干扰质控收敛与历史周期重建记录

## 结论

RP-040 修复了 2026-08-28 06:30 UTC 福建四站历史雷达实况中，Z9591 东侧连续高反射率扇形和一条残余窄射线未被极坐标质控剔除的问题。修复后的 06:30 UTC 分析继续使用 Z9591、Z9593、Z9598、Z9599 四站，实际诊断 PNG 中不再出现截图所示的放射状红色伪回波；同一历史起报周期的 QPE、LK 和 STEPS 已重新生成并通过现有统一时间与产品界面提供。

本阶段是工程质控收敛和代表周期回放，不是正式业务准入。雷达配置仍为 draft，当前规则尚未用晴空、强对流、台风、海杂波和山地遮挡等独立样本完成业务阈值验收。

## 根因

原径向干扰概率主要比较相邻方位。当多条相邻射线同时被连续干扰污染时，扇区内部射线彼此相似，邻域差异反而不显著，因此宽扇形内部可能逃逸。

第一轮长距离饱和特征已识别 72 条异常射线并消除大部分宽扇形，但实际渲染仍残留一条窄射线。对 Z9591 最低仰角逐射线复核后，定位到方位角 63.52° 的第 267 条射线：有效库数 1,835，45 dBZ 以上比例为 0.667，距离增长 32.5 dB，峰值 66.5 dBZ。它具备明显的长距离增强特征，但比第一版 0.70 的高值比例门槛低约 3.3 个百分点。

## 修复与版本链

最终规则在保留邻域检测的基础上，增加保守的长距离连续饱和判据：

```text
连续高反射率库数 >= 400
且 45 dBZ 以上库点比例 >= 0.60
且近远距离反射率增长 >= 12 dB
```

三个条件必须同时成立，降低把普通强对流核心误判为径向干扰的风险。对应不可变版本为：

- 极坐标质控：`rp040-fujian-radial-v3`，流水线 `rp040-fujian-radial-1.2.0`；
- 单站网格：`rp040-hybrid-qc-v3`，算法 `hybrid-scan-1.2.2-rp040-qc`；
- 四站拼图：`rp040-fujian-four-radar-qc-v2`，算法 `qi-mosaic-1.3.1-rp040-qc`；
- 历史输入：`rp040-historical-replay-v3`，构建器 `nowcast-input-builder-1.1.1`。

旧版本工件不覆盖、不删除。为了让已经完成单站网格的历史扫描能够进入新的质控版本，控制面和持久层均新增 `RADAR_GRID_READY -> QC_RUNNING` 的版本化重处理路径；新作业继续用版本和工作流身份隔离，失败不会污染旧的可用产品。

## 边界与下一步

本次只对截图对应的 06:30 UTC 代表周期完成了 v3 全链重建，不能据此宣称 2026-08-28 的全部 38 个历史预报周期都已换成 v3。下一步应先用旧诊断和极坐标特征筛出受径向干扰影响的 Z9591 扫描，再仅重算受影响的 QC、网格、拼图、QPE 和历史预报周期，避免无差别重跑。

正式业务启用前仍需准备静态杂波图、海杂波/异常传播概率、经确认的雷达标定与站点元数据，以及独立晴空、普通降水、强对流、台风和山地遮挡案例。阈值应在这些冻结样本上评估误报和漏报，不能继续针对 06:30 UTC 个例调参。
