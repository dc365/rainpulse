# RP-042 福建雷达质控多证据与验收框架实施记录

日期：2026-09-01
部署回放：2026-09-02

## 1. 结论

RP-042 在不改变 RP-040 生产质控结果的前提下，先实现当前 2026-08-28
福建四站历史数据能够支持的质控能力：径向干扰形态分类、双偏振模糊诊断、
同体扫垂直连续性诊断，以及可缺项、不可伪造结果的质控验收统计框架。

新配置 `rp042-fujian-evidence-v1` 中，新增形态、双偏振和垂直连续性均为
`diagnostic_only`。RP-040 已判定的长距离径向干扰继续按原规则整条有效射线
硬标志；新增证据只写入诊断字段和摘要，不参与当前质量指数、低质量门或 QPE。
因此本版本是下一轮质控阈值冻结前的证据采集版本，已部署到 105
`realtime_shadow` 链路并完成历史回放，但不是生产配置切换或业务验收。

## 2. 现有数据盘点

服务器归一化归档中，2026-08-28 共 452 个体扫：Z9591 110 个、Z9593
112 个、Z9598 112 个、Z9599 118 个。四站体扫均声明 DBZH、ZDR、RHOHV、
PHIDP、VR、SW、SNR，并包含 9 个反射率仰角层。因此当前数据可支持：

- 单体扫射线形态与污染面积统计；
- DBZH、RHOHV、ZDR、PHIDP、SNR 的模糊气象回波概率诊断；
- 相邻仰角之间的垂直一致性诊断；
- QPE 率场的均值、P95 和最大值统计；
- 在未来补入人工标注、气象回波真值和雨量站配对数据后，直接计算完整验收指标。

当前归档不能单独支撑：

- 静态杂波图：缺少跨多日、跨天气的晴空样本；
- 海杂波与异常传播分类：缺少冻结海岸线资产和人工标注案例；
- 时间连续性：当前 QC 作业输入契约是单体扫，尚未冻结前后体扫上下文；
- 邻雷达一致性：需要先统一极坐标到共同空间并定义重叠区、时差和质量门；
- 异常回波精确率/召回率和真实降水保留率：缺少逐门真值标签；
- 雨量站偏差和相关系数：缺少同时间窗、完成站点质控的雨量站配对数据。

这些项目在验收报告中返回 `skipped` 和具体原因，不以零值、代理值或空样本冒充
验收结果。

## 3. 已实施能力

### 3.1 径向干扰形态证据

`INTERFERENCE_TYPE` 使用 `uint8` 保存逐门类型：0 无、1 窄径向、2 宽扇区、
3 断续径向、4 短距离径向、5 反向尖峰。检测器在 RP-040 的相邻方位基线和
长距离饱和规则之上，增加连续分段、分段数量、最大距离和沿程反向突降证据。

`QCRadarVolume` 继续兼容旧产物，并可选写入：

- `P_METEO_DUAL_POL`；
- `P_VERTICAL_CONSISTENCY`；
- `INTERFERENCE_TYPE`。

摘要新增各类型射线数、各类型门数、硬标志门数和按极坐标门面积计算的污染面积。
审计器新增 `--audit-mode evidence`，可只读重放归一化体扫并输出这些证据。

### 3.2 双偏振模糊诊断

模糊诊断组合 RHOHV、SNR、ZDR 和相邻距离门 PHIDP 变化，缺测分量会被跳过并
按可用权重归一化。它当前只生成 `P_METEO_DUAL_POL`，不覆盖 RP-040 的
`QI_METEO`。

实测表明 Z9591 径向干扰门可能同时具有高 RHOHV、高 SNR 和看似连续的双偏振量，
仅用双偏振阈值会把部分干扰误判为降水。因此当前必须继续以径向空间形态作为主证据，
双偏振只用于后续人工复核和联合阈值标定。

### 3.3 同体扫垂直一致性诊断

每个仰角与下一个不同的更高仰角按最近方位、最近距离门对齐，在 150 km 范围内
比较 DBZH 支持度，生成 `P_VERTICAL_CONSISTENCY`。该结果可帮助区分只存在于
单层的异常回波，但当前没有浅层真实降水标签，暂不作为删除依据。

### 3.4 验收统计框架

新增验收模块和命令行入口，支持：

- 异常回波 precision、recall、F1 和混淆矩阵计数；
- 真实降水保留率；
- 极坐标污染面积；
- QPE 样本数、均值、P95 和最大值；
- 雨量站 bias ratio、相关系数、MAE 和 RMSE。

输入采用显式 NPZ 字段；只有字段和有效样本存在时才计算。最小命令为：

```bash
PYTHONPATH=algorithms uv run --project algorithms \
  python -m rainpulse_algo.radar.qc_acceptance \
  --input acceptance-bundle.npz \
  --output acceptance-report.json
```

## 4. 真实数据复核

Z9591 的 110 个归一化体扫全部完成 RP-042 只读证据审计，错误数为 0。共识别
2,893 条形态证据射线：窄径向 57、宽扇区 1,856、断续径向 67、短距离径向
913、反向尖峰 0；RP-040 规则实际硬标志 1,882 条射线。

按极坐标门楔面积统计，110 个体扫中有 45 个存在硬标志面积，逐体扫污染面积之和为
3,340,350.357 km²，受影响体扫平均为 74,230.008 km²，单体扫最大为
582,526.943 km²。该“逐体扫面积之和”包含不同时间对同一地理区域的重复计数，
用于比较版本和时次污染强度，不能解释为一次天气过程的空间并集。45 个硬标志体扫
包括相邻射线规则命中的体扫，因此不应与 RP-040 只按长距离饱和特征选出的 44 个
重建体扫直接等同。

为验证“不改现有生产结果”，同一批输入分别使用 RP-040 和 RP-042 运行。初次比较
定位到 7 个体扫存在局部分段概率覆盖旧整条射线结果的问题；修正后对这 7 个体扫逐一
复验，径向硬标志射线数、低质量门数和平均 QI 均完全一致。代表性的 2026-08-28
02:50 UTC 体扫两版本结果同为：平均 QI 0.684654、低质量门 172,087、硬标志
射线 49；RP-042 只额外记录 1 条断续和 2 条短距离诊断射线。

四站抽样重放均成功。Z9593、Z9598、Z9599 的短距离或其他低置信证据只保留为
诊断，不触发硬标志。现有样本未命中反向尖峰，反向检测器仅完成合成测试，不能据此
宣称真实案例验收通过。

现有下游 QPE 可以直接计算分布指标。RP-040 已重建的代表性 06:30 UTC 分析中，
新 QPE 均值为 2.6185 mm/h、P95 为 8.0465 mm/h、最大值为 80.4649 mm/h；
35 个新旧配对周期的新版本 P95 周期均值为 7.908 mm/h。RP-042 当前不改变 QI
和 QPE；为验证版本传递与工作台展示，本次使用独立的 RP-042 QC、格点、拼图和
NowcastInput 版本完成了全链路回放，没有覆盖 RP-040 工件。待形态或双偏振证据
正式进入 QI 时，必须用同一验收模块重新比较质控前后 P95 和最大值。

RP-040 实施记录中的 1,880 条与本次相同当前输入直接重放得到的 1,882 条相差 2 条。
RP-040 与 RP-042 在同一当前输入上的硬结果一致，因此该差异属于历史审计输入或目录
快照差异，而不是 RP-042 回归；后续冻结正式验收集时应同时冻结输入清单和校验和。

## 7. 后续准入条件

RP-042 暂不替换 `rp040-fujian-radial-v3`。切换质量指数或生产链路前至少需要：

1. 冻结包含真实降水与各类污染的人工逐门/区域标注集；
2. 以 precision、recall、真实降水保留率和污染面积同时选阈值；
3. 补入配对雨量站数据，比较质控前后 QPE P95、最大值、偏差和相关系数；
4. 冻结静态杂波图、海岸线、时间上下文和邻雷达共同空间合约；
5. 完成历史回放和影子链路观测后，再发布新的不可变生产配置版本。
