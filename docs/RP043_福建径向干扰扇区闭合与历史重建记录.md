# RP-043 福建径向干扰扇区闭合与历史重建记录

日期：2026-09-02

## 1. 问题与结论

RP-042 已能识别大部分宽扇区、窄径向和断续径向干扰，但 2026-08-28
10:25 CST、10:45 CST 的 Z9591 最低仰角仍存在少量漏检。复核原始极坐标数据后，
确认这不是地图渲染问题：漏检射线位于已确认干扰扇区的边缘或内部间隙，邻近射线
本身也被污染，使旧规则的相邻方位差异失效；同时它们分别略低于 0.60 高反射率
门占比或 400 门最长连续段阈值。

RP-043 不降低 RP-040 的全局硬判阈值，而是在已有硬标志和 RP-042 诊断证据之上
增加两个保守确认步骤：已有扇区种子之间的一至两条射线闭合，以及短、长方位窗口
共同支持时对诊断射线晋级。全历史只读审计表明，新增结果集中在 Z9591 的已知干扰
时段，其他三站基本不变。本版本仍属于 `realtime_shadow` 工程回放，不构成业务质控
验收或生产准入。

## 2. 根因证据

10:25 CST 的目标射线方位角为 276.52°，有效门比例 0.997、45 dBZ 以上门占比
0.583、最长高值段 256 门、近远距离中位数增长 47 dB。它仅因高值占比小于 0.60
且连续段小于 400 门而漏过旧长距离规则；立即相邻射线同样污染，使邻差只有
0.75 dB。

10:45 CST 的目标射线方位角为 183.63°，有效门比例 0.998、45 dBZ 以上门占比
0.550、最长高值段 147 门、近远距离增长 53.5 dB。其四条近邻射线均已是硬标志，
但旧算法没有在已确认扇区内部闭合单射线空洞。

两个时次还分别存在 RP-042 已分类但保持 0.65 诊断概率的强方位突变射线。
因此修复需要利用已经存在的硬种子和诊断证据，而不是把任意高反射率或远距离增长
直接判为干扰。

## 3. 实施

新增不可变配置 `rp043-fujian-radial-closure-v1`，并将下游格点、拼图和
NowcastInput 配置分别版本化为 RP-043，避免覆盖 RP-042 工件。

### 3.1 有界扇区闭合

只检查两侧均已有硬标志的环形方位空洞，最大宽度为两条射线。候选射线还必须同时
满足：有效门比例不低于 0.90、45 dBZ 以上门占比不低于 0.50、最长高值段不少于
120 门、近远距离增长不低于 20 dB。任一条件不满足都不会闭合，因此连续降水带或
孤立强对流不能仅凭强度触发。

### 3.2 多尺度证据晋级

只处理 RP-042 已经给出 0.65 诊断概率的射线。检测以 30 dBZ 回波门数构造方位
边缘强度，比较 ±4 条射线的短窗口与 ±40 条射线的长窗口背景；同时要求边缘跳变、
短长尺度差、诊断门数、高反射率门数和近远距离增长均超过冻结阈值。晋级只覆盖原有
诊断门，不扩展到整条未分类射线。

### 3.3 兼容与追溯

旧 QC 配置未声明新字段时两个步骤默认关闭。配置 Schema、模块 provenance 和
全链路版本测试均已更新；双偏振和垂直连续性仍保持 `diagnostic_only`，本次没有
伪造静态杂波、海杂波、时间连续性或邻雷达证据。

## 4. 回归与全历史只读审计

合成回归覆盖：有界单射线空洞必须闭合、多尺度断续尖峰必须晋级、连续降水带不得
扩张为径向干扰。RP-043 对服务器全部 452 个归一化体扫完成只读审计，错误数为 0。

Z9591 逐体扫硬标志污染面积增加 21,124.434 km²，约为 RP-042 累计面积的

目标时次定向回放结果：

- 10:25 CST 新增 2 条硬标志射线、2,169 门；276.52° 目标射线新增 1,835 门；
- 10:45 CST 新增 3 条硬标志射线、3,987 门；183.63° 目标射线新增 1,836 门；
- 连续降水合成样本保持 0 条硬标志射线。

## 7. 仍受限的准入条件

RP-043 解决的是现有样本中有明确上下文证据的径向扇区漏检，不代表所有异常回波
类别已经验收。生产切换前仍需人工真值、真实降水保留率、异常回波 precision/recall、
雨量站偏差和相关系数，以及静态杂波、海岸线、跨体扫和邻雷达共同空间资产。
