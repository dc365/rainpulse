# RP-046 统一工作台精确数据与运行可视化实施记录

更新日期：2026-09-03

## 1. 目标与边界

本阶段承接 RP-045，在不依赖新增福建雷达历史资料的前提下，先完成能够独立验收的系统能力：

1. 将地图“色阶读取”升级为来自原始数值场的精确格点查询；
2. 四幅同步地图共享十字光标，并在一个浮层中显示当前图层的真实数值、质量和帧来源；
3. 将高扇出 Workspace 聚合响应写入 PostgreSQL 有界读模型，保留短 TTL、ETag 和失败时上一版本连续性；
4. 增加 Workspace SSE 变更通知，历史固定周期不因界面预设切换而重复构建详情；
5. 增加周期级处理 DAG，展示解码、质控、格点、拼图、QPE、模型和产品任务的排队/运行耗时；
6. 为仍在执行的历史重算提供受控取消入口。

当前只有 2026-08-28 福建四站数据，不能据此建立静态杂波图、海杂波/AP 统计或冻结业务质控阈值。本阶段不修改 RP-043 质控算法判定，也不声明业务准入。

## 2. 精确格点查询

### 2.1 QPE 数值侧车

诊断 Worker 在既有透明 PNG 之外，为 `RATE_QPE` 增加一个不可变点查询侧车：

```text
query/grid-rate-qpe-point-index.bin
```

侧车按格点存储：

- 浮点雨强；
- 0–1 质量指数；
- 缺测状态；
- 网格起点和分辨率。

诊断 manifest 新增 `point_queries.grid-rate-qpe`，包含对象路径、SHA-256、字节数、有效时间和帧类型。旧读取器会忽略该扩展，原 PNG 契约保持兼容。

### 2.2 统一查询入口

新增：

```http
GET /api/v1/workspace/sample?asset_url=...&longitude=...&latitude=...
```

接口只接受系统自身已发布的诊断、确定性产品、STEPS 和 NowcastNet 资产路径，不接受任意远程 URL。确定性产品复用 RP-015 已有二进制 point index，并通过 Range Read 只读取一个格点。QPE 读取诊断侧车。STEPS/NowcastNet 在其新产品完成侧车后使用同一接口。

响应明确区分：

```text
analysis  雷达分析
native    模型原生帧
derived   时间适配派生帧
```

旧产物没有数值侧车时返回 `exact_sample_unavailable`，不会退回 PNG 色阶下限冒充精确值。

## 3. 同步十字光标

OpenLayers 四图继续共用 View。新增轻量事件桥，将任一地图的指针经纬度和像素相对位置广播给工作台：

- 四图同时绘制同一位置的横纵参考线；
- 停留 110 ms 后请求一次精确格点；
- 浮层显示真实雨强、对应格点、质量指数和原生/派生身份；
- 离开地图立即清除，不在 pointermove 中持续触发网络请求。

该实现不修改底层气象图层渲染，也不重新创建 OpenLayers Map。

## 4. PostgreSQL Workspace 读模型

新增 `workspace_projections`：

```text
projection_key
status_code
headers
body
etag
expires_at
stale_until
generated_at
last_accessed_at
```

它是可重建、短生命周期的 UI 读模型，不是新的领域事实来源。请求顺序为：

```text
进程内短缓存
→ PostgreSQL projection
→ 现有领域 API 聚合
```

默认目录 TTL 5 秒、周期详情 TTL 15 秒；底层聚合短时失败时可在限定窗口继续返回上一份成功响应，并通过响应头显式标记 `PERSISTENT_STALE`。过期记录分批清理，避免表无限增长。

新增 SSE：

```http
GET /api/v1/workspace/events
```

服务按目录 ETag 判断是否真正变化，只在变化时推送 `workspace.changed`。现有轮询仍可作为浏览器或代理不支持 SSE 时的降级机制。

## 5. 周期处理 DAG

新增：

```http
GET /api/v1/workspace/cycles/{cycle_id}/stages
```

从现有 workflow/job 证据聚合：

```text
四站 Decode → QC → Grid
                 ↓
             Mosaic → QPE → Diagnostics → Model Input
                                           ├─ LK
                                           ├─ STEPS
                                           └─ NowcastNet
                                                 ↓
                                           Products → Verification
```

每个节点返回 job/run、雷达、模型和配置身份，以及排队耗时、执行耗时、重试次数和失败原因。后台只显示最新周期的一条紧凑 DAG，避免增加新的顶层页面。

## 6. 历史重算取消

新增：

```http
POST /api/v1/admin/regenerations/{request_id}/cancel
```

请求必须通过现有服务器端管理令牌代理，并提供 3–240 字符取消原因。取消使用数据库事务完成：

- 标记重算请求为终止并记录原因与时间；
- 尚未完成的 job 标记为 `SKIPPED`；
- 尚未投递的 outbox 事件标记为 `cancelled`；
- 尚未发布的目标 forecast run 标记为 `SKIPPED`。

已经在 Worker 中执行的计算不能被不安全地强杀，但其后续阶段不会继续。不可变原始数据和已发布产品不删除。

## 7. 数据保留策略

沿用 RP-045：派生 STEPS/NowcastNet 产品默认保留当前成功版本与上一个成功版本。数据库运行证据和原始/归一化雷达数据不由本阶段清理。精确数值侧车与所属产品使用相同生命周期，不单独残留。

## 8. 验证

新增或扩展测试覆盖：

- 一帧 QPE point index 的编码、缺测和质量语义；
- 1、12、24 帧 point index 的 Go Range Read 边界；
- 精确 QPE 查询；
- PostgreSQL projection 的 ETag、TTL 和不可用回退；
- 周期处理 DAG 的状态排序；
- 管理取消接口的鉴权；
- Web 网关仅对白名单取消路径注入服务器令牌；
- 四图十字光标和旧产物无侧车时的失败关闭。

完整验证命令：

```bash
make contracts-check
make test
make lint
make build
```
