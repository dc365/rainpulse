# Sparse residuals inside frozen original fans

The dense target-window requirement can miss the weak tail of an already
identified original object. Candidate geometry now comes from immutable RAW
bands measured at other distances. Target and adjacent windows cannot train
edges or original source references. No accepted residual becomes a source.

The target window still requires at least80% measured coverage on each band
row and both outside shoulders, with at most20% actual RAW foreground on either
shoulder. Current reliable polar weather and protected bridges remain vetoes.
Original parent membership, original source-derived range, source support and
competing-identity abstention remain unchanged. Missing sides are never dry air.

Policy3 enables this extension; policy2 reproduces the deployed dense-window
v8 behavior. The leaf default retains policy2 so historical source-footprint
artifacts and pinned baseline comparisons replay without implicit new rules.
The source-footprint caller explicitly selects policy3 for new candidate output.
