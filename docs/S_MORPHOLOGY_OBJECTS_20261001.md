## 2026-10-02：固定原始外边界内的分支联合测量

`--variable-objects --boundary-hypotheses --enclosed-branches` 增加显式研究模式：
在固定的原始种子左右边界内联合多个原始 run，要求最外侧两边仍匹配原始种子。
跨越固定边界的原始 run 不裁剪；未知或受保护的中间路径不能提供联合支撑。
联合只连接测量关系，不填补 DBZH，不改变原始来源，不递归向外扩大范围。
实际 SNR（包括非静默 SNR）只证明内部接收观测覆盖，不证明无天气；
报告单独记录非静默 SNR／缺失 DBZH 的门数，候选仍仅包含原始有效 DBZH 门。

最左到最右外边界测量；低轮廓父对象的完整收窄天气反例仍保留。
