# S 波段孤立点：完整原始对象与物理环带复核

本轮将孤立点纳入 S 波段残留优化，新增可选 `residual.speckle_physical_support`。实现和固定样例复核已完成，生产配置未启用，105 本轮未部署。八个真实样例没有新增处置命中，不能称孤立点问题已经解决。

## 修复的判断限制

旧规则以质控后的残留连通域判断对象大小，用固定 3×7 门邻域统计支持，只将有反射率的门算作已观测。存在两种限制：有噪声底观测的周边仍无法提供支持；较大原始对象被前序质控切碎后可能被当成小对象。新增正反例确认这两种行为。

新路径先在完整原始低阈值反射率上建对象，再限制面积、直径、原生门足迹和距离。按 1/2 km 两档物理环带及分象限观测覆盖判断孤立性，保留扫描断口和天气保护。对象历史不随先前删除而缩短，不迭代外扩。

反射率缺测继续为未知。有效原生 SNR 在 -50～0 dB 的门可提供有限的噪声背景支持，但不转换成“无降水”、不生成反射率。目标门仍必须有自身可用的低信噪比或偏振异常证据，且完整原始对象的证据占比至少 60%。复核保留当前配置的目标低 SNR 门槛 3 dB，没有提高到 8 dB；偏振缺失不是异常证据。

进入引擎后沿用残留处置原因、QPE eligibility 和 DBZH_USABLE 规则，RAW 不变。写出携带参数及完整原始证据，发布校验重新计算并核对数组、原始值摘要。资源超限时撤回整层可选复核，不发布部分遍历结果。未配置新字段时保留旧配置序列化和运行路径；没有修改生产 YAML。

## 可复用复核

入口 `scripts/audit_s_speckles.py` 读取冻结、绑定 Web 帧身份的原生 NPZ，生成报告和可选全幅图片，不写产品。输入需包含 RAW、原生坐标、矩量及可用性、几何断口和原始保护字段。输出目录必须尚不存在。

```sh
PYTHONPATH=algorithms python scripts/audit_s_speckles.py \
  /path/to/native-snapshot.npz \
  --profile configs/qc/s-physical-constellation-20261002-v6.yaml \
  --output /path/to/new-review-directory --plot
```

本地八样例证据在 `.build/s-discontinuous-20261001/isolated-20261002/eight-current-policy-v2/`，报告绑定输入、配置、脚本、模块和图片 SHA。原始数据、报告和图片均不提交 Git。

新增测试覆盖噪声背景支持、完整 RAW 父对象、天气邻域、强回波、未知观测、显式无回波、扫描断口、远距离粗门、分辨率和北向接缝，以及引擎数据隔离和写出篡改检测。测试入口：

```sh
PYTHONPATH=algorithms python -m pytest -q algorithms/tests/test_physical_speckle.py
```

## 接下来

优先给弱碎片补原始射线／扇形来源和相邻时次证据，保留原始边界、天气冲突及未知状态。历史重复性只作辅助，不能单独排除稳定天气回波。对无来源孤立点继续要求实际观测及自身异常证据；待真实固定样例有新增安全处置、天气反例和产品写出验证后，再决定是否启用。当前不能靠提高 SNR 删除阈值或直接删所有小对象制造改善。
