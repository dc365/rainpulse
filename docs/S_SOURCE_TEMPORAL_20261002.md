# S 波段弱残留：过去原始射线种子复核

新增 `source_temporal` 诊断和可复用脚本，补充上一轮孤立点与原始射线来源复核。本轮得到新的匹配证据，尚无新增质控删除；没有修改生产配置、引擎处置或 105 部署。

## 范围与规则

先评估完整当前 RAW，再由复核脚本选择孤立点或已发布残留。过去的供体必须是同站、同仰角且来源配置版本一致的原始体扫，所有原生采样时间严格早于当前层；用原生 UTC 时间而非界面时次标签比较。

供体必须落在原始射线种子实际观测单元内，不使用已关联尾段、不在射线上外推，不将新匹配转为种子。最近一次几何可比、DBZH 实际有观测的供体优先；其无原始种子、天气证据或 SNR 未知均保留为冲突，不跳过它挑选更旧匹配。

核对原始距离、角度与波束高度，范围不外推，扫描断口两侧保留。当前及供体 SNR≥3 dB，DBZH/SNR 各允许 3 dB 变化，最大时间差 1200 秒、水平误差 1500 米、高度误差 250 米、仰角差 0.1°。可靠偏振天气及已有保护保持。重复 scan/cut 不增加支持，身份相同但证据变化拒绝；有整层及匹配数量资源上限。

分别输出“实际历史观测”“原始种子匹配”“原始边界条件通过”。边界条件未通过的匹配只能作为线索。重复出现、弱 SNR、缺失偏振均不单独证明污染；本模块完全没有 QC action authority。

Z9598 08:42 的 243 个完整 RAW 诊断匹配中，13 个位于已审计的 Web 可见残留内；该审计选区仍是 RAW 781 门、现有质控可见 728 门，本轮没有改变这些数值。13 门匹配来自 08:36 标签对应的过去原生层，按实际角度映射到过去第 191～215 行，不能直接按行号复用。它们的过去源台账 `SOURCE_HOLD` 全部为 2（`NO_NARROW_BOUNDARY`），即窄带边界证据不足；原始种子也不等于已确认污染，不可以据此新增删除。26 个几何孤立门仍全部没有过去原始种子匹配支持。

其他时次的零值不统一等同于不重复：有些没有历史输入，有些历史来源版本不一致或超龄。报告保留各自拒绝原因，不用不适用输入当负证据。没有为获得命中而忽略版本条件；独立天气真值和泛化验收仍未完成。

## 复用脚本与证据

```sh
PYTHONPATH=algorithms python scripts/audit_s_source_temporal.py \
  /path/to/past-native-snapshot.npz /path/to/current-native-snapshot.npz \
  --output /path/to/new-audit-directory

python scripts/render_s_qc_review.py \
  /path/to/current-native-snapshot.npz /path/to/exact-published-qc-receipt.json \
  --temporal-report /path/to/new-audit-directory/report.json \
  --output /path/to/new-review.png
```

输入为冻结、绑定 Web 帧与原始矩量/源台账的 NPZ；输出目录及图像需为新路径。报告绑定输入、源台账、代码及诊断文件 SHA；出图再核对当前输入与实际发布审计、诊断摘要和观测掩膜。灰色只是 RAW 背景；右栏青色圈为过去种子匹配，不表示已删除。原始数据与生成图片保留在私有 `.build/`，不提交 Git。

本轮证据路径 `.build/s-discontinuous-20261001/source-temporal-20261002-v2/`。新增 15 项来源诊断测试和 6 项图像绑定测试，相关总测试 490 项通过；源码 lint 与 diff 检查通过。

## 后续处置边界

优先复核这 13 门所对应的完整原始扇形边界为何被拒绝，保留天气重叠与原始历史；不能丢弃保护或裁短历史重新锚定。对孤立点，需要补齐同一来源版本的相邻时次或其他当前异常证据，历史稳定性本身不能作为删除规则。只有得到可处置证据并验证原生数据隔离和产品发布后，才部署新增质控效果。
