# Unified native object implementation, candidate v1

The candidate replaces repeated source-anchor prerequisites with a shared
immutable RAW object record. `object_model.py` stores actual window boundaries,
native members, original history and membership SHA. `variable_morphology.py`
exports these records only when requested; its existing default masks and
legacy decisions remain unchanged.

`unified_objects.py` implements nomination -> joint evidence -> local gate
disposition. Ordinary uncertain/contaminated windows reduce object support and
remain retained locally. Complete curved, narrowing and ambiguous-fork histories
are counterexamples. Dense short lines need stronger aspect, coverage and edge
evidence. Weather/protection and actual target shoulders remain gate vetoes.

`projected_objects.py` groups exact disconnected original members against a
frozen original boundary. No previous rejected-source ID is needed. Multiple
original objects, long span, substantial support and stricter joint evidence
are required. Association cannot chain through accepted fragments, interpolate
members, cross a native sector gap or restart a counterexample's clean tail.
Membership/work budgets fail without partial promotion; redundant single-parent
or too-short nominations are excluded before materialization.

## Verification and limits

Regression covers rotation and angular resolution, variable width, disconnected
unanchored objects, local contamination/unknown observations, actual weather,
weak targets beside wet shoulders, short lines, forks, narrowing/curved weather,
native-sector provenance, immutable RAW and forged proof replay. Existing fixed
and variable morphology tests also pass. This is a candidate mask generator,
not yet an integrated worker/QC-writer release.

Private final eight-input comparison is
`.build/s-discontinuous-20261001/unified-objects-20261002-v4/report.json`.
It binds module/script/input/evidence/image hashes and replays each mask validator.
RAW is unchanged; proposed targets intersect neither external protection nor
missing DBZH. This compares fixed, variable and unified morphology masks, not
entire production QC outputs or independent weather truth. Preliminary v1/v2
are superseded; v3 failed the membership budget and is incomplete.

The 09:48 source-stage remaining overlap rises from 0 in the fixed/variable
detectors to 90 candidate gates; the inspected image highlights northwestern
fragments. These are offline proposals, not Web-published removals. For exact
historical stored-visible Z9598 targets, 08:18 is still 0/2094 and 08:42 2/728.
The current framework therefore does NOT resolve the main wide fragmented fan.
Actual mixed-parent branch decomposition remains necessary; uniform scoring
and global association alone are insufficient.

Next requirements remain: decompose stable original subbands within complete
mixed/forked parent histories; resolve weather and ownership conflicts locally;
integrate proof/configuration/action semantics into the actual engine/writer;
run the RADVOL-QC reference baseline; freeze independent event/site holdouts;
verify the installed candidate image before deployment and actual Web products.
Do not enable this candidate in production or claim generalized cleanup from
the additional gate count.
