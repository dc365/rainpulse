# 统一 S/X 雷达质控工作台：首批落地

对应设计：`UNIFIED_RADAR_QC_WORKSPACE_DESIGN_20260925.md`。本批落实 A 阶段，并保留 B/C/D 的数据准入门槛。

## 已实现

- `/?preset=qc` 和旧 X 链接 `/?preset=qc&band=X` 进入同一个 `RadarQCWorkspace`。预报工作台的“质控排查”入口跳转至此处。
- 顶部按“任务模式 → 波段 → 站点 → 仰角 → 字段”组织；日期、播放与真实资料时间轴只保留底部一处。S/X 使用同一反射率色谱，质控标记使用分类图例。
- 单站验证默认成对显示原始/质控结果，支持双图、卷帘、单图；S 图共用地图视角，X 图也使用相同的地图视角和交互。波段切换保留目标日期与六分钟时次，各自保留站点和扫层；缺资料时不自动换站或换时次。
- 同图叠加复用 S 地图和单一时间轴。X 图层被明确标为“待地理配准”，无法勾选；融合验证显示候选资格门和后台任务入口。前端不把原生 X PNG 当作有地理坐标的图层，也不把透明叠放命名为融合结果。
- URL 记录当前波段、模式、日期、时间、站点、扫描/结果和扫层；图片请求按扫描/结果/扫层绑定，同一对 PNG 解码完成后才同时显示。
- X 单站页与 S 一样只显示原始/质控后两幅底图，透明回波直接叠加到底图；取消第三幅站点地图及原生图缩放条。S/X 同心圈标签统一仅显示距离数字，单位为 km。
- Worker 根据任务冻结的归一化体扫站点坐标、原始方位角、距离门及逐射线仰角，使用 WGS84 测地线和 4/3 地球模型采样为 EPSG:4326 PNG。每层 `map` 携带 bounds、坐标来源、投影版本、地面最大距离及三类图件路径；Go 校验并发布只读路径。缺测、方位缺口和质控剔除保持透明，不插补缺失数据，不改变 QC 数值。
- 地图视图可用于候选质控验证，坐标/融合资格保留在资料详情。旧结果无 `map` 时提示生成新版结果，不套用其他扫描的地图范围。

## 当前限制与下一批前提

- X 站目录的 `geometry_status` 仍是 `unverified`。地图以体扫头中的站点位置为候选定位，不意味着站点测绘、标定、高度基准或融合准入已经核验。地图资产由真实极坐标重新采样生成，未直接拉伸原生 PNG。
- 实际 S/X 跨站同图叠加仍须核验 X 站点定位；实际融合验证还须等高度基准、频率/标定、同网格同时间及产品资格核验。现有候选任务入口只供查看，不表示业务准入。
- S 目录当前提供分析周期级可用性，尚无全日期逐站原始/质控图对索引。时间轴按真实分析周期展示；当前周期内站点若缺帧会留空。逐站可用性轨道需 Go 汇总契约后补充。
