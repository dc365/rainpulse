# 检验分析实施记录（2026-09-10）

## 使用

在“检验回放”地图下展开“检验分析”，不增加第二条时间轴。

- 时效曲线：选择算法、阈值和邻域，后台计算 CSI、FSS、邻域 CSI、MAE/RMSE；点击曲线点跳回原时间轴及对应算法地图。
- 空间频谱 PSD：随当前时效读取共同有效区域，显示 QPE 与所选预报的谱曲线及分析范围。PSD 高低不是优劣排名。
- 案例统计：选择北京时间起报范围，手动开始；显示进度、取消、均值、样本数、跨时效曲线和逐记录回放入口。

## 计算与资源约束

单帧及 PSD 按需计算、短时缓存；曲线与批量由 Go 后台任务调用既有 Python 产品服务。仅 CPU 运算，不启动模型推理或复制预报数据。

同一条记录使用 QPE 与全部选中算法的共同有效域。缺测不补零；不满足条件的时效明确跳过。含 NowcastNet 时默认检查原生 10 分钟时效，避免把派生插帧混入模型检验。统计为相同有限样本上的等记录宏平均，并非汇总列联表的 CSI；跨时效覆盖可能变化，不代表独立天气过程的显著性检验。

PSD 选择共同完整正方形区域，依次尝试 256/128/64/32 格，去均值、二维 Hann 加窗、按格距归一化并径向平均；仅保留完整频率环。无完整区域时提示不可计算，不用缺测补零制造谱信号。方法约定详见 `contracts/data/workspace-verification-analysis.md`；窗函数和谱密度归一化参考 [SciPy periodogram](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.periodogram.html)，本项目实现为二维扩展。

任务最多 128 个起报、24 个时效，单进程同时运行一个任务，超时两小时。相同设置重算覆盖同一报告，最多保留八份小型 JSON；不保存额外网格副本。API 重启后未完成任务标记中断，用户手动重算。源数据更新后应点击重新计算，报告显示生成时间和固定参数。

报告目录：`runtime/reports/workspace-verification`，容器路径 `/var/lib/rainpulse/verification-jobs`。首次部署须保证容器 UID/GID 65532 可写；可通过 `RAINPULSE_VERIFICATION_JOB_HOST_ROOT` 指定宿主目录。离线部署程序镜像必须包含本次 API、Web 和 product-builder-worker；已有检验报告可选，不是历史案例展示的前置条件。
