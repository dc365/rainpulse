# X 径向质控：原生波束证据与跨层复核

## 本轮修复

普通 RSTM type-1 文件的站点头有垂直波束宽度，解码器已与站点配置核对，但归一化对象未保存它。上下层算法因此只能报告“有测量”，不能核验两个垂直波束是否独立。

`56796d4` 在归一化根属性保存 `native-site-beam-v1` 契约，包含原始文件 SHA256、配置版本、原生垂直波束宽度及来源。仅接受 type-1、有限且处于 (0,3] 度的原生值；不从候选配置补值，不把相控阵单个接收/发射波束当作全站等价波束。

字段及几何数组保持不变，旧对象和任务凭据保留。代表资料使用正常 `radar-decode-rebuild` 生命周期重建，不手工修改对象属性或任务状态。

## 冻结策略

`5af913d` 保存通用策略 [x-context-native-beam-v1.json](../configs/multiband/x-context-native-beam-v1.json)。参数保持已有有界默认值：最多两个供体、64MiB、200万对、180秒、500米水平差；垂直差 250–3000米，目标/供体 SNR≥15dB，供体 RHO≥0.97，双波束不重叠。只把有独立上层天气支持的已排除候选降为混合待复核；不恢复回波，不放宽删除预算。

策略适用于已有增强质控且实验启用的 X 站，不按站名、方位、时次或仰角写例外。缺少原生波束证据的旧资料/相控阵继续明确未知；不改变物理站的可信启用状态。
