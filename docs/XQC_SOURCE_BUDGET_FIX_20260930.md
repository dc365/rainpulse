# X 径向与扇形模型计算预算修复

## 原因与边界

ZF702 scan 3b3bf9da-aac2-5800-88a5-6d29ed907d9c 的 0/2/4/5 切面，在当前 v2-z10 下源模型超过默认500000次试验后整个模块置零，外层仍显示EVALUATED。raw≠qc只证明其他模块有动作，不能作为径向处理通过的判据。

## 修复

- 按原始射线一次计算参考成员关系，逐目标仍严格去掉目标和guard距离块。相同参考集合只计一次模型试验；未拟合的重复seed枚举另计seed_comparisons。物理阈值、参考门、判定顺序、缺测与降水保护不变。
- 成员关系临时矩阵纳入summary内存预算。不增加默认试验上限，不缓存跨目标拟合模型。
- 径向连续/分段/扇形子模块各自完整完成才合入结果；后续超限保留已完整完成模块，明确PARTIAL_RESOURCE_LIMIT与未完成模块。切面总体明确DEGRADED_SOURCE_RESOURCE_LIMIT；API保留状态，界面提示不能作为全量质控验收。
- 不将形状候选直接判成污染。原始值与历史结果保留，候选结果不启用QPE/预报。

## 验证

- 回归：默认5000试验的合成源，修复前资源超限，修复后与高预算一致；后续fan超限时，修复前丢失全部证据，修复后保留连续模块。
- ZF702切面0离线源模型：EVALUATED，388203次模型试验，516828次seed枚举，161682源候选门，连续/分段/扇形全部完成。默认预算未调整。
- 真实全图验收需基于正常Worker生命周期发布的新结果，不能只用以上源模型候选数量宣称干净。
- 旧hardening测试中8项已存在不适配（mock不接受response_quantile；r7参考未包含后来的primary-mode及模型诊断变化）。本次不掩盖这些失败，运行相关当前测试并保留红绿日志。
