## 筛查定义与限制

- X：原始反射率 ≥15 dBZ、距离 ≥15 km；按原生门检查质控结果是否非有限。
- S：`DBZH_USABLE` ≥20 dBZ、`RHOHV_RAW` ≥0.95、反射率可信掩码有效且 `QC_ACTION < 2`。缺少这些字段的仰角不参与；不能将其解释为无雨。
- 使用逐径向时间，时间差 ≤180 秒，候选位置的水平距离 ≤1000 米。查询最近 32 个 S 候选门，故这是有界冲突筛查，不能穷尽全部空间邻居。
- S/X 的位置、MSL 高度核验并不完整。水平位置来自候选配置；用斜距乘仰角余弦近似地面距离，仅适用于本次筛查。
- 辅助比较采用已有 4/3 地球模型计算**各自雷达以上高度**，高度差 ≤1000 米。它不是共同 MSL 等高比较，不能用来确认或排除真实降水。
- S 强回波的存在不能证明 X 对应门没有叠加干扰；S 没有匹配门也不能证明 X 门不是降水。
