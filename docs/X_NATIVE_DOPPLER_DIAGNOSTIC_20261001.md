# 原生 X 矩量诊断边界

这是径向残留的只读诊断，不生成清除或保护资格。使用同一层原生门的 REF、SNR、VR、SW 与各自 VALID/AVAILABLE 掩码；不得把缺测当成零，不跨缺测门计算相邻差，不用波形扩展码猜测解模糊状态。

每条原生射线输出有效门数、相邻门对数、原始速度差、谱宽分位数，以及在文件声明 Nyquist 周期下的循环差。循环差只是假设性敏感性检查：声明周期不等于解模糊验证，不能将高速度差解释成污染，也不能将低循环差解释成天气。没有可信 Nyquist 时保留原始差并显式说明循环诊断不可用。未知采样代码原样保留，动作资格始终为 false。

范围/仰角/时次/站号不参与阈值特判。诊断保持输入不变，受现有层门数资源上限约束。真实残留、正常速度折叠、天气边界、缺测、坏几何和无速度字段均需覆盖。

## 标准字段核对

[国家标准信息公共服务平台 QX/T 653—2022](https://hbba.sacinfo.org.cn/stdDetail/14ef28ddf83d0682d8b58736b1d2cdc8f204873b3c79b0816c27ef88a54f8416) 表 6 定义了常规 FMT 的解模糊模式、两组采样数、相位模式及大气损耗。解码和原生采样记录新增保留这五个字段，保留扩展值和缺测哨兵；未经核验的 PA 布局仍不读取这些偏移。波形 8、相位模式 0 超出该表枚举，不赋予厂商语义。用户目前无法核实厂家格式，排查继续使用现有矩量。
