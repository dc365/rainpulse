# 设计与实现边界

## 1. 调用链

`x_qc()`在X输入身份校验后，发现内联enhancement才进入新协调器。协调器使用不带enhancement的临时XProfile调用原v1函数，避免复制第二套基础算法或递归重入。原S Worker与所有S算法默认值不修改。

读取集合补ZDR/VR/SW和各矩可用掩码；标准化资产保留的真实radar_config_version和速度核验信息传入，缺失为缺失。几何适配保留全部原始行、稳定排序映射、重复射线屏障和真实角度/时间/仰角间断；SNR的可用域不依附DBZH有限域。

## 2. 检测而非图像擦除

接收域使用原RDR拟合与留出检验，通过独立XReceiverConfig降低物理距离尺度；残差、相位稳定性、至少多个独立距离块和实测侧翼仍保留。分段与源族是显式可选模块。源族cr_only政策不升级为确认剔除。

低相关径向路径使用原始多尺度对象提名，外加目标自己的可靠极化及两侧实测反差。形态、强度、近站位置不单独触发剔除。高相关平滑线若不符合完整源模型，不因外观被强删。

CF使用共享features/engine/classifier；孤立对象沿用物理尺度和支持感知，不对弱核响应直接处置。调用额外上下文必须实际存在。第一版为每切面运行：没有跨仰角/过去体扫观察时明确不可用，不能把没有上层数据当作无雨。

本站晴空背景按内容哈希加载，并比较本站、真实处理配置与时间；不复制S站资产。目标缺少ZDR可使用共享背景的部分矩路径，但不能将尾部当精确DR。速度字段即使存在，动作级使用也要求配置与输入元数据中的核验ID、波形及Nyquist一致。

## 3. 一个X出口决定处置

新增证据先汇合，再由X全局audit/cr_only/quarantine决定动作；S Action、S flags、S QI不作为整数直接迁移。原v1已经确认无效的门不被恢复。源/极化冲突、天气保护或缺少资料不等同于无雨。

每切面动作比例有独立预算，超限整体撤回新增动作而不是留下前半部分。资源/几何不适用明确弃权；输入损坏、错误配置、缺失指定依赖、背景哈希错误不能伪装成成功运行。此类错误保留异常，旧版本已发布基线不被覆盖。

## 4. 相位和定量独立

只收紧实有PHASE_VALID、LIQUID和可靠极化条件；缺任一基础合同不生成新的可靠路径。新污染和原候选会中断路径；相位不跨缺口重启，PIA受原上限约束，upstream_verified不得重复订正。

内部相位工作掩码使用私有字典，原字段/原可用性不变，实际生效掩码另存。原生READY诊断要求最终CR资格及几何条件，但不启动QPE；需要独立反演、标定和检验才能升级业务。无任何“自动设verified=true”的代码。

## 5. 性能与产品

沿用逐切面调用、原始共享和A/B/C/D工具。共享核新增开销必须以完整Worker测量；不宣称与旧基础X QC同速。保留既有gate/byte预算；原生诊断也单独限字节，不将全数组塞入JSON。

每切面记录放在Sweep附属诊断中，不放入会随层改变的Volume.metadata，以免破坏流式融合的源身份一致性。共同元数据只包含算法版本、参数SHA及模式。原始行号和源模型排序映射可核对。

采样/PNG编码不改变；QC只隐藏确认剔除，未决单独标志。experimental_horizontal_max额外消费XQC_WITHHELD_MASK，不能出现单站已取消资格而组合仍引用同门的问题。

## 6. 验证界线

见验证报告中的真实执行结果。最新完整仓库未在本容器取得。当前模型文件通过精确blob核验；X-v1质量函数本地测试基底由既有源码与最新已审阅动作语义组装，不把它宣称为最新完整quality.py的逐字节副本。共享算法依据恢复源码测试，所有实际模块摘要记录在validation。
