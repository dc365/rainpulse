# X 与 S 工作台统一

用户要求：X 反射率采用当前 S 波段色谱，布局、时间轴和交互复用已有工作台。

## 实现

- `reflectivity_palette.json` 是 S 诊断渲染、X 原生 PPI / S-X 候选图及 Web 色标的共同来源。采用 5–70 dBZ、每 5 dBZ 一档的 14 色离散色谱，与 105 当前 S 诊断 Worker 一致。边界值按下界取档，超界钳制，缺测透明。
- X 质控后图保留待复核门的反射率颜色；确认剔除门透明。红色/琥珀色动作只在质控标记图展示。数值 QC 和业务准入条件不变。
- S 和 X 使用相同 `ReflectivityLegend` 组件。历史不可变结果按其原 manifest 色谱显示，明确提示历史色谱，不把旧 PNG 配新色标。
- X 复用 S 的 `SharedTimeline`：逐帧、播放速度、键盘、按真实时间定位、可用性标记；新增 observationOnly 仅隐藏预报/起报语义。X 不创建虚构六分钟帧。
- X 使用同样的顶部预设、雷达选择器、控制样式、设计变量。移除独立站点侧栏和卡片时间轴。两幅原生 PPI 仍联动拖动缩放，不伪造未经核验的地图位置。
