# Z9598 残留干扰与开源质控核查

2026-09-11：当前线上仍为 evidence-2.1.0，本次未修改运行算法。

## 实测原因

08:15 原始最低仰角中，方位 80.3° 的远距离有效回波覆盖率约 89%，105—107° 为 72%—84%，低于现有整径向 90% 门槛。179°、181.9° 的距离订正反射率 IQR 为 17.3、14.1 dB，高于 8 dB 门槛，尽管 RHOHV 中位数仅约 0.49、0.34，仍不会晋升。以上是检测入口漏检原因；剩余每个门还需区分高相关保护、邻站否决和实际气象回波，不能按截图整片删除。

离线原型 experiments/qc/z9598_segment_candidate.py 改为 100 km 滑动窗口，要求至少三个窗口、支持跨度至少 249 km、局部覆盖 80%、低相关及距离增长共同成立，仅作用于通过窗口内的观测门。未接入任何运行 profile。

105 三个真实最低仰角回放：08:10 新增 0 门；08:15 新增 2,868 门、3 条射线；08:30 新增 1,583 门、2 条射线。缺测和 RHOHV≥0.95 新增标记均为零。9 个负对照（各样本替换高相关、缺测相关、常反射率）通过。结果位于 runtime/reports/qc-z9598-20260911/segment-candidate-results.json。这是邻站否决前的候选计数，不能宣称发布后的改善或误删率为零。提升有限，不满足截图效果验收，暂不推广。

## 库与当前实现

algorithms/pyproject.toml 和算法源代码未声明或调用 Py-ART、wradlib。当前基于 NumPy/SciPy 自研 QC；双偏振模糊和垂直一致性在 v3 profile 中为 diagnostic_only；静态杂波和 sea/AP 资产引用为空。Hybrid 内已有自研 DEM/圆形波束部分遮挡、累计遮挡相关实现，不能说系统完全没有地形质控；运行资产是否可用须以任务输出诊断核实。

- Py-ART despeckle_field 识别小连通对象并生成 GateFilter，适合孤立噪点，不会因射线“看着异常”就删除大连通扇区：https://arm-doe.github.io/pyart/API/generated/pyart.correct.html
- wradlib filter_gabella 使用梯度及连通区几何，classify_echo_fuzzy 使用极化变量；适合做并行对照和候选概率，默认参数不等于本地区业务验收：https://docs.wradlib.org/en/2.6.1/generated/wradlib.classify.ClassifyMethods.html
- DEM 遮挡计算需要站址、仰角、波束宽度和 DEM；遮挡估计不等于恢复严重遮挡后的真实反射率：https://docs.wradlib.org/projects/notebooks/en/latest/notebooks/beamblockage/beamblockage.html

## 下一步验收路线

1. 对每条残留射线输出整径向/分段判定失败原因、各仰角支持及邻站否决来源，先确定哪些残留能可靠硬剔除。
2. 独立环境接入 Py-ART 去孤立点和 wradlib Gabella/模糊分类作为基线，保留原始几何、缺测掩码，输出候选掩码，不直接覆盖反射率。
3. 用人工确认的降水区、干扰区及其他站点阴性样本比较漏检、误删、强回波保留和耗时。接入生产需通过现有邻站否决及完整 Worker/产品链验证。
4. 补静态杂波资产及确认 DEM 生效；严重遮挡优先剔除或选择更高仰角，不放大恢复。
