# 杂波分证据评分实验

这是未接入生产的候选评分，权重未经标注样本校准，不代表概率或分类准确率。
沿用单日晴空背景回顾8月28日，两目标站接受候选处理，四站全仰角重新组合。

|证据|分数|约束|
|---|---:|---|
|背景强度一致|2|观测覆盖>=80%、>=20份、处于P10-3至P90+3dB|
|低SNR|1|实测SNR<8，缺测不计分|
|偏振异常|2|SNR>=8、RHOHV<=0.85且有效、ZDR异常且通过物理范围检查|
|历史重复|1|至少2份严格过去观测，强度匹配比例>=80%|
|多普勒|1|实测或有界配对，速度绝对值<=1、谱宽0–1.5m/s|
|纹理|1|Gabella或反射率纹理异常；不要求同时命中|

隔离候选要求：背景一致、总分>=4、至少三类证据、当前具备组合资格、距站
75km内、反射率<=30dBZ且有限、没有现有天气保护。背景与历史归为同一证据类，
低SNR与偏振归为同一可靠性类；其余为多普勒、纹理。这里的分组用于避免
明显重复计数，不声称统计独立。仅背景+低SNR，或再加历史重复，仍不能隔离。

逐项移除证据统计剩余候选（ablation），而不是仅报告更多删除。模块不会改写
输入证据数组。原始观测保持不变；回放只在内存关闭组合资格。

新增9项评分单测，连同已有匹配、近站分支共25项通过。检查缺测、天气保护、
强回波、资格门槛、相关证据重复计数和纹理消融。

复现：`replay_joint_clutter.py inputs.json backgrounds output --scored-evidence`。
模块 `review_extension/clutter_score.py` 未接入生产runner。

补充验证任意二值证据组合下，移除证据不会新增候选，且评分不修改传入证据。
时间重复与背景共享证据类，不能靠重复计数凑足三类。生产开关未新增或启用。
