# 晴空背景、偏振、时序/多普勒联合回放

本实验不发布生产 QC、组合或 QPE。使用 9 月 18 日背景回放 8 月 28 日属于
事后分析，不代表实时验证。两个目标站采用已有单日背景，另外两个贡献站原样参与组合。

## 规则与验证边界

在原始极坐标门上要求：

- 当前已具备组合资格，原始/质控反射率有值，距站小于75km；
- 背景实测次数至少20、回波重复率下界至少0.8，仰角差不超过0.2度；
- SNR至少8dB、RHOHV为0–0.85，ZDR在物理检查范围内且小于-1或大于4；
- 反射率不超过30dBZ，且不超过背景平均值6dB；
- 无现有天气保护；
- 另外至少满足：两份严格过去观测重复率>=0.8，或者速度绝对值<=1m/s、谱宽0–1.5m/s。

原生速度优先，缺失时可用有界匹配的独立速度扫描层。单独低速度、单独重复性
或单独低强度均不删除。缺测没有被当作零回波。此规则是待验证的保守假设，
不是已证明有效的分类器。

只在内存覆盖组合资格数组，使用生产同一 P3 全体扫四站最大值组合代码、
旗标配置和站点坐标重建前后场。不修改原始文件、不使用图片擦除。
检查隔离后无新覆盖、反射率不能增加；统计天气保护门、>=35dBZ门和组合强回波变化。
这些保护统计是代码约束，不是真实天气分类准确率。

当前研究 NativeSweep 重建仍沿用回放脚本的几何有效性简化，不等同于完整生产
worker 验证。匹配脚本已保留全部扫描层，避免独立速度层在联合回放中遗漏。

## 复现

在安装相应当前模块的环境中运行：

```
python scripts/replay_joint_clutter.py inputs.json backgrounds/ output/ --configs configs/
```

inputs 是 `[case_label, qc_uri]` 数组，包含两时次四站及可用的前序体扫。
输出有观测匹配记录、联合命中统计、四站组合前后数值NPZ与对照PNG。
这是固定案例研究脚本；不应直接作为生产任务入口。

## 已定位的限制

`clear_air_pilot.py` 的背景 hits 定义为有限且 DBZH>=0，不是所有有效弱回波的
出现频率。上轮组合追踪发现部分主要贡献扫描层的中位数约-2dBZ，这类弱背景
不能由当前>=0重复率完整描述。下一轮需把“有效观测覆盖”“不同强度档出现率”
与强度分位数分别统计，不能简单降阈值后自动隔离。

显示 `_scalar_rgba` 会将低于第一个色标10dBZ的有效值截到同一种蓝色，
因此大片蓝色同时包含很弱回波。这是可视解释问题，不能拿显示修改替代QC。

## 弱背景 v2 与低 SNR 消融

已重新解码107份晴空体扫，分站分扫描层保存有效观测率、-10/-5/0/5/10dBZ
超阈比例及P10/P50/P90。每档比例均以全部体扫为分母；分位数仅使用有限观测。
对全部18个反射率层验证：比例在[0,1]、阈值升高时比例不增加、P10<=P50<=P90。
原背景输出字段保留，新增 `distribution_version=weak-background-v2`。

Z9598最低层：有效观测覆盖>=80%的格点15937，原>=0dBZ重复>=80%仅565。
这说明旧背景未充分描述稳定弱回波，但有效观测覆盖本身不是杂波标签。

离线弱分支要求背景覆盖>=80%、实测>=20、Z<=10且<=背景P90+3、SNR<8、
Gabella与反射率纹理同时命中、无天气保护，只改内存组合资格。没有使用低SNR
下的RHOHV作为可靠的独立分类证据。四站全体扫重建结果与上一轮相同：08:12
变化0像素、08:18变化6像素，弱分支新增隔离0门。

证据字段实际存在，排除字段缺失导致跳过。Z9591 08:12仅1门同时满足弱候选
与双纹理条件，随后被天气保护排除；其余目标为0。当前“两个纹理必须同时异常”
与大片弱残留不匹配，不能继续把这个AND条件作为大片杂波处理的必要条件。

下一步应设计可解释的分证据评分并做消融：背景强度分布相符、SNR可靠性、
偏振在足够SNR下的异常、时序、速度及实际可比的跨层证据分别计分；纹理为
补充证据。独立检查天气保护来源与误保护，不能为了命中直接取消保护。

结果保存在 `artifacts/clear-air-20260918/weak-clutter/`（含gate-results逐条件统计），
背景在 `weak-background/`。运行联合脚本时增加 `--weak-evidence`；仅检查候选
可增加 `--gates-only`。生产未切换，背景仍是单日、未来日期的回顾研究资产。
