# 晴空背景与分类型杂波联合判别：设计、实现与验证

版本：clutter-fusion-20260921-v1。基线：9f8489075a90874903f881a5d49c79bf3d61254e。
这是可选、非业务验收的工程候选。没有改变径向算法，不部署、不切换默认配置。

## 1. 本版解决什么

把上一版短时段晴空背景库，与本次“可比垂直结构、支持感知纹理、分类型模糊判别”研究合并为一个判别及处置入口。不是把背景图、Gabella、低相关、低顶高各自生成的删除掩码做并集。

冻结现有旧 QC、非降水、NMR 和 RDR 作为父基线。在父链计算结束后，新增唯一的 `volume_review.clutter_fusion` 阶段；本次所有新背景及特征证据都在这里统一分类和投影。旧阶段暂不重写，是为了可归因的成对比较；新阶段不撤销旧隔离，也不会用已删结果作为新候选种子。后续只有完成等价及气象验收，才考虑合并、替代旧分类路径。

附带 ZIP 是旧“晴空背景与部分矩判别”代码包，不是两小时实测晴空序列。本版重新利用其中构建、统计、哈希读写、时间块留出和部分矩比较函数；没有导入旧独立 EBG 的动作／接入文件，防止出现第二条背景删除链。已有单日回溯 near-background 父配置原样保留，不能把整条链宣称为不依赖历史。

## 2. 处理顺序

```text
冻结原始体扫与每个矩的实际 availability
    ↓
当前体扫特征：反射率纹理、圆相位增量抖动、极化联合模式
    ＋
原生或可核验配准的多普勒、实际更高层观测
    ＋
可选的分站/处理配置/实际仰角短时段晴空背景
    ↓
一个分类器：天气相容 / 地物样 / 生物样 / 非气象未定类型 / 混合 / 资料不足
    ↓
审计 / 仅收紧 CR / 充分证据的定量隔离
    ↓
所有贡献门先过资格，再取全仰角、全站最大值；保存赢家、原因、风险数值
```

“地物样”“生物样”表示特征模式，不是已确定物种、AP、地形或海杂波原因。评分是未校准隶属度，不是概率；证据家族数不等于统计独立样本数。

## 3. 特征和动作合同

### 3.1 纹理与极化

反射率局地标准差仅由真实有效样本计算。当前初始窗口为三条径向、约 2 km 径向跨度，记录门距、角分辨率和对应物理窗口。至少六份实际样本，支持比例至少 0.6；几何断裂、重复/坏射线、窗口端点不参与新动作。它不保证不同雷达、不同距离统计分布相同，需要按来源分层验收。

PHIDP 同时保存圆标准差及相邻有效门“相位增量”的圆抖动：359/1° 不被误作 358° 跳跃，平稳径向梯度不被误作随机噪声。增量不跨缺测，且仅在当前配置指定的 100–500 m 原生门距内使用。没有声称它是脉冲级 CPA/SQI；超出适用门距明确没有这项证据。

DR 使用现有 NMR 的 `wradlib.dp.depolarization` 后端；显式 `numpy_reference` 用于无库研究。没有自动回退。RHOHV、DR、PHIDP、ZDR 派生信息只组成一个极化家族，不能重复计数。±7.5 dB ZDR 尾部默认不计算精确 DR，也不能绕过成普通缺测；背景可分别统计正、负尾部类别。

可靠极化需实际 SNR≥8 dB；生物样初始需 SNR≥12 dB、Z<25 dBZ 和联合低相关/较高 ZDR/相位增量抖动。平滑的 DBZH 不自动否定生物样模式。单一极化家族支持的此类候选可进入 CR-only 研究，但不能单凭它新增定量隔离。

### 3.2 垂直和多普勒

原生同门 VR、SW 可用时优先采用。不按相同数组索引复制另一切面的速度。

跨切面匹配使用实际方位、地面距离、逐径向仰角、高度差及时间差。默认输出几何匹配诊断，不驱动新动作。只有实际元数据中声明同一经核验波形/速度模糊范围/配准合同，并显式选择 `verified_pair`，该配对才可作为动作级多普勒证据。几何匹配本身不是波形或测速质量核验。

更高层必须有实际有限 DBZH 和可靠 SNR，目标也需可靠 SNR，才计算同地面位置反射率下降；没有把上层缺测、超距、无该矩当成“无雨”。默认垂直结果只诊断。动作级 `verified_beam` 另需真实波束宽度和来源，检查主瓣高度区间分离；仍只是一种约束特征，不是独立污染真值、完整三维体积积分或可靠回波顶高。没有 ET20/低顶高直接删除。

原始 `NativeSweep.attrs['clutter_context_contract']` 可包含：

```json
{
  "beam_width_deg": 1.0,
  "beam_source": "实际设备/配置回执ID",
  "doppler_pair_verified": true,
  "waveform": "实际波形身份",
  "nyquist_ms": 25.0,
  "verification_id": "实际配对审核回执ID"
}
```

以上数值只是字段说明，不能作为当前四站默认元数据。第一版不自动从别的字段猜这些值；不提供合同即保持诊断。保留真实 donor sweep/ray/gate、时差、高差及水平误差，写回时既重排目标数组，也转换 donor-ray 的索引值。

### 3.3 背景

短时段资产按站点、实际仰角、处理配置绑定；包含稳健分布、矩值有效次数、时间块漂移、尾部状态和来源哈希。默认构建至少12份样本、至少三个30分钟块、时长至少一小时；这只是短时段工程支持要求，不是长期气候置信度。建议约两小时、20个完整体扫，并按整个体扫归入时间块留出，不能将同一体扫拆进训练和测试。

没有解码器确认的 acquired/no_echo 状态时，出现频率保持不可用，不以有限 DBZH 的个数伪装完整出现概率。当前目标必须匹配兼容的背景、稳定核心以及当前可靠非气象测量；背景重复本身不能删除。背景增强、可靠天气、旧未知保护保留。单纯强度未超过背景3 dB不能证明没有叠加弱雨。

缺 ZDR/PHIDP 时仍可使用背景与当前 DBZH/SNR/RHOHV 子集；保持缺测和正/负尾部类别区别。背景资产缺失输出 NO_ASSET_BOUND，当前体扫路径仍运行；日期/配置不兼容不使用背景。哈希错误明确失败。实时默认只用过去且不超过12小时的背景；回看未来背景必须显式 retrospective 和目标日期，不能冒充因果运行。

### 3.4 联合分类和天气保护

- 极化＋真实反射率纹理；或极化＋动作级垂直衰减，可以支持非气象候选。
- 地物样需联合多普勒近零/窄谱宽、极化与结构证据，零速度本身不删除。
- 生物样使用极化联合模式，不强制 DBZH 粗糙或速度接近零。
- 背景稳定且当前部分矩支持，可以补充完整 DR 入口的空缺。
- 可靠独立天气、来源未知的旧保护、NP 天气/混合、强回波、背景增强不解除。
- 有明确来源的局地天气相容性默认也保留。另一个实验配置只允许有具体非气象证据且至少两个家族的局地冲突进入“混合CR限制”，不赋予 QPE 杂波隔离。

当前阈值和评分来自本项目开发原型，不是第三方库提供的福建成品模型。缺失特征不归一化成满分。部分资料造成的未定，不能统一视为污染；无新增依据也不会自动变得更可信。

## 4. 模式与输出

- `audit`：增加 CF_* 诊断，所有父级 RAW/QPE/CR/trust/QI/flags 逐值不变。
- `cr_withhold`：只收紧可信 CR；保留原因和风险，QPE 与信任掩码不变。
- `quarantine`：只有至少两个受支持家族的完整候选，关闭 trust/QPE，LOW_QUALITY降权；不新增确认干扰标志。触及相位/KDP/衰减的原信任连续段时使派生量失效。

本轮未改变 NMR 低 SNR 策略、径向 RDR/segment 算法或已有晴空背景父配置。所有模式均不可恢复旧不合格门，不填值、不做 dBZ 背景相减、不擦PNG。预算超限保持隔离并要求复核；计算资源超限则整个体扫返回零新增动作，不能仅发布已算完的部分切面。

字段前缀 CF_*，保存 CLASS/REASON/FAMILY_BITS、每类分数与支持数量、背景模型状态、context来源和实际处置。CF_BEFORE_* 保存精确前置值，验证先恢复前置视图递归执行未修改的 RDR/NMR/VOR/旧 QC 校验，再验证新证据与精确差分。

组合输出增加 CR_CLUTTER_CANDIDATE、CR_CLUTTER_MIXED、CR_CLUTTER_WITHHELD 数值风险层及 WINNER_CLUTTER_CLASS/REASON。并不更改前端颜色/透明度。多站必须使用同一个融合配置身份，站点资产在共同registry中选择；不同站可有不同背景，但不能混合新旧策略。无合格贡献保持不可用，不能称作有效无雨。

## 5. 文件接入与版本兼容

只修改 volume_review 的 config/integration/validation/receipts/composite 五个文件，其余新增模块、脚本、测试和合同。最新 receiver_domain 与 segment_reference、NMR核心原样保留。

本包已将旧晴空 ZIP 的必要源库整合到当前基线；不要再叠加运行旧 ZIP 安装器，其五个旧接入文件可能覆盖较新的径向/NMR钩子。本版 nested background 始终为 audit/evidence-only，只有 CF 统一动作。

默认没有 `clutter_fusion`，旧参数序列化/哈希保持一致。配置生成器保留真实父配置（包括径向开关），只添加新子块和新profile身份，不选择运行配置。没有变更 Go、React、部署、调度、数据迁移或线上资产。

## 6. 科学与工程验收

先当前体扫审计/CR对照，再绑定真实晴空背景做增益消融，再评估多普勒/波束合同，最后考察隔离对 QPE 的代价。晴空不代表没有散射，不能以图面完全空白为目标。

09:00/09:12原始包只有用于测试的冻结输入，缺少最新版全链 QC 输出和全部上下文。本地回放因此只能比较“独立 NMR strict8 核心”与其后 CF 增量的本站全仰角 CR，不能称为相对线上净提升或实际四站拼图重算。没有真实两小时晴空序列，本版没有新的实测背景清除率。合成数据仅证明合同与集成可运行，不可部署为站点模型。

最终应以同一输入、同一上下文、同一父版本的完整 QC→Zarr→CR 结果核对：污染残留、弱天气误排除、未定覆盖、QPE变化、赢家逐门一致性及分站最差表现。强回波零变化主要是保护条件结果，不是独立零误删证明。
