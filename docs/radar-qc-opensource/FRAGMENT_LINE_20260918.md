## 原因与实现

08:42 冻结样本中，西侧细线有旧源模型支持，但连续开运算/候选
未覆盖剩余片段。北侧 346.35° 的残留同时存在源模型不匹配，单独
增加形态识别无济于事：第一次仅接形态的回放只新增隔离 46 门，
北侧 890 个远距离剩余门全部被识别为候选，但新增处置为零。

新增可选 `fragment_line` 分支：

1. 原始极坐标多反射率等值级，提取至多三条射线宽的窄对象。
2. scikit-image `probabilistic_hough_line` 在方位/距离图上关联断续
   径向片段；原始米制坐标 `RANSAC/LineModelND` 检验径向几何。
   仅提名实测等值级门，空隙与缺测不填充、不沿连线整段删除。
3. 复用旧源模型及分段源模型。另为强相干细线增加独立的留出块
   物理证据：高 SNR、稳定 SNR/圆周相位/ZDR、有效高 RHOHV；
   目标20公里块及两侧保护块不参与参考拟合，跨至少三个参考块、
   两组独立参考均须吻合。逐门匹配后仅实验隔离。
4. 缺测、天气保护、冲突、平台歧义仍是屏障。低 SNR 或缺少极化
   证据不能靠直线形态取得处置权。配置缺省关闭，旧配置行为不变。

完整字段与不变量见 `contracts/data/qc-fragment-line.md`。
