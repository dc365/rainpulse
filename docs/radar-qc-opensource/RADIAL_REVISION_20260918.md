# 径向残留三步优化：实现与接入记录

基线：`547ead93f0a2849893f008dafcbbf78f1f2a483d`（QC 7.3.6，review-20260917-v1）。
新增扩展版本：`radial-source-v2-20260918`。这是一版离线工程候选，不是气象真值验收版。

## 1. 目标与不改变的内容

针对前一轮两站 08:42 脱敏案例的“完整侧翼缺失”“强弱状态混合”“束外背景选择不合理”问题，分三步增加候选和参考路径。原有强长线、宽源模型、OC1、非降水分类与 generalization 动作链保留；没有降低旧版的统一强度、长度、残差或极化阈值。原始矩值、原始有效性、缺测和有效无雨的区别均不改变。

本改动不改 Go、React、数据库、任务协议、默认部署配置或运行服务，不修改拼图来制造视觉改善；不新增已确认干扰标志，不恢复已经失去的定量资格。

## 2. 第一步：原始支撑结构候选与已有源匹配交集

`radial_revision/topology.py` 在原始 ray/gate 上，按 10/20/50 km 物理窗口计算观测支撑占有率。它描述“这个方向在这段距离内有多少实际观测”，**不描述没观测的位置一定无雨**。横向连续支撑窄且束外支撑稀少时，仅将中心原本有实测的门列为候选。

保留原有双侧实测反差分支。新结构分支不要求每个侧翼距离门都存在矩值，但必须通过几何连续性、宽度和保护屏障检查。角度和实际宽度同时受限，扫描数组首尾保守断开，不跨方位 gap。

新隔离建议 = 原始结构候选 ∩ 已有留出参考的严格目标匹配 ∩ 非保护区。

只有结构而没有测量源匹配的门，仍不隔离。旧 QC 删除结果不能反过来充当“干净侧翼”。所有配置值为开发初值，不是四站通用验收阈值。

## 3. 第二步：训练端状态分离与独立弱源诊断

`radial_revision/segments.py` 在每个目标距离块之外，先去掉目标及两侧 guard 块，再估计原始 DBZH/SNR 的共同线性距离处理项、发现训练 SNR 状态、拟合参考分布。状态数最多 3，由训练样本中较大 SNR 间隔划分，**不是使用目标值选择最接近它的参考，也不是已经实现任意变化点检测**。

强相干状态必须满足：至少 3 个参考块、100 km 实际参考跨度、100 个样本、每块至少 7.5 km 的测量支撑；交替参考块形成的两个分组必须一致；严格功率残差不超过 2.5 dB，SNR 块间离散不超过 2 dB，并满足原始 PHIDP/ZDR 稳定性及目标极化包络。目标只能匹配唯一状态。

共同距离项的两组径向校验沿用原有关系思想：它是接收处理关系，不是独立的干扰证据。新增强状态隔离要求该关系被实测支持；不能把失败时的零系数当作已测校准。训练端数值平台检查限制在参考块内；自身目标平台检查不能蔓延进入训练选择。

所有留出不变性都以调用方传入的天气／外部冲突掩膜固定为前提。上游保护证据的生成算法未在这里重写；脱敏回放复用其存储结果。因此本报告不把增量实验表述为整个 QC 链路的端到端留出验证。

### 弱信号与缺极化

弱／不相干状态可以建立基于原始 SNR 的接收尺度分布诊断，不再强行通过强相干状态的全部功率及极化条件；记录低 RHOHV 比例、相位增量方差等原始特征以及状态来源。缺极化独立标记，不补造极化、IQ、SQI 或 Doppler 矩。

这部分是对已有 OC1 noisy/coherent 思路的**参考构造补充和诊断**，不是复制一个已校准 noisy 分类器，也没有把新弱源模型接入 OC1 的确认动作。`weak_policy` 只能是 `diagnostic_only`。弱诊断不能独立获得隔离；不能用某个强片段的隔离结论覆盖相邻弱片段。

## 4. 第三步：不均匀宽束与有界片段身份

`radial_revision/bundles.py` 搜索中心束之外、实际有足够观测的两侧背景。中心可包含不同幅度，不再要求整束幅度接近一个值。初版搜索奇数 1–11 条中心径向及最多 3 条外侧步长，同时检查角度/物理宽度、侧翼观测占有率和中心支持比例。每个候选门仍须有实际反射率相对于实测背景的反差，束外缺测不能填低值。

原始短片段可形成对象身份；同一径向的相邻片段，在 gap 不超过配置上限且 SNR 签名相容时有界关联。整个身份跨度相对首段受限，不能通过多跳不断生长。实测非候选间隔、天气保护、冲突及状态明显变化截断关联。

**身份不是动作**：空隙没有对象掩码、没有测量值、没有隔离动作。关联不传递源资格。现阶段关联主要提供审计和碎片归属，不声称仅靠关联已解决所有短线。

## 5. 运行路径与开关

实际入口保持：

```
broad_source.infer_broad_source
  -> review_extension.source.source_additions
     -> 原有 narrow/multiscale 资格（不变）
     -> radial_revision.engine.evaluate（新增，可选）
  -> 原有 BWS 候选
  -> generalization 的隔离、QI、信任/QPE 资格和预算流程
```

仅增加 `generalization.broad_source.source_review.radial_revision`。不配置即关闭，新增 None 字段从历史参数序列化中裁剪；已测试裁剪与旧分支输出，完整仓库所有历史配置哈希仍需实际项目回归确认。

配置由 `scripts/make_radial_revision_profiles.py` 从本机**实际父配置**生成，不使用脱敏包的 YAML 作为线上雷达资产配置。产生 6 个独立子配置：step1/2/3 × audit/experiment_quarantine。原有父级 broad/source 模式不被更改。

- `radial_revision.mode=audit`：新扩展只诊断、不增加旧源分支的动作；父配置已有的旧动作仍然正常执行，不是关闭整个 QC。
- `radial_revision.mode=experiment_quarantine`：允许新增扩展提出隔离建议，但原有父级 broad/source 两个开关仍须同时允许。
- `allow_segmented_quarantine=false`：即使计算出强分段源，也只记录资格，不让其成为新增动作；step1 必须为 false。
- 生成的 step2/3 实验配置显式启用强分段源建议，需按步骤选择，不能默认代替已运行配置。
- 任意路径都保持 `operational_eligible=false`。

## 6. 诊断与校验

新增 `RV2_` 数组分别记录原始支撑候选、未知侧翼、宽束响应、尺度、弱诊断、强状态匹配、状态/参考/对象身份、参考跨度、残差、校准可用性、屏障、资格和实际建议。字段类型见代码 `DTYPES` 及数据契约。

`RV2_QUALIFIED_MASK` 是源支持的假设；`RV2_ACTION_PROPOSAL_MASK` 还受到显式实验开关约束。父级 `SRC_REVIEW_QUALIFIED_MASK` = 原有资格 ∪ 新动作建议。持久化校验核对上述等式、数据类型、形状、缺测、保护屏障、参考来源和唯一状态，拒绝仅改掩码制造动作。

运行时只向摘要放置模型计数、状态计数、配置和参考记录 SHA-256。完整参考记录由离线回放单独导出，不塞进任务/完成事件。极坐标数据中的额外诊断数组不是跨服务 REST/NATS 负载。

计算规模、参考折数、对象数超过新扩展预算时，整条新增扩展弃权，不保留任意部分结果；已有基线继续。非法输入和配置直接报错，不吞掉契约错误。

## 7. 复现与实际验证范围

交付包内 `validation/验证报告.md` 是本轮已执行结果的入口。两站各 11 个切面，三个阶段累计 66 次源分支增量回放；audit 另对两个最低切面执行三个阶段。脚本读归一化原始矩，复用存储的旧版留出匹配和保护掩膜，新分段参考重算。

脚本执行真实 `source_additions` 和对应字段校验，并根据存储 QC 状态投影新增隔离及定量资格损失。**动作投影不等于重新运行 generalization、质量因子、完整 Worker、Zarr 序列化、Hybrid、Grid、拼图或 QPE。** 不输出冒充正式产品的 QC 资产。

数据包只有两站一个时次，已用于开发，不能当独立验收集。弱雨、海上降水、窄雨带、小强单体、混合污染、其它时次与四站最差表现仍需独立检查。不得用新增隔离门数当准确率或宣称相应门已经被证明为干扰。
