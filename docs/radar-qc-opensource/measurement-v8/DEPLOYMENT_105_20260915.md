## 使用

在 105 项目根目录执行：

```bash
sudo docker run --rm --network none rainpulse-qc-measurement:8.0.0 --help
```

真实数据 freeze/extract/train/infer/assess 使用本目录的 `RUNBOOK_给Codex.md`。输入通过只读卷挂载，输出放独立可写目录；原生参数使用上述二进制路径及现场构建回执中的 SHA256。没有真实权重，不把合成 demo 模型接到前端。

复建使用 `deploy/Dockerfile.qc-measurement-v8`；基镜像需已有 `rainpulse-cpu-worker:qc-opensource-7.0.0-r1`，安装编译器和新增依赖的构建步骤需要可访问包源，工具执行本身可以禁网。

运行日志、测试 XML、镜像 ID 和合成 demo 位于服务器 `runtime/reports/qc-measurement-v8-20260915/`。停止使用实验镜像即可退出实验；在线服务继续使用 V7。在线切换仍缺真实标注/验收权重及版本化 Worker、任务、校验器和下游接入，并非更改版本号即可完成。
