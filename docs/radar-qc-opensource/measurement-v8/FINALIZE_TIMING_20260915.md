# P1 最终出口第一步与计算计时

已将runner中的最终健康降级、基线可用性门控、LOW_QUALITY标记和
DBZH_USABLE生成提取到finalize_decision。保留全部原始判断及顺序，
不改动作、不改原因、首次决定者仍由StageAudit维护。
这不是把V2–V7所有决策合并成单一新评分器，也不是整项P1完成。

新增运行时计时：输入适配、独立证据、垂直支撑、逐仰角决策融合、相位、
最终出口、总计算。日志qc_compute_timing含scan_id及毫秒值；可选timing_sink
供离线分析。不写入QC summary，避免计时改变不可变资产哈希。
计时范围在QC引擎内，不包含对象下载、Worker解码、上传，后续需在Worker补齐。

105相关18项测试通过：最终出口不复活隔离/拒绝/缺测、健康降级、
V7真实Worker序列化及现有开源QC测试。抽取过程中的统计变量引用遗漏已由
集成测试发现并修正，最终测试全绿。

scripts/qc_finalize_equivalence.py将真实冻结体扫限制为最低仰角，
以相同缺省外部上下文对比前一版本runner和当前runner的所有数组及summary。
此检查用于代码重构等价，不等同线上已发布资产的完整上下文重算。

本轮代码在105实验环境验证，未重建或切换线上Worker镜像。
下一项：依据计时细分耗时最大的证据族，同时为后续出口整合增加阶段动作
和原因的等价检查；静态先验数据盘点与图预算专用降级仍待实施。

## 真实最低仰角对照结果

216个数组逐项一致，summary一致。
本次实验总计算3386 ms，独立证据2308 ms（约68%），决策融合737 ms，
相位20 ms，最终出口及审计5 ms。该样本不含实际邻站上下文、下载上传，
且容器限2 CPU，不能代表在线体扫总延迟；但足以确定下一次计时应细分独立证据。
