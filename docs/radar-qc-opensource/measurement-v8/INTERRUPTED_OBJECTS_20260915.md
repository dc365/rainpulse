# 断续对象识别：实现与实测

新增 interrupted_objects.py，FragmentConfig.interrupted_objects_enabled 默认 false。沿原始同一射线，将间隔不超过3km、整体不超过40km的真实回波段分组；跨度至少15km、观测占据率至少25%、冻结的既有 REJECT + RADIAL_INTERFERENCE 锚点累计至少2km，才生成对象候选。上述为工程试验参数，未经真值标注校准。对象ID、原始射线编号、起止门、观测和锚点门数输出用于诊断。

对象只代表关联，不代表污染；只有目标门自身满足已有可靠SNR、低RHOHV、圆周相位离散证据，才允许确认。有强可信邻站支持时转为冲突隔离，不直接删除。缺测不填充，不赋予候选；不递归借新候选扩展锚点。没有邻站不构成污染证据。

这是对已有“近锚点且反射率差匹配”关联的可选补充，解决其对弱碎片幅度差和单段锚点的依赖。尚不包括跨方位对象跟踪或完整多时次证据。

## 测试

原有15项 fragment 测试、新增3项对象测试均通过。覆盖无锚点不生成对象、缺测不填补、范围有界、高相关系数天气不误确认、目标自身污染证据才确认、可信邻站冲突保护，以及原始数据不变。正向用例明确验证旧关闭路径不新增确认、开启后可以确认；并非仅检查负例。
