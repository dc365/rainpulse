# V8 原生检测方位适配实测

## 原因与修复

此前 29 个真实扫描全部在 native.py 的全扫均匀性校验退出，calls=0。
实测常见 366 条射线，多数间隔约 0.99°，夹有 0.02–0.25° 短间隔。
原始非均匀采样不能直接传入规则矩阵算子。

增加默认关闭的 angular_mapping。实验显式使用 angular_step_deg=1.0，
拟合圆周格点相位，每个格点选择最近的真实射线，角差不超过格距 0.25；
保证单射，任何射线不重复使用。无匹配、重复歧义、坏几何均不可用。
没有插值、填零或修改原始测量；未选中的原始射线不获得分数。
输出映射回原始射线，记录 source_indices、最大角差和语义摘要。
完整均匀 PPI 仍走原有路径；不支持的扇扫保持未知。

这是一种有角误差上限的近邻采样实验，不等价于原始非均匀几何上的精确算子。
独立实验保持原 bRopo C 二进制；不改变线上 V7、既有 features 或模型。
新配置会改变特征语义，后续训练必须重提取，不能与旧模型混用。

## 105 结果

29 个扫描最低仰角全部处理完毕：

- 21 个 executed，累计 248 次原生调用、165,800 个有效评分门。
- 7 个 no_usable_native_support：严格完整观测瓦片仍不足。
- 1 个 unsupported_angular_geometry：不满足本适配的完整 PPI 前提。
- 不能将上述 8 个扫描和其他无评分门视为无干扰。
- 相比此前 29 个全是 calls=0，已打通可支持区域的真实计算。
- 46 项既有 measurement 测试通过；3 项新测试验证额外射线单射、误差门控和未选中射线保持 NaN。

批处理脚本 scripts/qc_native_mapping_batch.py，显式映射开启、tile_rays=8，
容器 rainpulse-native-mapping-20260915，2 CPU / 6 GiB。
服务器输出 runtime/reports/qc-native-mapping-20260915/progress.json；
每扫描保存 summary.json 和原始 ray/gate 顺序的 native.npz。
本轮没有训练权重、没有自动发布质控图，不宣称污染识别率改善。

## 后续边界

先评估有效分数在已隔离门、可信气象门和漏检候选中的分布与原始 PPI 对照，
再考虑门级隔离建议。对未覆盖门，需要独立验证支持缺测掩膜的检测方法，
不能为了覆盖率缩小保护边界或把未知值设零。
