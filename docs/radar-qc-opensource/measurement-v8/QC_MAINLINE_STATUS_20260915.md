## 本轮修复

NativeConfig 增加可选 emitter1_minimum_contrast_db。
None 保留历史调用行为；显式设置时只对 Emitter1 按0.5 dB/byte编码强度差，
不加绝对反射率偏置。Emitter2 保留原始绝对强度参数及其内部原生实现。
原始C源码和二进制未修改；不将两个检测器的不同语义强行统一。

真实试验显式使用4 dB作为一个待验证工作点，不称为已校准最优阈值。
受控样本：背景0/20 dBZ、相同10 dB突起。新调用检测成功且平移不变，
历史调用漏检；Emitter2前后逐门相同。回归测试通过。

105容器 rainpulse-native-contrast-20260915 按顺序运行：

```sh
python scripts/qc_native_mapping_batch.py /results /out 4
python scripts/qc_native_action_audit.py /results /out /out/audit
```

/results 为之前冻结的29扫描；输出为新的
runtime/reports/qc-native-contrast-20260915，不覆盖历史对照。
仅实验候选和归因，没有线上推断或发布。
