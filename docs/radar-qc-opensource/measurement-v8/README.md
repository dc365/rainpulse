# V8 测量分类离线实验：原生候选、连续特征、训练与受约束动作

## 交付身份与边界

目标基线：`1669ed1dad26b649eb69a083e8f6e8807c69d56b`。
实验版本：`qc-measurement-experiment-8.0.0`。**不是 `qc-opensource-8.0.0` 生产配置。**

本版落实上一轮“仅改候选的动作上界—原生 Emitter 对照—本地分类器—径向状态提议”的
可执行离线链路。所有新增能力位于 `measurement_v8/`，读取冻结的标准化体扫和已经发布的
V7 QC 资产，不重算旧上下文，不修改 V7 数值，不发送 NATS，不修改数据库，也不部署105。
唯一对既有文件的修正是历史参数摘要测试遗漏排除 `evidence_graph=None`；不改变生产摘要算法
或任何冻结配置。

**当前没有四站人工真值，没有经过当地验收的权重。** 不附业务模型，不把合成训练的高分
冒充真实天气准确率。默认 `audit` 仅输出提议，实际实验动作与 V7 一致。获得独立人工标签、
模型、动作策略和签核回执后，才能选择 `experimental` 对本地实验副本应用新增动作。
仍不自动成为可发布 QC 资产。不得直接把副本复制进105对象目录充当已注册业务产品。

## 已实现的闭环

1. **真实原生核心。** 用固定提交的 bRopo 原样 C 核心调用 `detect_emitters`、`detect_emitters2`，
   包含离线构建脚本和许可证。不是把研究函数重写成同名Python；也不是完整RAVE/ODIM适配。
2. **观测支持适配。** 完整且均匀的有效PPI可周期填充真实边界射线；含缺测时只运行完全有观测
   的矩形块，边界留保护带。没有把缺测填零、无雨或伪值。无支持／失败／预算耗尽结果为NaN，
   与原生零分不同。Emitter2依赖行统计，**分块结果不声称等于全扫描结果**。
3. **连续特征。** 原始DBZH、RHOHV、ZDR、SNR、VR、SW，真实距离与扫描尺度，多物理尺度
   沿距均值/标准差/支持率，周期相位差、相位一致性，多尺度双侧差异及支持，原生分数和可选
   的已冻结上下文。没有站号、固定方位删除特征。原始值不被特征缺失值插补覆盖。
4. **可训练判定。** sklearn 1.8.0 RandomForestClassifier；训练集拟合中位数并附缺失指示器，
   每过程等权。独立校准集拟合多项log-probability LogisticRegression；验证集只用于输出报告。
   工程下限是每份分区至少2个独立过程、每类至少10个标签，不是科学样本量标准。
5. **安全、可复现模型。** 输出有限大小的JSON树和校准矩阵，不读取pickle/joblib。
   检查树索引、循环、归一化、类型、尺寸、摘要和特征身份。实际测试JSON推断与sklearn一致。
6. **径向状态。** 一维Viterbi状态提议，有物理长度约束；缺测打断序列。不声称已经实现
   半马尔可夫、横向束级联合图或四维天气推断。最终动作仍须满足本门的模型分数，不能靠
   平滑把低证据门删掉。短门不在特征/分类前按2km一刀切丢弃。
7. **动作与评价。** 可信天气、干扰、混合三类，另有未计算/未定状态。强天气存在证据与
   高干扰评分冲突时只提议隔离、不确认无雨。确认和隔离分别统计；旧拒绝/隔离不恢复，
   原始无雨和缺测不创建新观测。逐站、独立体扫/切面报告，必测站缺失是INSUFFICIENT。

## 为什么不直接再接到旧V7末尾上线

V7新增确认仍由旧极化组合批准，单纯增加候选无法扩大最终可判定类型。本版分类器的分数与
提议单独输出，不先受旧 `pol_bad` 硬门槛过滤。另一方面，没有人工校准就直接应用预测也不可靠。
因此先形成可验证模型与独立候选结果；生产Worker接入作为明确后续阶段，不在本包里隐藏一个
默认启用的未经验证模型。

**这不是声称算法已经改善图中细线。** 当前能证明的是原生执行、IO身份约束、训练/校准隔离、
推断一致性和实验动作不污染V7。真实收益必须用Z9591/Z9593/Z9598/Z9599的冻结资料及负例核验。

## 模块

- `native.py`：原生执行、完全观测支持、预算/失败状态。
- `features.py`：连续测量特征和实际可用性；配方与代码摘要进入特征身份。
- `dataset.py`：原始ray/gate标签、分区、重复scan和过程泄漏检查。
- `forest.py`：实际训练、分离校准、JSON树导出/校验/推断。
- `states.py`、`policy.py`：状态提议与分层动作，不递归扩张。
- `case.py`、`workbench.py`：绑定完整输入，输出实验sidecar与相同采样PNG。
- `assessment.py`：人工标签下的提议评价，隔离与确认分开。
- `tools/qc_v8/action_ceiling.py`：旧V7条件冻结下，仅扩大review能够增加确认的条件上界。

## 实际输入和输出语义

输入normalized、QC必须是完整本地Zarr目录；使用本工具的目录摘要方案，不等同于
RainPulse object-store `artifact_sha256`。绑定scan、radar、cut、每射线时间、所有共同原始矩、
V7配置语义摘要、QC资产和context_fingerprint。若提供可选上下文NPZ，必须是实际准备阶段导出，
名称 `sweep_000__weather_support` / `temporal_persistence` / `temporal_samples`，并含相同
`context_fingerprint` 标量。工具不会根据邻站图片或相同像素位置生成支持。

输入QC资产和可选上下文的内容已被固定，但**本工具不重新准备上下文，也不能仅凭fingerprint
证明某个外部提供的上下文矩阵确实来自正确的地理匹配**。其获取链需由105原请求与资源清单核验。
`unverified_engineering` 不会在本版被伪造为verified；上下文未提供时对应特征NaN。

输出 `*-experiment.npz` 使用 `EXPERIMENT_` 前缀保存标准动作/资格副本，`BASELINE_` 保存V7，
`V8_`保存新分数/提议/增量。它是独立实验契约，不冒充通过原V7分阶段校验的QCRadarVolume。
PNG三组分别为 baseline、experimental_actual、proposed_not_applied。第三组只是“提议若被应用”
的预览，不是已发布图，也不能按删掉多少像素计算准确率。

## 原生适用边界

量化工作副本使用0.5dB步长，核心输入1–254，不变更原始反射率；超出可表示范围不进原生支持。
原生长度参数由实际米数换算成门，须满足C核心2–254的范围；宽度明确为射线数量。
分块只取真实完整观测，因而会留下真实数据的覆盖空洞；这不是“无干扰”。模型绑定二进制SHA、
支持策略和特征配方；完整模式与分块模式另有特征/训练几何域检查，不能未经训练就跨模式应用。
源码、驱动、编译器和二进制回执均保留。重编后摘要变化，需要重新冻结与核验模型配方。

## 模型与气象标签

标签CSV：`ray,gate,label`，标签为 `weather/interference/mixed/unknown`，坐标来自原始切面，
不能使用合图或网页坐标。unknown不进入监督训练，缺测不能标成weather。
按天气过程分 train/calibrate/validate，并隔离时间上下文窗口；重复scan不能跨分区。
同一物理切面的不同分析时次不能重复增加样本。代码检查ID/分区重复，但无法自动识别人工
给同一过程取了不同名字，因此现场仍须审核过程边界。

校准数据须有可解释的抽样设计。每过程等权的校准结果不自动等于业务发生概率；故意平衡类别
的方便样本也不等于自然频率。输出概率是该配方和该标注分布下的数值，必须独立检验可靠性。
强小单体、弱雨、层状边缘、海上回波、稀疏远端和混合区不能缺席。Z9593不自动当真值。
模型不输入站名或绝对方位；几何域之外默认无新提议。没有足够资料时，保留V7并报告不可判定。

## 性能与回退

核算独立cut读取、原生执行、特征、分类、状态、序列化时间；本地不上传所以upload=null，
没有上下文重算所以context_prepare=null。默认原生子进程是离线参考实现，不作为实时拓扑。
特征矩阵有提前预算，完整中间场仍可能占用明显内存；建议逐切面运行，实测105峰值RSS。
不把合成运行时长外推为P50/P95。现场吞吐验收后再考虑批处理/C扩展和缓存。

回退只需停止使用新离线输出：V7源码、配置、队列、既有资产均未改。任何真实模型的部署都必须
另有版本化参数/权重SHA/作业身份、下游动作验证及回退，不复用旧缓存，也不解除原NATS有界事件修复。
