# 原生 Emitter1 稀疏适配实测

仅离线诊断，无 QC 动作、无生产配置切换。原始数据未修改。

## 源码依据与边界

bRopo detect_emitters 先读取当前及上下各一条射线计算方位对比，再沿距离统计连续段。新增 measurement_v8/sparse_emitter.py 按实际相邻三射线共同有效的连续距离段调用原版 C 核心，只取中间射线输出。不插值、不填缺测，不跨 geometry gap。缺测切段可能缩短连续长度，输出只是局部分段证据，不等价于完整射线得分，也不是污染概率。Emitter2 有整行统计，未采用此适配。

试验参数：最小长度 4 km、方位对比 8 dB、最多 2000 次调用。该阈值是工程试验参数，未经真实降水标注校准。调用预算不足或失败保持 NaN，不能解释为无干扰。

## 后续主线

下一步应逐门区分“相邻肩部缺测/共同连续段不足”和“已有完整支撑但方位对比不足”，再设计多尺度对象背景证据。不能把缺测补零来获得对比，也不能单凭原生分数删除。当前改动保留为诊断适配，不启动全站重算或发布。
