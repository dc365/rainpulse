# OC1：原始对象、跨块参考与天气反证的可运行实现

日期：2026-09-15。参考上游 `3a7c407040ffb37a905190aa3669150b489c1105`。
这是一个新增模块及独立动作实验补丁，不覆盖 V7/V8，不改变原配置，不自动部署。

## 1. 这次与上一轮研究原型的区别

上一轮同射线统计原型跨整条射线取参考，输出 proposal_code，未形成完整对象边界，不能直接作用于业务。这次实现：

1. 使用原始 DBZH 可用性和实际 ray/gate 几何建立有界门段。长缺口、实测低于候选阈值的门会分割；短缺测只关联身份，绝不成为训练样本或目标动作。
2. 限定参考只来自目标所在原始门段域。按50 km块排除目标及左右各一块，至少五个有效参考块、足够实际样本与跨度才拟合。
3. 区分噪声型与高相干型测量签名。前者依靠目标外原始极化分布与相位增量离散，目标用自己的SNR匹配；后者还要求目标本身实际可用且相位/ZDR/RHOHV匹配。
4. 增加天气反证：目标局地连续高相关与平稳相位（噪声族）、实际观测的横向天气连续性、局地SNR增强、显式带可靠回执的外部支持。冲突保留为混合/未决，不强行判成RFI。
5. 输出完整逐门状态和留出参考证据。邻射线只形成结构关系，不共享训练值、不传动作。
6. 明确的 audit 与 experiment_quarantine 策略。后者确实修改实验数值/资格和隔离掩码，而不是只显示提议；两者身份独立。没有新增确认污染。
7. 提供真实 Decision 形状兼容的可调用适配器、同输入实验脚本、完整回归和五例实际输出。

本版没有训练概率模型，也没有完成IQ/谱域信号分解。天气反证是可解释的保守规则，不应写作“已校准天气竞争似然”。统计相容不等于源的物理同一性。

## 3. 参考参数的依据和边界

所有常数都是继承上一轮研究或明确的工程假设，不是MIT/NOAA的标准阈值。

- 研究距离50–450 km、50 km块、1块guard、至少5块/200 km参考跨度：沿用前轮跨块试验。首尾不具备双侧参考时仍输出模型证据，但默认不应用隔离；不以缩小验证分母隐藏未处理端点。
- 原始对象最长可关联缺口6 km、总缺口比例0.4：是有界结构身份假设，不是允许删除6 km空洞。实测低于候选阈值即屏障，不因数值低就改为缺测。没有足够原始域时明确弃权。
- 每块实际SNR支持≥7.5 km，参考块中位数差异P90≤2 dB，目标分布容差1 dB：检验接收尺度统计稳定性；未知处理器约定时不能称为真实恒功率。
- 噪声族：SNR≥8 dB的可用极化参考、低相关比例、跨块分布及实际相邻相位对共同约束。低相关不是目标单门删除条件。
- 相干族：相位偏差P90≤1°、ZDR≤0.25 dB、高相关和SNR条件。高相关不等于免责；这种签名也可能与真实天气/处理链异常无法区分，因此有独立开关，且不确认污染。
- 角宽分成细线、束、扇区假设。不能因比2.5°宽就否决整个相干源；>70°无界扇区留作未决。角宽本身不能确认或删除。
- 审计默认不改变任何基线数组。实验需明确 acknowledgement，并可关闭相干族；参考必须夹住目标。单切面新增QPE资格损失>10%时整切面退回原结果，不挑“最像”的部分勉强满足预算。10%是实验停止上限，不是可接受气象损失标准，需在独立验证前由团队重设。

## 4. 模型与天气解释

参考区只使用原始数值；`baseline_rfi_anchor`、`review_roi`、旧动作及旧QI完全不参与。目标SNR/相位/相关系数改变时，参考索引、参考摘要和拟合统计仍不变（固定原始几何与观测支持的条件下）。

原始对象边界本身使用DBZH可用性和回波阈值，因此若改变目标是否存在/是否低于阈值，对象拓扑当然可能改变。不能宣称所有形式的输入扰动都没有间接选择效应。

沿距相位只用实际相邻且两端均可靠的测量；训练相位对两端都必须在同一个非目标参考块内。圆周增量不受360°环绕影响，不跨缺测解缠。

状态包括：未观测、未提出、参考不足/模型失败、目标不相容、天气冲突、源模型暂占优、无界宽域未决。没有“normal=true”的隐式默认。几何不可用的有效测量保留实测身份，候选弃权，不把它改成原始缺测。

天气反证不能保证零误隔离。特别是输入矩完全相同的真实窄雨带和相干异常，本方法无法区别。测试中明确保留这一反例：实验隔离可能发生，但确认污染始终为0。没有用“测试全部通过”掩盖该不可识别情形。

## 5. 数据及实际动作

五例仅有去标识化最低仰角、没有真实时间/定位、全体积、SQI、IQ/谱和完整气象真值。不得用相邻case当确定等时间序列，不进行跨站地理配准或改变高程基准。

审计产物和实验产物单独存储。实验隔离门：QC_ACTION=DOWNWEIGHT，RFI_QUARANTINE_MASK=1，QPE_ELIGIBLE_MASK=0，定量DBZH为NaN；原始DBZH不变。没有NON_METEOROLOGICAL或RADIAL确认原因。所有保留门的基线数值逐字节不变，原有拒绝/隔离永不恢复。

若有生产QC_FLAGS，由调用者传入该版本LOW_QUALITY位；没有正确flag不能构造伪生产Decision。附件缺失的QC_FLAGS没有被编造。

## 6. 接入边界（重要）

`evaluate_native(native, baseline, model=..., policy=..., phase_period=..., low_quality_flag=..., weather=...)` 返回新的 Decision、Evidence、Outcome，不修改参数里的原Decision。其数组顺序与传入NativeSweep一致；正式产物回到原始射线顺序时必须使用同一个native.restore，不能将内部排序索引冒充源ray。

建议先在现有离线实验/固定任务回放中调用。默认 audit 可用于严格数值不变对照。实验隔离只能写独立OC1结果契约和新作业身份；旧V7验证器依赖原来的分阶段动作账本，不能把额外动作塞进去后仍标为原V7。

本次没有修改生产 runner、规划器、基础配置、消息上限或诊断renderer。要正式发布新QCRadarVolume，还需要为新版本增加分阶段baseline/增量字段及完整Worker→Grid→Mosaic→QPE→diagnostic契约验证，由Codex在完整仓库和105完成。不要直接把本适配器结果覆盖旧QC Zarr。

默认同时提供`scalar_completion`，只有受限标量和证据/结果摘要，不含folds/对象/矩阵。详细数据存对象资产，延续现有NATS修复。

## 7. 性能与降级

核心只依赖NumPy；报告可选Matplotlib，测试可选pytest。不新引入训练库、网络服务或原生库。原生bRopo先前已实验，不在本次声称再次运行。

门段扫描O(N)，分块稳健统计约O(N log G)，横向连接只比较相邻射线真实重叠，宽度计算为O(N)；不构建全门两两图。最大门数、域和fold有预算，超限抛错且不产出部分结果。CLI在临时目录内完成全部校验后原子重命名，失败清理临时目录，拒绝覆盖已存在结果。

审计、实验和原生基线应分别计时。只保存必要全场结果，逐门可读CSV输出ROI和所有基线可见的源提议；剩余门仍保存在完整evidence.npz/outcome.npz，不缩小评估域。完整报告与绘图内存不等于实时核心内存。105 P50/P95、真实上传和上下文耗时本环境未测。

本代码是基于本项目原始数据研究的原创实现；没有移植MIT/NOAA的完整代码、参数表或私有算法，没有声称这些机构认证。仅使用NumPy公共数学算子，不打包第三方源码。研究数据不获新许可，不应随代码补丁公开提交。

- MIT Lincoln Laboratory, John Y. Cho, ATC-454 (2023): https://www.ll.mit.edu/r-d/publications/radio-frequency-interference-censoring-scheme-canadian-weather-radar 。仅借鉴分型/测量一致性的思路，缺SQI和未处理极化语义时不能复现完整方案。

- NumPy周期差/unwrap参考: https://numpy.org/doc/2.1/reference/generated/numpy.unwrap.html 。本模型实际只在有效相邻对计算模周期差，不跨孔洞调用unwrap。
- 前轮项目对象统计原型是本版直接工程起点；其结果不能当作人工标签。本版分别增加了原始域边界、目标外参考回执、天气反证、显式动作与防篡改检查。

## 9. 合并、验证和回退清单

1. 新审核分支应用新增文件补丁，保留基线与input/private数据隔离。
2. 安装最小测试依赖，执行模块测试、五例实际复算、原始inspect及real invariants。
3. 先audit核对所有baseline数组不变，再explicit experiment看真实隔离及ROI外代价。
4. 对每个残留点用source ray/gate读取fold和训练区间，检查是否跨物理对象、是否覆盖了真实天气。ROI不是标签，准确率/召回率保持null。
5. 同renderer、同资源、同上下文做正式受控回放；五例是开发集，不是独立验收集。高程资料不更名、不伪造成已转换。
6. 依人工签核，建立不同日期/过程的天气、混合区和污染标签；在看holdout结果前冻结可容忍损失。没有标签不自动提升。
7. 默认关闭不改变生产。回退只需不调用模块/使用audit，保留历史结果；不删除原始资料或最后可用资产。
