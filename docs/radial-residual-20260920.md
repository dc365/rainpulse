# 径向残余片段检测

这是下一版候选配置，默认运行配置保持关闭；部署时使用独立 profile 标识。

冻结已有独立干扰证据为锚点，在同一射线和相邻射线内跟踪短残片。跟踪使用 5 km 距离步长，边界每步最多移动一个波束宽度，距离锚点最多 40 km。天气保护门、方位缺口和无观测门会阻断跟踪；缺测只可约束已有锚点对象，不能单独生成污染证据。新增片段不会成为后续锚点，也不会补值或擦除整条射线。

输出保留门级处置掩膜、边界、尺度、锚点距离、父锚点编号，继续进入既有 QC 隔离和可信度链路，图片只是这些数据的渲染结果。

本地相关测试 224 项通过。105 服务器只读回放结果：09:00 新增 323 个可信门、09:12 新增 619 个、15:30 新增 36 个；天气保护门和缺测门均未改变。这只是提案回放，完整 worker 重算和图片效果需要部署后验证。
