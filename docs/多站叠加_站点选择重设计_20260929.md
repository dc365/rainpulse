# 多站叠加/组合反射率 站点选择重设计（2026-09-29）

## 问题诊断

1. **"S 全部 / X 全部 / S+X 全部"点击无反应**：`select()` 只做"追加"——当该波段站点
   已全部勾选时，点击后集合不变、界面无任何变化；按钮无按下态、无计数反馈；
   超过 32 上限时静默截断。
2. **两套波段概念重叠**：「筛选波段」下拉（只过滤列表）与三个「全部」按钮（批量追加
   勾选）语义相近但行为不同，用户无法区分。
3. **同一批站点出现在两个列表**：上方"站点与图层"目录复选框负责勾选，下方"显示图层"
   才有仰角/透明度/上移；勾选后必须滚到下面才能调整；且注明"列表末项在上方"（反直觉）。
4. **组合反射率模式复用整个侧栏**：该模式地图只渲染"已发布组合产品"，逐站仰角/
   透明度/顺序控件不产生任何视觉效果，是死控件；两种模式的站点选择用途不同却无说明。

## 两模式的站点选择是什么关系（写入 UI 文案）

- **多站叠加**：勾选站点 → 各站原始/质控 PPI 图件按站点中心叠加显示；逐站仰角、
  透明度、叠放顺序直接控制图面。
- **组合反射率**：浏览的是**数值组合产品**（S 组合 / S+X 组合 / 对照），图面不渲染
  逐站图件；此时勾选站点的用途只有两个：①地图点查的源数值图层；②作为「生成组合」
  提交重算的雷达清单。

## 新设计

A. 选择区合并为一组控件：搜索框 + 波段分段筛选（全部 / S 站 / X 站，按下态）+
   **全选（切换语义：当前筛选已全选→"取消全选"，带 aria-pressed）+ 清空**；
   全选作用域 = 当前筛选可见站点；头部显示「已选 N/32」。
B. **单一站点列表**：目录行即控制行。未勾选 = 一行；勾选后行内展开状态与
   仰角/透明度/上移/聚焦距离圈控件；删除第二个"显示图层"列表。
C. **列表顺序 = 叠放顺序**（第一行在最上层），"上移"沿显示方向，删除
   "列表末项在上方"说明。
D. 组合反射率模式：隐藏逐站仰角/透明度/上移/距离圈控件，侧栏顶部注明
   "勾选站点用于『生成组合』与地图点查"；地图工具保留「定位产品」。
E. 会话中已失效的站点选择自动清理；上限 32 保留，到达后未选站复选禁用。

## 验证

- 测试：分段筛选 + 全选切换（全选 4 → 取消全选 0）纳入 overlay 直达回归；28 站全选
  用例改走新「全选」；全量 153 用例、build 通过；lint 回到既有基线
  （顺带把渲染期 setState 调整为官方 derived-state 模式，避免新的 effect 级联渲染告警）。
- 105 就地部署（index SHA 前 16 位 `254ee2b82cdafbee`）实测：
  全选 → `已选 28/32` 且按钮变「取消全选」；取消全选 → `0/32`；
  「S 站」过滤 + 全选 → `4/32`（作用域正确）；组合反射率侧栏无仰角/透明度/距离圈
  死控件，顶部显示用途说明。
- 兼容：sessionStorage 旧图层配置中 `visible:false` 加载时归一为显示（新设计不再有
  独立"显示"开关）；站点目录变化时自动清理失效选择。

## 追加（2026-09-29 第四批）：组合反射率去除站点选择

用户定论：组合模式没必要逐站选择。落地：

- 组合反射率侧栏不再渲染站点选择区（搜索/波段筛选/全选/站点列表全部隐藏），改为
  标题「组合反射率 · N S + M X 全部参与」+ 一行说明（全部站参与、点查看产品源数值）。
- 「生成组合」链接的 radar 清单改为**全部已登记站点**（此前依赖勾选状态）。
- 组合模式下逐站 X 图层解析 fetch（radar-layer-resolutions）不再发起（无渲染消费，
  纯浪费请求）；多站叠加模式的该 fetch 行为不变。
- 105 实测：侧栏 0 复选框、标题「4 S + 24 X 全部参与」、生成组合链接含全部 28 站。

## 边界

仅改 `apps/web`（MultiStationMap.tsx、radar-qc-workspace.css、相关测试）；产品计算、
探针、组合生成入口与后端契约不变。
