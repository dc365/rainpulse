# 工作台时间选择

头部区分实时监测和历史案例。实时入口要求目录标记为实时/业务运行、数据年龄在十五分钟以内，且起报时间也在最近十五分钟内；历史结果不因影子运行标签被视为实时。

历史案例按北京时间日期分组，点击日期后选择已有结果的起报时次。前后按钮在当天已有时次间移动；不会补造缺失时次。下方时间轴继续选择该次预报的有效时刻。历史选择固定，目录每三十秒刷新以接收补算结果，但不会自动切到新起报。

沿用工作台青绿色、浅灰绿底与细边框。日期和起报时间是主要信息；可用算法与实时状态作为辅助信息，历史数据不显示实时延迟。

验证命令：`pnpm --filter @rainpulse/web test` 与 `pnpm --filter @rainpulse/web build`。浏览器验证覆盖真实目录的弹层、时次选择，以及 390 像素窄屏头部。
