# 7.3.1 共享距离项实施与回放

已实现，尚未提交、未切换生产配置。本版对应上一轮宽扇区距离项研究方案。

## 改动

- `broad_source.shared_range_term` 从 DBZH−SNR−20log10(r/km) 估计共享距离关系。每个目标块与相邻保护块均不参与；两组分离径向分别估计，检查有效数量、跨度、残差、斜率范围及组间差异。
- 不满足条件时返回零距离项，按原源模型处理，诊断明确标注样本不足、关系不支持或组间不一致。
- `observed_range` 覆盖原始几何内已有的有效距离门，取消候选模型固定 450 km 截断；不创造观测、不填补缺测。
- `range_term_folds` 保存每折次系数、两组估计及失败原因。距离项只作观测关系订正，不是新增独立污染票数。原功率残差阈值、天气及极化逐门保护不变。
- 独立 `qc-opensource-7.3.1`／`fujian-qc-broad-source-range-v1.yaml`；新开关不能借用旧版本身份。旧版默认参数及语义哈希保持不变。
- Worker、版本校验和产物验证已支持新版本；Dockerfile／Compose 候选部署文件为 `deploy/*qc-broad-source-range*`。
