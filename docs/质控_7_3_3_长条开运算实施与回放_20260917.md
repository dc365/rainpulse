# 7.3.3 长条开运算正式候选实现

已把gemini2的极坐标长条开运算接入BWS候选和现有隔离处置链路，独立配置
configs/qc/fujian-qc-radial-opening-v1.yaml。未发布生产，代码未提交。

- RAW DBZH>35dBZ；方位×距离数组使用(1,N)足迹，50km换算门数并取不小于该长度
  的奇数（250m门宽为201门），避免偶数足迹锚点偏移。缺测及数组外为false。
- 使用scikit-image 0.26.0 opening，运行时校验版本；没有抄写形态学算法。
- 必须先有留出源功率模型及角向参考支持，再通过逐门功率/SNR限制。
- 长条且符合源模型、但原极化包络不符的门可疑隔离，不新增确认RFI。
- 原始值保留；通过既有链路降低QI、排除QPE/DBZH_USABLE。天气、局地增强、
  几何不可用和数值平台仍阻止新增隔离。
- BWS_REASON bit64记录形态支持；若其弥补极化匹配失败，bit16仍保留。
  bit64表示候选支持，不表示最终删除或污染真值。实验/审计模式与预算复核保留。
- 旧版本开关默认关闭且不进入旧参数哈希，注册7.3.3至profile/worker/validation。
