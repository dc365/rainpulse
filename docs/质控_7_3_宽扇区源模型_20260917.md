# 7.3 宽扇区源模型：实现与小样本回放

2026-09-17。候选代码已实现；105 生产仍为 7.2.0，本报告不是上线或气象真值验收。

## 实现

独立模块 `algorithms/rainpulse_algo/radar/qc_engine/broad_source.py`，配置 `configs/qc/fujian-qc-broad-source-v1.yaml`，版本 `qc-opensource-7.3.0`。保留旧版相干源阈值和身份哈希，独立假设允许更宽的极化分布；不是 MIT/NOAA 算法复刻，也不是已校准的 RFI 概率。

1. 在原始极坐标 DBZH/SNR/RHOHV/ZDR/PHIDP 上建模。检验 DBZH 随距离的 20log10(r) 关系、SNR 距离块中值稳定性及极化分布。
2. 50 km 目标块和两侧保护块不参与参考拟合；至少五个有效参考块、200 km 跨度。目标门自身须通过参考模型预测，不能整片删除。
3. 相邻径向的参考拟合也须一致，至少三条且覆盖三度；几何缺口阻断关联。参考平台识别局限在参考块，避免目标修改影响参考选择。
4. 独立天气支撑、局部增强、缺测及未证实的数值平台保持保护。默认 audit 不改变动作；独立实验配置才隔离，清除定量可信掩膜，不添加确认 RFI 标记。超预算记录需复核，不偷偷恢复至 QPE。
5. 输出 BWS_CANDIDATE_MASK、BWS_REASON、BWS_FOLD_ID、BWS_RANGE_RESIDUAL_DB 及折次拟合记录；已接入 Worker 版本、参数哈希、产物验证。候选 Dockerfile/compose 已准备。
