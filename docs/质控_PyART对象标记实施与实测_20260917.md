# Py-ART 原始对象标记：实施及105实测

已实现 `qc_engine/object_morphology.py`，复用 Py-ART find_objects，不重写连通标记。
固定20/35/45/55dBZ分别输出标签及对象记录；不平滑、不插值、不改变QC动作。
按内部几何断点切段；仅连续全PPI允许首尾连通。对象特征包含测量门数、距离跨度、
圆周角度跨度、中位距离处横向跨度、已有源功率残差支持。所有数值仅为审计特征。
单径向横向中心跨度为零；aspect分母以距离门宽下限防除零，不应解释为真实物理
长宽比或直接删除依据。源残差缺失显式记录，不当作零或正常天气。

## 105 四例最低仰角回放

原始对象在RAW上标记；剩余门使用7.3.2增量可用掩膜。源功率残差来自7.3.1缓存，
该部分功率模型与7.3.2相同，但不是独立真值或重新拟合验收。
每例四阈值对象计算约2.58–2.68秒，不含完整流水线。四例均完成。

10:48约99.65%的统计域残留属于同一原始宽扇区对象；该对象有源残差的265286门中，
99.988%的功率残差≤2.5dB。10:42相应147597门中99.999%符合。
这些比例不等于确认污染率：功率一致、对象连通和极化一致属于相关源假设证据。
不能因此整对象删除，仍要保留逐门天气/增强冲突及模型不确定性。

10:42还有单径向13.5km、11km的独立高值段，没有现存源功率参考；不能靠小对象
尺寸或高aspect直接删除。10:48剩余23门在两个其他对象内，也缺源参考。
Z9598两例没有该高值域残留，不能作为真实降水误删率证明。

## 下一步应收敛到什么

优先围绕已识别宽扇区对象建立局部同源支持：把待审门与同对象、同距离的可靠
参考片段比较，明确哪些因供体不足、供体组不一致、极化越界或外部天气保护残留。
不要再把主要算力投入“去更多小斑点”。对象身份只能限制参考域，不能替代逐门
污染证据。独立细线仍需要单独留出拟合，缺证据只审计。

本轮未实现跨片段关联、边界回指原点拟合或新增逐门处置，也未替换生产7.3.1。
