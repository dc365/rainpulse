# 宽扇区距离项：根因、离线验证与下一版方案

## 结论

本轮为研究排查，不修改生产算法、不部署、不发布图层。105 对两站两个时次完成八次低内存增量阶段回放。找到可验证的主要模型遗漏：7.3 的 `broad_source.infer_broad_source` 仅使用 `DBZH - 20log10(r/km)`，未消除原始数据中稳定的线性距离项。该遗漏使许多真实观测参考块超出功率残差阈值，无法进入后续源模型。其次，450 km 固定上限漏掉实际观测末端。

这解释了当前宽扇区主要残留，不代表解释了所有细线、碎片和历史误删。

## 可实施方案：先校正观测关系，再判断源

模型采用 `Z_source(r) = c + 20log10(r/km) + a*r_km`，但禁止给每条疑似径向自由拟合 a 来强行匹配天气。

1. 用成对矩 `DBZH - SNR - 20log10(r/km)` 估计全切面共享的距离项。每个目标块及相邻保护块均从估计中排除；用两组分离径向独立估计，两组必须一致。
2. 本次试验要求每个距离至少五条有效径向、至少一百个有效距离门、参考跨度至少 200 km；两组斜率差≤0.002 dB/km、各自拟合残差 p90≤0.5 dB、斜率在 [0,0.03] 内。条件不满足则不启用该订正。这些为现有配对距离项实现边界，正式版本仍需冻结与回归测试。
3. 距离项只消除数据处理关系，不作为独立 RFI 证据。保留原来的源功率残差阈值、极化逐门检验、几何断口和天气保护。
4. 处理范围根据有效原始距离与雷达配置确定，不固定在 450 km。本次敏感性试验将上限设为 500 km，但仅处理原始已有观测，没有外推或填充新门。
5. 记录每个留出折次的 a、参考跨度、组间差异、失败原因与订正前后残差；单独版本和配置哈希。源码已有 `fragment_radials.estimate_range_term` 提供思路，但它使用全距离，本模块必须增加目标／保护块留出，不能直接照搬调用。

## 剩余门与验收

不能继续把剩余门全部按“未清干净”删除。下一步需区分源与天气混合、数值量化及极化分布随距离变化：对现有目标失败门提取局部沿程 rho 方差、PHIDP 圆方差以及目标功率增强，只有在已有源对象范围内判断动作。不得用扩张掩膜填满整片，不得把缺失邻站当作无雨。当前四个保存样本的邻站／垂直支撑有效门为零，是误删验收限制。

成熟路线参考 MIT Lincoln Laboratory ATC-454：先识别污染径向，再逐门判断，并设置极化、尖峰与散点的不同处理路径。其 SQI、原始相位及厂商 KDP 缺测语义与本项目不能直接等同，不能用 SNR 代替 SQI，也不能照搬加拿大设备阈值。
https://www.ll.mit.edu/sites/default/files/publication/doc/radio-frequency-interference-censoring-scheme-cho-atc-454.pdf

正式实现应补充：目标／保护块扰动不改变距离项的回归测试；跨径向组不一致回退；缺测保护；真实正常降水及源天气混合负例；全体扫重放；质控数据和诊断图同版本发布。本次尚未满足全面误删验收，也未切换生产。
