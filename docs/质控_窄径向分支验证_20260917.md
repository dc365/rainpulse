# 窄径向分支验证

实现 narrow_source.py 独立候选模块，未接入生产动作或新发布版本。
要求RAW>35dBZ连续50km、留出源参考和功率残差≤2.5dB，以及两侧真实回波均低
至少10dB且反差连续20km。缺测侧、几何缺口、坏径向与天气冲突不能作为通过。
开运算复用scikit-image；单项新增测试与已有开运算2项测试通过，Ruff通过。

105使用临时 broad_source_probe 提前记录角向支持检查前的残差，仅增加诊断，
没有取消宽扇区门槛。四例增量可用门基于7.3.3。此审计未传天气冲突，是形态与
源证据的候选上界；因候选全为0，不涉及天气保护之后的实际新增隔离。

- 10:42高值剩余341，源参考不可用/不符340，两侧缺测或几何无效335；候选0。
- 10:48高值剩余1596，源参考不可用/不符23，两侧缺测或几何无效999，另591门
  不满足两侧高反差；所有门都未形成20km连续双侧反差，候选0。
- Z9598两个对照候选0。
以上原因可重叠，不能相加当分类总数。

东向线集中在80.83°，其中1317个高值门仍可用。按相邻约1度的初步探针，
仅335门两侧同时有数值，中心相对两侧最大值的差中位数为-6dB。这不符合
典型双侧低背景的正尖峰假设。较强相邻扇区与缺测边界解释了为何形态像细线，
却不能用“高出两侧”规则识别。

结论：本轮没有清除效果，不宣传新增改善。下一步应研究同源扇区的边界延伸，
结合逐射线源拟合与相邻已识别源的关系，而不是不断降低双侧反差阈值。
仍需排除源叠加区的真实降水；不能把缺测设成0dBZ或直接允许所有单径向通过。
