# 质控排查：左下角面板改为雷达拼图

## 结论

质控排查预设四同步图的第 3 格（左下角）默认从“质控标志”改为“雷达拼图”：RP-010
质量感知、时间对齐的多雷达反射率拼图在目标网格上的 `DBZH_QC` 场（诊断层
`grid-dbzh-qc`，工作台面板 `analysis:dbzh_qc`）。质控标志不删除，改为同一格内的两态切换，
默认值仍是拼图。

2026-09-16 用户口径：默认雷达拼图，另给一个按钮可手动切换为质控标志。

## 现状

质控排查 = 四同步图，顺序取自 `panelsForPreset(detail, 'qc', radar).slice(0, 4)`：

| 位置 | 面板 | 内容 |
|---|---|---|
| 左上 | `dbzh_raw:<雷达>` | 单站原始反射率（极坐标 PPI） |
| 右上 | `dbzh_qc:<雷达>` | 单站业务质控后反射率（极坐标 PPI） |
| 左下 | `qc_flags:<雷达>`，缺失回退 `analysis:qc_flags` | 质控标志位（分类调色板） |
| 右下 | `qpe` | 雷达 QPE 雨强 |

标志位图只回答“这一门被哪个原因标记或剔除”，不回答“多站合成结果是否被质控伤害”。排查动作的
落点应当是拼图，所以左下角应显示拼图。

## 为什么是 analysis:dbzh_qc

- RP-010 `RadarMosaic` 是质量感知、时间对齐的反射率拼图；`DBZH_QC`（dBZ，缺测为 NaN）
  就是拼图反射率，融合规则为同质量线性 Z 融合、QI 加权，禁止 dBZ 直接平均。
- RP-011 QPE 消费该拼图并发布 `RadarAnalysis`；工作台诊断层 `grid-dbzh-qc`（标题“质控反射率”）
  渲染的是同一字段。
- 工作台面板 id 由 scope 决定：`scope=grid` → `analysis:<field 小写>`，因此拼图面板是
  `analysis:dbzh_qc`。
- 该网格诊断层是强制的（7 层 `requiredGridFields` 含 `DBZH_QC`）。不需要新增后端数据、
  契约或重算，本次是展示层改动。

## 面板表达

- 标题 `雷达拼图`：服务端 display_name 仍是“质控反射率”，由前端在拼图面板上覆写为业务叫法。
- 角色标签 `多雷达拼图`，角标沿用 `分析`（lifecycle=analysis）。
- 上下文行：`多雷达拼图 · 质控反射率 · N 站参与`，N 取 `detail.radars` 中
  `state=PARTICIPATING` 的数量。
- 图例：沿用 `grid-dbzh-qc` 的 dBZ 连续色标（scale 模式，单位 dBZ），不再出现标志分类图例。
- 底注：`拼图按 QI 融合单站质控结果；空白为缺测或低质量剔除，不代表无雨`。保持
  “有效无雨 / 缺测 / 低质量”三态，绝不把缺测转成零。
- 点值探测沿用现有实现，读的是图层 PNG 上的 dBZ 分类值，不从颜色反推雨量。
- 空态：`该分析时次尚未生成雷达拼图。`

## 阅读顺序

单站原始 → 单站质控 → 多站拼图 → 雨量产品：从证据到结论。前两格共用所选雷达的站点视图
（距离环、站点标记），拼图与 QPE 使用各自的栅格范围，便于直接判断“单站被剔除的东西是否
仍留在拼图里”。

## 证据图层切换（保留质控标志）

单图菜单只列出当前预设的面板，所以如果左下角直接换成拼图，“质控标志”在质控排查里将完全
不可达（只剩 `/qc-review` 页面）。因此第 3 格做成两态切换（工具栏“证据图层”一组两个按钮）：

| 选项 | 面板 | 用途 |
|---|---|---|
| 雷达拼图（默认） | `analysis:dbzh_qc` | 多站合成结果 |
| 质控标志 | `qc_flags:<雷达>`，缺失回退 `analysis:qc_flags` | 门级原因与剔除 |

- 只显示当前周期确实存在的图层，避免死按钮；选择失效时自动回落到首个可用项。
- 切换只影响第 3 格：左上、右上、右下和时间轴位置不变；时间轴可用性条与单图菜单跟随该选择。
- 工具栏多了一组控件，宽度不足时整条控制栏允许换行（`.qc-controls`），窄屏下证据切换可横向滚动。
- 切换时清空点值探测和图层错误状态，避免把上一个图层的点值或错误留在新图上。

## 降级

- 拼图层缺失（诊断降级、旧周期、仅 QC 重算未出图）→ 第 3 格回退到 `analysis:qc_flags`，
  仍保留质控标志视图。
- 单站极坐标面板缺失 → 沿用现有回退逻辑（退到该周期实际存在的质控面板）。
- 加载失败 → 沿用现有图层空态与重试提示。

## 不做

- 不改后端契约、诊断层集合、拼图或 QPE 算法，不重算历史。
- 不把标志做成拼图上的半透明叠加层：`RasterGISMap` 当前是单栅格层，叠加需要新的图层能力和
  调色板冲突处理；需要“为什么这一格被剔除”时用“质控标志”切换或 `/qc-review`。
- 不改拼图时间轴：拼图只存在于已有分析周期，时间轴口径不变。
