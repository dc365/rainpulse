## 4. 阶段说明

### A 阶段

A 阶段的核心目标是修正确定性软件缺陷、冻结上下文与审计边界、去掉重复验证/解压、补基准与可观测性。本轮确定的软件缺陷已修复，不依赖 C 阶段物理资料才能开展软件回归。对应复审、隔离验证与性能证据集中在《雷达质控优化_复审修复与验证_20260908.md》。未以本地合成通过替代服务器性能或真实气象效果验收。

### B 阶段

B 阶段已经完成“诊断与离线工具”层面的交付，但没有越权声称取得真实业务效果：

- B1 只新增 texture 与 circular-variance 诊断，不改 `P_METEO`、QI 或硬 flags；
- B2 只新增 geometry-aware trusted support 诊断，不开启新的负晋级；
- B3 已具备标签清单、Beta 平滑静态杂波先验与 promotion 汇总能力，但真实标注资产仍待独立准备。

### C 阶段

C 阶段当前全部以 fail-closed shadow/offline 方式推进：

- C1 已能在离线与 QC 影子链路中生成 `PHIDP_SHADOW_*` 与 `KDP_SHADOW*`；
- C2 已能离线生成衰减、相对偏差与校准证据，并通过 worker 可选接线保留 default-off 边界；
- C3 已新增显式输入层状 VPR-QPE profile，默认不改变 RP-011 行为，只能在上游显式提供 `PRECIP_TYPE`、`MELTING_LAYER_BOTTOM_HEIGHT` 与 `MELTING_LAYER_TOP_HEIGHT` 时工作，且 far-range overshoot 保持 missing。
