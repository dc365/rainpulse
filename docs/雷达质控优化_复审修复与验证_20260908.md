## 4. 性能实测与限制

同机合成单层 360×1840，2 个同站上下文、2 个邻站输入，seed=47，预热 1 次、测量 7 次，使用内存对象存储模拟。前后保持相同尺寸和运行方式，算法版本有科学行为修正，不能称为科学输出等价的性能对照。

| 指标 | 修复前 | 修复后 |
|---|---:|---:|
| core 中位耗时 | 1.1219 秒 | 1.1100 秒 |
| 模拟 pipeline 中位耗时 | 1.5418 秒 | 1.5162 秒 |
| 进程最高 RSS | 391.875 MiB | 437.375 MiB |
| 每层 DBZH 实际读取次数 | 3 | 1 |

读取次数减少已有确定性证据；耗时差异很小，不宣称显著加速。进程最高 RSS 在此样本中增加约 45.5 MiB，不能宣称内存下降。共享只读解码视图保留任务内数组，并不等于降低整个进程的最高内存。单层合成试验不替代多仰角体扫、真实 MinIO/网络、目标服务器并发和长期 RSS 验证；当前缓存预算和默认并发未因此提高。
