## 3. 总体设计与固定决策

```text
Go 时间窗查询与输入冻结
          |
          v
QC Worker 读取/校验 normalized 与上下文
          |
          v
一次解码 + 可观测性/几何检查
          |
          v
形态候选 --> 双偏振/时间/垂直/邻站证据
          |                    |
          +--------+-----------+
                   v
            统一最终裁决
                   |
                   v
 原值 + 原因flags + 分量QI + 判决溯源
                   |
                   v
 QC Zarr构建/一次完整校验/原子发布
                   |
                   v
        Hybrid --> mosaic --> QPE --> LK
```

固定以下决策，实施者不再另选大架构：

1. **保留现有 QC 入口和数据合同骨架，新增版本化裁决路径。** 不重写成另一套雷达平台，不一次性替换为 wradlib/Py-ART。
2. **先产证据，最后裁决。** 多尺度、闭合、边缘、残余模块不得反复覆盖最终硬判结果。
3. **未知证据为 NaN/不可用。** 任何时间、几何、字段、遮挡或健康校验失败，减少证据可用性，不增加非气象证据。
4. **第一批不启用新的垂直负证据和邻站负证据晋级。** 当前物理可比性不足。可信邻站正支持可保护弱候选；负证据须等 B2 的门控及独立验证。
5. **性能先保科学输出等价。** 数值行为变化只由新算法版本承载；索引、缓存、并发和存储优化需要单独等价检验。
6. **最小可用交付是 A1 至 A4。** 它能够修正确定性问题并移除大矩阵，独立上线到工程影子；A5 之后逐步增加，不等待真实标签才能修复软件错误。

最脆弱假设是“跨站/高层观测与当前低层天气具有可比性”。方案通过先关闭其负证据晋级、保持诊断与正支持、在后续增加三维可观测性门控来避免依赖这个未经验证的假设。

## 5. A1：证据结构与统一裁决

**目标文件**：`qc.py`，新增 `qc_decision.py`，QC schema、新 profile、QC 数据合同、`test_radar_qc.py`，新增 `test_radar_qc_decision.py`。

内部每层证据必须至少包含：

- `observed_mask`：当前 DBZH 有限、范围合法；每个辅助 moment 另有可用掩码。
- `candidate_mask`：候选门，不代表最终剔除。
- `candidate_reason_bits`：邻差、饱和、形态段、extent、multiscale、fan/edge/residual，使用独立 uint16 诊断位图，不能混入业务 QC_FLAGS。
- `strong_seed_mask`：只来自饱和物理判据及 A2 规定的双侧正邻差强段。
- 时间、偏振、垂直、邻站证据值及各自可用掩码；缺测值用 NaN。
- `meteo_veto_mask`：可信邻站正支持作用于当前候选。
- `hard_mask`、`soft_mask`、最终原因，以及显式 `override_reason`。

裁决顺序固定：

1. 无效当前观测不参与候选和干扰 flag；保持 missing/hardware 语义。
2. 强种子门保留硬判。若强种子与邻站保护冲突，可按明确例外保留强判，但记录 `strong_seed_overrides_cross_support`；这是保留已有高置信检测的显式工程例外，需要在真实验证里单独统计。
3. 其他候选若有有效气象 veto，最多为 soft，不得经后处理变成 hard。
4. 不含 veto 的 weak 候选，要求至少两类可用证据，其中形态只能计一次。初期可使用“形态+合格历史持续性”；垂直/跨站负证据开关为 false 时不计数。
5. fan、edge 和 residual 只能由本轮已经确认的原始强种子提供锚点，并要求原有本门/本射线几何特征；本轮晋级结果不得反复作为新种子无限扩张。存在 veto 时不晋级。
6. multiscale 作为形态补充，不能单独绕过两类证据门槛，也不能推翻 veto。
7. 最后一次性写概率/score、INTERFERENCE_TYPE、RADIAL_INTERFERENCE、LOW_QUALITY、QI_INTERFERENCE。避免通过“先写硬概率，再改 flags”留下不一致。

只在实际受影响门上记录硬判；“整条射线扩展”必须满足独立明确的整条轨迹规则并记录原因。0.65 与 0.80 沿用当前分数含义，不能把 0.80 描述为 80%的统计置信度。

摘要给出候选门/射线、硬判门/射线、soft 门、veto 保护门、强种子覆盖 veto 门，各最终原因门数。候选类别允许重叠，最终类别必须互斥；总数可以从数组重新计算并一致。

## 6. A2：邻线扩杀与缺测修正

### 6.1 双侧正邻差

v2 窄径向强种子不再使用 `abs(current−邻线均值)`。

对每个门分别比较当前值与左右真实相邻射线。两侧均有有效观测且当前分别至少高 12 dB，才进入强段候选。左右必须是不同射线；缺一侧时保留单侧诊断候选，不做该强判。相邻按实际方位排序并检查角距，不能把缺口两侧当正常相邻；第一批使用当前映射容差 0.75°的两倍作为最大相邻间距 1.5°，这也是版本化工程参数。

强段还须满足现有有效门比例 0.55；双侧超差候选在双侧共同可观测门中占比至少 0.50，且连续候选长度达到现有 80 门。硬标仅落在满足连续段条件的候选门。短于 80 而达到形态 12 门的段保留 soft 候选。

对当前 250m 门距，80 门对应 20km。第一批不改变已有门数阈值的含义；新增站型前再统一转换为物理长度。正负异常分离，负向条纹只作诊断。不要仅把 abs 删掉仍保留污染均值和全射线硬标。

### 6.2 高层缺测与垂直场

在 v2 路径，分离 `observed_high` 与 `echo_high`：观测范围内合法有限值是可观测，达到现有 `minimum_dbzh=10` 才是支持回波。上层全 NaN、无匹配方位、量程不覆盖、仰角不匹配都返回 unavailable。

A 阶段只计算诊断，不根据高层低 extent 增加负证据。`vertical_consistency.mode=diagnostic_only` 与新增负证据开关必须同时被遵守。

禁止量程外最近门夹取。低层 150km、上层只到 50km，匹配结果不可用。方位缺口不得任意跨越；下一层缺 DBZH 不能因数组占位产生 0 支持率。

即使高层有限且无雨，也不自动否定低层浅层降水。B2 补齐波束和云层可比性后才能研究负证据晋级。

## 7. A3：时间上下文与冻结身份

**文件**：`services/control/cmd/orchestrator/main.go`、`main_test.go`、`services/control/internal/postgres/radar_store.go`及测试，`qc_worker.py`，拟新增 `qc_context.py`，QC 配置 schema 和相应合同测试。

### 10.4 缓存

候选缓存只存紧凑特征，不缓存整个 QCResult。几何缓存只存映射和可观测掩码，DEM 缓存保持验证后的 tile/遮挡。都采用按字节计费的 LRU，总预算分开：候选 64MiB、几何 128MiB、DEM256MiB，每项大于预算直接不缓存。

缓存键包括工件内容摘要或实际站点+全坐标+DEM 版本/摘要+地球模型+网格+算法参数摘要。仅用 radar_id/sweep_name 作键不合格。客户端/文件句柄不得跨不兼容进程复用；并发同键计算要避免重复占满预算。返回只读视图，禁止调用方污染缓存。

DEM 无资产、校验失败或缓存未命中，走既有降级/读取路径，不能伪造遮挡 0。

## 13. B 阶段：可实现的诊断与数据工具

### B1：偏振纹理与相位诊断

### B3：冻结标签、静态杂波与晋级工具

新增离线数据 manifest/schema 和构建命令，按天气过程分开发/保留集；同一过程的前后扫描与上下文必须属于同一分区，不能按门随机切分。需要样本类别：晴空、AP/海杂波、浅层暖雨、层状雨、强对流、台风/山地、干扰叠加降水。每类至少 3 个独立过程才允许报告该类稳定比较；不足时该类状态 insufficient_data，不靠重复扫描凑过程数。

标签取值：0=确认气象、1=确认非气象、−1=不确定/不评价；记录标注者、资料来源、版本和复核状态。保留集在配置/代码冻结后才读取。MRMS 短临 holdout 不替代本地极坐标标签。

静态杂波图只用经独立天气证据筛选的晴空资料，按站/仰角/几何统计“有观测次数”和“达到 10dBZ 次数”；采用 Beta(1,1)平滑得到先验 `(hit+1)/(observed+2)`，同时输出支持计数。至少 20 个晴空日且该门≥200 次有效观测，否则该门先验不可用。10dBZ 与支持数是离线工程起点，版本化记录，不直接转成 GROUND_CLUTTER 硬 flag。

海/AP 工具生成海岸距离、地形、波束高度和时序/偏振特征；不创建“海面=杂波”的概率图。未取得多过程标签时不训练分类器、不填假资产 URI。

拟新增晋级配置 `configs/verification/fujian-qc-promotion-v1.yaml`，默认只用于工程候选比较：按过程 bootstrap2000 次、seed 固定，要求异常 precision 及 recall 差值的 95%下界≥0、气象保留率差值下界≥−0.005、QPE RMSE 比值 95%上界≤1.02，并报告强回波≥40dBZ 子集和各过程类别。缺标签或配对雨量站时相应门禁不可通过。上述数值是本方案提出的工程非劣门槛，不是已获气象业务方批准的准入标准。

任一关键子集显著恶化不得用总体平均抵消。运行参数保持冻结，用新过程复评，禁止看过保留集后反复调阈值仍称独立验证。

## 14. C 阶段：物理订正的实施规格与数据门槛

C 阶段与 A 的软件修正分开交付，每个模块单独版本、原值、订正量、可用 mask 和 QI。满足数据前置条件才实施启用，不让实施模型随意补物理常数。

### C1：PHIDP 处理与 KDP

前置：确认各站 PHIDP 单位、周期、系统相位资料和源保留码；有涵盖强雨/缺测/相位折叠的真实对照资料。

流水线固定为：可信门筛选→连续有效段划分→系统相位估计/扣除→段内相位解缠→鲁棒局部拟合→KDP 与不确定度。禁止跨长缺测段拟合。以距离 km 为自变量，KDP 为相位梯度的一半；PHIDP 单位 degree，KDP 单位 degree/km。

对照 wradlib 已实现的 PHIDP/KDP 方法，先以独立离线适配器验证，不立即增加主 Worker 依赖。系统相位无可用估计时标不可用，不能默认为 0。拟合窗口和过滤门槛由真实开发集冻结；没有这些资料时只完成 B1 诊断，不启用伪订正。

必测常相位 KDP=0、线性φ=φ0+2kr 恢复 k、相位跨 360、噪声/离群点、非均匀门距、缺测断段、短段、单位转换、所有失败时原始 PHIDP 仍存在。

### C2：站间标定、衰减、湿罩

前置：C1 已通过；站点波段与硬件参数冻结；有可信重叠观测及雨量站/标定参考。当前四站是 S 波段，禁止直接搬 C 波段 a、b 系数。

站间偏差仅在时间/三维/遮挡都可比的降水门估计，以按过程分组的稳健中位及区间报告，不凭两个站差值就判断谁错。没有绝对参考时只报告相对偏差，不擅自把某站定为真值。

衰减优先对照 Py-ART ZPHI 或基于可信 KDP 的路径积分，使用版本化站点/波段系数表与适用温度条件。显式限制订正总量，超过适用范围降权/跳过，不通过巨大放大补齐。湿罩需要站域一致偏差和外部支持，不能把区域真实弱雨误当设备衰减。

输出原值、订正值、订正 dB、算法/参数版本、适用 mask、跳过原因、QI_ATTENUATION/QI_CALIBRATION。必测无衰减恒等、恒定 KDP 积分、缺测不跨段累积、严重遮挡不放大、系数缺失跳过、订正后极值边界。

### C3：融化层、亮带、VPR 与 QPE

前置：温度/冻结层或可信垂直资料，多个层状雨和对流过程，配对雨量站。没有温度资产时仍保留偏振诊断，不用单一猜测冻结层高度硬删混合相态。

先识别降水类型和融化层，随后只在模型适用的层状场估计 VPR；对流默认不做层状 VPR 外推。保留原始与订正反射率、垂直剖面参数和外推不确定度，远距越顶无观测时保持 missing。

验收比较地面 QPE、小时/过程累计雨量、极端降水分位数、按距离与地形分层偏差。校正 QPE 的雨量站与独立验证雨量站分离；同一观测不能既调参又作为独立真值。

C 阶段完成标准是物理模块和真实独立验证均有证据。缺资料是明确的数据阻塞，不能把开关关闭的空实现算算法完成。

## 16. 发布、回算与回滚

代码合并与启用新 profile 分开。先部署能同时读 legacy/v2 的代码，旧 profile 仍可执行；验证后再切换 QC profile。当前 Worker 按环境加载单一配置，切换前暂停相关新任务入队并排空/明确处理旧 profile 任务，不能让旧任务无限因版本不符重试。不要暂停其他算法队列。

影子切换需同时更新 orchestrator 与 QC Worker 配置引用，并检查环境覆盖后的实际值、profile/pipeline/config hash 和产物 provenance。真实验证选固定 manifest 下少量完整周期，覆盖每站、强干扰和无明显干扰对照；先逐周期，再扩大范围。

新输出使用新版本身份和 prefix，保留旧成功版本；必须验证 QC→grid→mosaic→QPE lineage 一致，不能新 QC 混旧 grid。当前可用结果在新链路成功前不被清除。全历史回算只在用户授权和磁盘预算明确后执行。

回滚恢复旧 profile 和对应兼容代码/旧成功产品引用，不删除 raw/normalized、不回写历史 flags、不回滚不相关 NowcastNet/平台修改。新增索引属于可保留兼容结构；避免因回滚做无必要数据删除。

## 17. 交接完成判定

实施者最终报告必须分别列：

- A1 至 A8 每项完成/未完成及证据；不能只给“整体优化完成”。
- B1 至 B3 诊断工具完成度、真实数据满足情况、哪些开关仍关闭。
- C1 至 C3 是否满足数据门槛，未满足的具体数据类型和阻塞模块。
- 配置/代码/输入/context 指纹、科学行为变更、完整测试输出、性能基准、未解决风险。
- commit/push/deploy/replay 是否实际执行；没有授权或没有执行就明确未执行。

软件回归通过、工程影子回放通过、气象业务效果通过是三个不同结论，必须分别陈述。

## 18. 方法来源与使用边界

- [MRMS QC，Tang 等 2020](https://repository.library.noaa.gov/view/noaa/31698/noaa_31698_DS1.pdf)：偏振基本判据需要融化层/冰雹等例外保护。
- [wradlib 模糊分类](https://docs.wradlib.org/en/latest/generated/wradlib.classify.classify_echo_fuzzy.html)：多 moment 纹理与缺测支持；B1 自定义 MAD 不是该函数默认纹理，阈值不可混用。
- [RADVOL-QC 径向干扰，2026](https://www.mdpi.com/2072-4292/18/15/2625)：候选、多参数验证、降水重叠保护；C 波段案例不可直接搬到福建 S 波段。
- [wradlib PHIDP/KDP](https://docs.wradlib.org/en/2.3.0/dp.html)、[Py-ART ZPHI](https://arm-doe.github.io/pyart/API/generated/pyart.correct.calculate_attenuation_zphi.html)：C 阶段对照实现。
- [KNMI 实时 QPE，2025](https://essd.copernicus.org/articles/17/4715/2025/index.html)：杂波、衰减、VPR、质量融合和雨量站联合评估。
- [Zarr2 性能文档](https://zarr.readthedocs.io/en/v2.18.5/tutorial.html#optimizing-performance)：访问模式、chunk 和稀疏空块优化。

这些来源解释方法选择；本文新增默认值和验收门槛是工程方案决策，未声称来自论文或已通过福建验证。
