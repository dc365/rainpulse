# 雷达质控重设计：开源算法优先

日期：2026-09-11。状态：设计完成，尚未实现或替换线上算法。本方案取代继续围绕 Z9598 微调整径向阈值的路线；遵守 v1.1 总体架构，不新增服务、不引入训练。现有 2.1.0 仅为可回退工程基线，不视为效果验收通过。

## 1. 决策与问题边界

采用 Py-ART + wradlib 作为质控基础，直接调用其发布版本函数，不拷贝源码重写一套。自研部分限于数据适配、证据融合、业务质量标志、跨时次/邻站支持及开源基线证实漏检后的径向补充模块。

08:15、08:25、08:30 的问题按同一种跨时次失效处理，不能新增按站号、时刻、固定方位硬删除规则。已测 08:15 存在整径向覆盖率与整体平滑门槛漏检；08:25 尚无本轮逐门原因实测，必须作为强制回归样本，不能假称已解决。此前分段原型改善有限，保留实验记录，不接入生产。

最脆弱假设是双偏振字段具有可靠数值和正确几何配准。若不满足，系统退到反射率基础分类并标记能力降级，绝不伪造 RHOHV、速度或地形证据。开源库也不保证能无条件剔除全部 RFI；这必须通过同样本基线比较证明。

## 2. 算法职责

| 目的 | 默认选用 | 本系统处理 |
|---|---|---|
| 基础门过滤/多变量纹理 | Py-ART GateFilter、moment_and_texture_based_gate_filter | 记录每个变量过滤结果及可用性，避免只保留合并布尔结果 |
| 孤立点 | Py-ART find_objects / despeckle_field | 在原始极坐标连通对象上识别，记录门数/物理面积；不把强小单体自动当杂波 |
| 反射率杂波候选 | wradlib filter_gabella | 输出候选，不冒充径向干扰专用算法；与极化证据联合验收 |
| 极化非气象识别 | wradlib classify_echo_fuzzy | 统一转换为 P_METEO；保留不可判定掩码，默认权重不是已校准概率 |
| 波束几何/遮挡 | wradlib beam_block_frac、cum_beam_block_frac | 与现有 DEM/Hybrid 同输入对照后替代重复数学实现，保留资产缓存和选择逻辑 |
| 长射线/宽扇区残留 | 开源基线先行，必要时追加通用径向证据 | 使用距离分段、方位结构、时间/垂直/邻站证据；无站号白名单和固定删除方位 |

Py-ART 与 wradlib 源码及语义已查阅，见文末。Gabella 的 continuity/area 与 Py-ART 的 small-object 机制可复用，但都不能保证识别大连通宽扇区。明确拒绝“所有库输出取并集直接删除”和“换库即达标”。

## 3. 计算链与数据适配

原始极坐标 Zarr -> 输入校验/字段配准 -> 开源算法独立证据 -> 统一决策 -> QC Zarr -> DEM/Hybrid -> 拼图/QPE -> 展示诊断。

这些模块均运行在现有 Python Worker 内；Go 保持任务、重试、版本及发布控制，React 仍只调用 Go。

1. 保留 decode 和原始数据对象。按单个 sweep 构造 Py-ART Radar，避免不同距离门/仰角被强行填入一个规则三维体。DBZH 映射 reflectivity，RHOHV 映射 cross_correlation_ratio，ZDR 映射 differential_reflectivity，PHIDP 映射 differential_phase；速度仅在实际存在且配准后映射 velocity。
2. 校验单位、缩放、缺测码、RHOHV 合法区间、PHIDP 周期、方位单调/重复/缺口和扫描过渡。保持原始索引映射，结果按原序回填；不能用插值制造原本没有的观测门。
3. 完整 PPI 才允许首尾方位连通；扇扫和缺方位分别处理。按距离分辨率确定物理窗口对应门数，所有实际窗口数写入诊断。窗口跨缺口时证据无效，而不是将缺测填 0。
4. wradlib 分类字段按所冻结版本的实际函数契约适配；纹理输入与原始变量不能混淆，不能伪造不存在的 CPA、LDR 等矩。每门记录可用变量数量/权重和缺失原因。依赖升级必须运行语义测试，尤其验证气象概率方向。
5. 第一份 baseline 配置完整显式保存所冻结库版本的默认参数与启用变量；后续区域参数只在开发集统一调整，记录参数差异，不按截图单站优化。

## 4. 证据与动作分离

新增 evidence 数据：algorithm/library/version/parameters_hash、score_semantics、candidate_mask、available_mask、reason、耗时及输入字段来源。最终动作只有 KEEP、DOWNWEIGHT、REJECT、MISSING；MISSING 始终独立。

初始工程融合策略（属于候选，须通过下述验收才能上线）：

- 无效原始门为 MISSING；确认硬件故障保持已有硬拒绝。
- wradlib P_METEO ≤0.1 且至少两个有效变量族支持，并同时具有 Gabella 或 Py-ART 纹理候选，方可进入非气象硬拒绝候选。
- 单一过滤器命中、仅 RHOHV 低、仅零速度、仅海陆位置均只作为疑似证据。无足够变量时不能通过权重重归一化伪装为高置信结论。
- 高相关回波不是无条件天气真值，低相关也不等于干扰；优先保护有有效邻站/垂直气象支持的门。邻站缺测或超出可比波束高度不计为“无雨”。时间支持仅用过去数据，不能未来泄漏。
- 去孤立点须联合非气象证据或经过验证的孤立弱噪声判据；强小单体仅诊断，不直接硬删。
- 一般非气象候选不得贴 GROUND_CLUTTER 或 RADIAL_INTERFERENCE 的确定原因标签。确切原因需独立证据，未确定原因使用新增 NON_METEOROLOGICAL 标志。
- 干扰补充模块的入口是开源证据层，不再是旧算法种子扩张；输出局部门段和置信证据，不填补丢失门，不沿整条射线全删。

## 5. 版本与接口

沿用任务/API 体系，不新增微服务、外部账号或云接口。依赖 arm_pyart（导入 pyart）和 wradlib 均在 Linux CPU 镜像内安装，使用项目锁文件锁定所有依赖，保存安装报告、许可证和镜像摘要；安装兼容性未实测前不宣称某版本组合可部署。

新增 profile fujian-qc-opensource-v1，pipeline qc-opensource-1.0.0；冻结旧 v2/v3 不修改。profile 记录 engine 参数、能力缺失策略、证据融合和资源上限。JSON Schema 先改再写实现。

QC flags v2 使用目前预留 bit 15 为 NON_METEOROLOGICAL，旧 bit 含义不变；所有读取者按 definition_version 解码。Hybrid/拼图将该原因纳入硬拒绝集合。UI 提供来源算法、候选/最终动作、拒绝/保留理由、输入版本；字段仅追加，旧产品继续可读。

同一次任务的输入、上下文、profile、库版本和资产哈希组成缓存身份。结果 URI 不覆盖旧工件。同一分析不得混用旧/新 QC；展示“最新成功且链路一致”的分析，回退明确显示旧版本。

## 6. DEM 与静态资产

已有 gridding profile 采用 Copernicus GLO-30、4/3 地球半径、最大沿程遮挡和最低可用仰角。保留这些业务约束，替换数学函数前做平地/单山峰/累计遮挡和真实 DEM 一致性测试。核对站高垂直基准、天线高、波束宽度；当前 allow_engineering_only 不等于业务地形验收。

静态杂波图与海岸资产为空不能静默按正常执行记成功。输出 missing_asset，缺失期间不声称地物/AP 能力完整。杂波图须从多个无降水时段统计并版本化，不能从本次降水过程反推固定删除图。严重遮挡剔除或用更高仰角，禁止反射率强行放大恢复。

## 7. 验收数据与门槛

冻结当前 08/28 全部真实体扫清单并按 scan_id 去重；排除合成样本和其他日期试验样本。08:10、08:15、08:25、08:30 强制覆盖，检查时间均为北京时间，不能只测最低仰角。纳入全部站点及所有可用反射率仰角。

开发集采用包含上述失败案例的连续时间块。独立验收使用不重叠且与上下文窗口隔离的时间块，包含其他站点；若只有单日数据，只允许该历史过程验收，不声明跨天气通用。人工标签至少区分确认干扰、确认降水、不确定；不确定区域不纳入精确率/召回分母，单独报告占比。标签量和事件数必须公开，不能用海量相关门掩盖样本不足。

同一输入对照：现行2.1.0、Py-ART独立基线、wradlib独立基线、开源融合、新增径向补充。每一步报告增益和误删，保留未加自研的开源基线。

候选推广工程目标：每个强制案例确认干扰门召回≥90%，确认降水门误拒≤1%，确认≥35 dBZ降水门保留≥99.5%；按站/时段分别报告，任一分组不达标不推广。以上是本项目提出的验收目标，并非库保证或已达标。还必须检查残余长射线几何、降水区结构和QPE变化，不能用总删除率替代效果。

保护与契约必须100%通过：原始字节不变、缺测不转无雨、错误几何拒绝、概率方向正确、缺字段有降级、0/360与扇扫边界正确、重复投递幂等、旧工件可读、新原因在Hybrid/拼图硬过滤。不得仅靠截图“变干净”验收。

## 8. 性能与重算

保留 105 QC/grid 各4实例；每体扫只解码/读对象一次，每 sweep 只建一次适配对象，所有模块共享只读数组。限制 BLAS/OpenMP 每进程1线程，避免多实例过度订阅；DEM/几何缓存有容量上限，数据身份包含资产版本。测各阶段 wall time、CPU、峰值RSS、对象I/O、排队和端到端 P50/P95。

首轮影子基线独立限制2个计算进程，避免与现有重算争抢I/O。推广门槛：同机同数据同并发下，QC P95 不超过当前2.1.0的1.5倍，4实例总峰值RSS不超过32 GiB；若超限先剖析I/O/转换/纹理热点，不降低质量阈值求速度。这是资源目标，不是已实测能力。

新profile验收后按唯一体扫重算一次，再构建各分析时次，避免按每个预报反复重算重叠输入。复用必须包含上下文选择及配置哈希；不同上下文不能复用。每个完整分析就绪立即发布，不等待全部预报。当前旧版本批次保留作为对照，不删除已有结果；新批次切换在任务边界执行，不混跑未标识版本。

A：契约、依赖和两个开源适配器，默认影子模式，输出完整基线报告。独立合并后现有产品照常运行，已可供测试比较。
